Download the Qunxing desktop app

Explore open math problems on your own computer, with the AI subscription you already have. Results are checked in Lean.

The beta isn’t out yet. Download buttons will appear here when the first version is released.

To hear about it first: open qunxingmath-org/qunxing-app on GitHub and choose “Watch → Custom → Releases”.

Get started in three steps

  1. Install. Run the installer (no administrator rights needed), or unzip the full package anywhere and double-click Qunxing.exe.
  2. First launch. The setup guide helps you pick a work folder, finds the Codex CLI, Claude Code or Gemini CLI already on your computer, and connects one as your console. A subscription or an API key both work.
  3. Draw a problem and run it. Draw an open problem from the bank, check whether it is still open, then let the AI work on it. You can pause, add budget or send a hint at any time. Results that pass both the Lean check and the statement check light a star on the star map.

What you need

  • Windows 10 or 11, 64-bit.
  • At least one AI coding tool, signed in: Codex CLI, Claude Code or Gemini CLI.
  • Lean 4 is optional: you need it only for the Lean check, and the setup guide shows how to install it.
  • Internet access for drawing problems, bank updates, novelty checks and AI calls. You can also run locally only.

Privacy

  • Nothing is uploaded by default. Run records, proofs and costs stay on your computer.
  • To submit a result to Qunxing you press “Upload to Qunxing” yourself, in two steps, each with its own consent.

Safety

If Windows says “Windows protected your PC”, it is because the app isn’t code-signed yet. Make sure you downloaded it from this page or GitHub, click “More info”, then “Run anyway”.

To verify the file, open PowerShell in your download folder and run the command below. The result should match SHA256SUMS.txt in the release.

Get-FileHash .\Qunxing-Setup.exe -Algorithm SHA256
