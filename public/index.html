About Qunxing

Qunxing (群星, “the stars”) is an open-source project for exploring open mathematical problems with AI. Results are checked in Lean, and each verifiable contribution lights a star on a public star map.

Status: the desktop app is in early testing. The problem bank, star map and data API will appear here as they become available.

Download for Windows

Browse the problem bank: qunxingmath.org/en/problems.

Source and data: github.com/qunxingmath-org. Contact: team@qunxingmath.org. Please report security issues privately as described in SECURITY.md.

Qunxing records submitted material and local check parameters; it does not vouch for the correctness of results. The Qunxing name and logo are not covered by the open-source licenses.
