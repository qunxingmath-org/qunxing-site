下载群星桌面端

在自己的电脑上，用你已有的 AI 订阅探索开放数学问题；结果用 Lean 检验。

测试版还没发布。第一个版本发出后，这里会放下载按钮。

想第一时间知道：在 GitHub 打开 qunxingmath-org/qunxing-app，点「Watch → Custom → Releases」。

三步上手

  1. 安装。运行安装包，不需要管理员权限；或者把完整应用包解压到任意文件夹，双击 Qunxing.exe。
  2. 第一次打开。新手引导会带你选好工作文件夹，找到电脑上已经装好的 Codex CLI、Claude Code 或 Gemini CLI，并连上一个当指挥台。用你已有的订阅或 API 都行。
  3. 抽一道题，开跑。从题库抽一道开放问题，先查新，再让 AI 解题。随时可以暂停、追加预算、插话。Lean 核对和题意复核都通过的结果，会在星图上点亮。

需要什么

  • Windows 10 或 11，64 位。
  • 至少一个会写代码的 AI 工具，并且已经登录：Codex CLI、Claude Code 或 Gemini CLI。
  • Lean 4 是可选的：要让结果过 Lean 核对才需要，新手引导里会教怎么装。
  • 联网：抽题、更新题库、查新和调用 AI 时要联网。也可以设成只在本机运行。

隐私

  • 默认不上传任何东西。运行记录、证明和花费都留在你的电脑上。
  • 想把结果提交到群星，要你自己点「上传到群星」：分两步，每步单独同意。
  • 数据存在哪里、谁会收到、保存多久：见隐私政策。

安全提示

如果 Windows 提示「Windows 已保护你的电脑」：这是因为程序还没有代码签名。确认文件是从本页或 GitHub 下载的，点「更多信息」，再点「仍要运行」。

核对文件：在下载文件夹里打开 PowerShell，运行下面的命令，结果应和 Release 里的 SHA256SUMS.txt 一致。

Get-FileHash .\Qunxing-Setup.exe -Algorithm SHA256
