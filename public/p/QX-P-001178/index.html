题面

给 n 点集添加最少多少个点使其'自反'（每条确定线两侧点数≤3 型条件）？

形式化表述

求 R(n) 精确值/上界（小 n 精确，一般渐近）。

人话版

一句话：为了让一个 n 点集「自反」，最少要往里添几个点？

R(n) 是这样一个极值量：对平面上的 n 点集，需要额外加入多少个点（这些点称为反射点），才能使所得点集成为「自反的」。输入里对「自反」只给了一个模糊的线索（每条确定的直线两侧点数满足某类不超过 3 的条件），具体定义须按出处原文核对，其中「确定线」「反射点」的准确含义都影响答案。已知小 n 的精确值和一般的上界，一般情形（含渐近行为）仍未被确定。

（AI 起草，未经人工审校）

原文摘录

TOPP topp-0066 (Pach–Pinchasi et al.): characterize R(n), the minimum total number of reflex points needed so that a set of n points becomes reflexive.
