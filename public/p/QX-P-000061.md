# 21.130 奇阶有限交换群：|A|=n>2 元素可排列使相邻和互异

## 题面

（Sun 猜想）|G| 为奇的有限加法交换群，|A|=n>2，则 A 可排列为 a₁,…,a_n 使 a₁+a₂, a₂+a₃, …, a_n+a₁ 互异？（小 n 手验+构造，A层。）

### 形式化表述

见题面。

## 人话版

**一句话**：奇阶交换群里取 n 个元素，能排得让相邻两两之和全不相同吗？

设 G 是有限的加法交换群，且 |G| 为奇数；A 是 G 的一个子集，元素个数 n > 2。把 A 排成一个序列 a₁,…,a_n，然后看相邻两项之和：a₁+a₂、a₂+a₃、……、a_{n−1}+a_n，最后还有 a_n+a₁（首尾相接，所以一共有 n 个和）。猜想说：总能找到一种排法，使这 n 个和两两不同。n 是奇数这一细节在首尾相接时会影响结构的对称性。小 n 可以直接手算验证，大 n 需要对交换群的子集结构给出统一论证。

## 边界与约定

- 最小参数: n=3（3 个和两两互异——最小域；任意奇阶交换群任意 3 元子集手验可行）；n=4,5（回溯可及）。
- 退化情形: |G| 奇为前提（偶阶群域外——2 阶元的存在会破坏什么？注意 n 个和互异在偶阶下可能失败——前提的作用是检查点）；A=G 全集情形（|A|=|G|）；重复和的代数刻画（a_i+a_{i+1}=a_j+a_{j+1} ⟺ 四点结构——冲突图模型）。
- 约定依赖: 加法交换群记法；排列=A 的双射枚举；互异=n 个和两两不同（闭环含 a_n+a₁）。
- 结构性锚点: 冲突图（顶点=A 的元素对排列位置约束）+ Hamilton 回路模型——排列存在性=冲突图着色/回路问题，SAT/回溯直接可攻；奇阶假设在其中的作用是核心结构检查点。
- 建议独立验证方法（仅描述，不执行）: 对 (G,A) 小实例（Z_p, p≤13）SAT/回溯穷举排列验证（与 Kourovka 编目途径不同源）；对声称反例输出排列不存在性证书（冲突图不可满足）。
