# Is every link with vanishing Milnor invariants concordant to a homology boundary link?

## 题面

Milnor高阶链环不变量消失的链环是否都协边于homology boundary link？1990年代Cochran-Orr与Livingston已给出Milnor不变量消失但不协边于boundary link的例子；homology boundary link（更大类）情形开放。原文给出协边于homology boundary link的障碍与潜在反例构造路径。

### 形式化表述

判断存在Milnor不变量全消失但不协边于任何homology boundary link的链环；或证明皆可。

## 人话版

**一句话**：高阶链环不变量全消失的链环，都协边成"像边界"的链环吗？

链环是空间中若干条互不相交的闭曲线。Milnor 不变量是一族高阶不变量，粗略地记录各分支之间如何互相缠绕；若各分支都像边界一样解开，这些不变量就消失。boundary link 是各分支分别为某个曲面边界的那种理想情形，homology boundary link 是它的同调推广，条件更宽。1990 年代 Cochran-Orr 与 Livingston 已给出 Milnor 不变量全消失、却不协边于 boundary link 的例子；把这些例子换成 homology boundary link 后问题仍开放，需要构造新的障碍或证明皆可。

## 已知结果与进展

原文：给出障碍+高度solvable的homology boundary links不协边于boundary links（推深Cochran-Orr-Livingston结果）；每个homology boundary link在solvable filtration 0.5项处等价于boundary link；Park 2021 Princeton报告。原文摘要明示homology版未知。
