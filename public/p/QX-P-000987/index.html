人话版

一句话：一个对子群、商、扩张都封闭的群类，能包含多大的对称群？

有限群的非空类 X 若对取子群、取同态像、取扩张都封闭，就称完全类。除全体有限群这一类之外，完全类 X 的对称边界定义为使对称群 S_n 属于 X 的最大整数 n。已知每个不等于 3 的正整数都能成为某个完全类的对称边界。输入引文在此处被截断，只写到（在 CFSG 下，Revin 2025）：对每个完全类 X 存在非负整数 m，使……后面的条件原文缺失，因此这张卡的确切问句仍需对照原文补齐。
