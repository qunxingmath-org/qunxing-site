# MO#17560：2^x 与 3^x 均为整数 ⇒ x 为整数？

## 题面

若 2^x 与 3^x 皆为整数，x 必为整数吗？

### 形式化表述

2^x,3^x∈ℤ ⇒ x∈ℤ。

## 人话版

**一句话**：两个指数都取整数值，指数本身一定是整数吗？

设 x 是实数，并且 2^x 与 3^x 都是整数，比如 2^x=m、3^x=n。题目问：这时 x 是否必为整数？若 x=p/q 是有理数，取 q 次方可得 2^p=m^q、3^p=n^q，由此可以推出 q=1，所以有理数情形答案是肯定的。真正的问题是：会不会存在无理数（甚至超越数）的 x 同时做到这两点。这等价于问 2 与 3 的对数之间是否存在异常的整数关系，属于对数线性型与超越数论的范畴。
