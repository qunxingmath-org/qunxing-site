# a²+b²+3ᶜ+5ᵈ 表示

## 题面

n=a²+b²+3ᶜ+5ᵈ 表示

## 人话版

**一句话**：每个整数都能写成两个平方数加 3 的幂加 5 的幂吗？

题目问：是否每个整数 n 都能写成 n=a²+b²+3^c+5^d，其中 a、b 取整数，c、d 取非负整数（于是 3^c 与 5^d 也可取 1）。这是「万有表示」型问题：给定几类数（平方数、指数数列），问它们的和能否覆盖全部整数。Lagrange 四平方定理说明两个平方数不够、要四个才够，所以这里必须靠 3^c 与 5^d 补缺口。难点在于指数项极稀疏，而平方数又受模小素数的局部障碍限制率，局部与整体要同时处理。卡片未写明 a、b、c、d 的取值范围与 n 的正负，这里是常见口径。
