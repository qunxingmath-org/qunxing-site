题面

n 点完全图上 Maker–Breaker 三角形博弈（每轮 Maker 占1点、Breaker 占q点，Maker 想造单色三角形）的阈值偏置 q* 的精确值是多少？

形式化表述

求 q*(n) = min q 使得 Breaker 有必胜策略；已知 ⌈√(2n-2)-3/2⌉ ≤ q*(n) ≤ (√(8/3)+o(1))√n，上下界缝隙 ~常数因子。

人话版

一句话：Maker 抢 1 条边、Breaker 抢 q 条，q 多大才守得住三角形？

在 n 个顶点的完全图 K_n 上玩抢占游戏：每轮 Maker 占 1 条尚未被占的边，Breaker 占 q 条。Maker 的目标是自己占的边里凑出一个三角形，Breaker 想把所有三角形都堵死。阈值偏置 q*(n) 是让 Breaker 有必胜策略的最小 q。题面给出已知范围：⌈√(2n−2)−3/2⌉ ≤ q*(n) ≤ (√(8/3)+o(1))√n，两端只差一个常数因子，精确值长期未知。

（AI 起草，未经人工审校）

已知结果与进展

  • 经典界：Maker 赢 q≤0.5√n、Breaker 赢 q≥2√n 量级；2022 "A new bound for the Maker–Breaker triangle game" 显著收紧。
  • 2026 预算变体（budget 版）阈值已被解出（2609.38138）——但经典版仍开放。
  • 原文明确："first version ... for which the exact threshold bias is known"（指其变体）。

边界与约定

  • 边界：(1:q)偏置定义；Maker先手。
  • 独立验证建议：n≤200精确阈值DP/博弈搜索。
