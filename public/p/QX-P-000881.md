# F_2^n∖{0} 二染色中单色线性子空间规模 f(n)=O(n)？（OWR 2023/1）

## 题面

F_2^n 的非零向量二染色中必有单色（连同 0 构成）线性子空间，其规模 f(n) 是否 O(n)？

### 形式化表述

f(n) ≤ Cn ?

## 人话版

**一句话**：把非零向量染成两色，单色子空间能做到只有线性大小吗？

把 F_2^n 里除零向量外的所有向量任意涂成两种颜色。若一组非零向量连同 0 构成 F_2^n 的线性子空间，且这组非零向量全是同一种颜色，就叫一个单色线性子空间。f(n) 定义为最大的整数，使得无论怎么二染色，都必定存在规模为 f(n) 的单色子空间；等价地，它是所有染色下能保证拿到的最小值。问题问 f(n) 是否随 n 线性增长，即 f(n)≤Cn。这是把 Ramsey 理论搬到向量空间上的典型问题。
