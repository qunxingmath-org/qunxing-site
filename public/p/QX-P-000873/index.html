题面

在三个 Reidemeister 移动之外添加哪些移动，能使任意平凡结图都可通过交叉数严格不增的序列简化为平凡图？

形式化表述

∃移动集 M ⊃ {R1,R2,R3}: ∀平凡结图 D ∃M-序列 单调降到 0 交叉。

人话版

一句话：光靠三种 Reidemeister 移动，会让化简过程绕远路吗？

纽结图画在平面上，只允许三种局部改法：R1 拆掉一个自扭，R2 让两段平行边互滑，R3 让一条弧越过交叉点。一个图是平凡结图，指它代表不打结的圈。问题是：能否在这一步里始终保持交叉数不增（最好严格下降）地把它化简成零交叉的圆？已知只靠 R1、R2、R3 做不到单调，过程中交叉数常要暂时上升。因此要找出该额外补上哪些移动，才能保证任何平凡结图都有单调化简的路线。

原文摘录

Are there additional moves that, when added to the three Reidemeister moves, allow for strict monotonic descent in the crossing number of an unknot diagram?
