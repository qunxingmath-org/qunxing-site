# 模立方根提取是否等价于因数分解（TAOCP v2 4.5.4 ex.33, M50）

## 题面

N=pq，p≡q≡2 (mod 3)。若存在较高效算法以不可忽略概率从 N 与 x³ mod N 求 x mod N，则存在高效因数分解算法？

### 形式化表述

归约存在性断言。

## 人话版

**一句话**：能从 N 和 x³ mod N 反推 x，就等于会分解 N 吗？

取 N=pq，其中 p、q 都是模 3 余 2 的素数。此时 3 与 p−1、q−1 都互素，所以 x↦x³ mod N 是双射，每个值都有唯一的立方根 x。问题：若存在高效算法，能以不可忽略的概率从 N 和 x³ mod N 还原 x，是否就能据此造出高效分解 N 的算法？若是，则「开立方」与「分解」难度相当，这个假设就不能当作独立的密码学困难来源。
