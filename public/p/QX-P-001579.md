# 21.51 p-群：p^n 阶(初等)交换子群 ⇒ 同阶正规(初等交换)？

## 题面

（Glauberman）a) P 有 p^n 阶交换子群，对哪些 n 必有 p^n 阶正规交换子群？b) 改为初等交换呢？（p=2 时 b) 仅 n≤4 等已知。）

### 形式化表述

见题面 a/b。

## 人话版

**一句话**：有 pⁿ 阶交换子群，就一定有同阶正规交换子群吗？要哪些 n 才行？

P 是有限 p-群。题目分两问：(a) 若 P 有 pⁿ 阶的交换子群，对哪些 n 能保证 P 也必有 pⁿ 阶的正规交换子群？(b) 若把「交换」换成「初等交换」（每个非单位元都是 p 阶，即同构于 (Z/p)ⁿ），对哪些 n 能保证存在同阶的正规初等交换子群？答案依赖 n 与 p 的关系，题目要的正是这个分界。原文注明：p=2 时 (b) 只有 n=1 成立；两问在 n<(p+2)/2 时都成立（Glauberman, 2008），此外还有其他已知情形。
