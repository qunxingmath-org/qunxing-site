# 正 n 边形边向量随机排列的不自交概率（AMM E2594）

## 题面

将正 n 边形的 n 个边向量随机排列（形成闭多边形），所得多边形为简单（不自交）的概率 P(n)。

### 形式化表述

P(n) = #{σ∈S_n: 边向量排列 σ 给出简单多边形}/n!（mod 剩余对称性）——求 P(n) 公式/渐近。

## 人话版

**一句话**：把正 n 边形的边向量随机打乱首尾相接，得到简单多边形的概率是多少？

取正 n 边形的 n 条边，把每条看成一个有方向的向量；随机打乱顺序后从原点出发依次首尾相接，由于这些向量加起来是 0，接出来必定是闭合多边形。问它不自交（即简单多边形）的概率 P(n) 作为 n 的函数是多少。难点：“自交”是几何条件，要在线性多个排列里刻画它，精确计数和渐近分析都不容易。

（AI 起草，未经人工审校）

## 已知结果与进展

- 凸排列恰 2n 个（旋转/反射）⇒ P(n) ≥ 2n/(n−1)! 下界；随机等边多边形文献（Diao–Millett–Varela 等）活跃但无该精确量。
