题面

等投影多面体（除平行于面的方向外所有正交投影均为 n 边形）的完全刻画/构造。

形式化表述

刻画所有 n-等投影凸多面体（Shephard 意义）。

人话版

一句话：除了少数几个视角，从哪边看都是 n 边形的多面体长什么样？

称一个凸多面体 P 是 n-等投影的：除了正对着某个面的那些投影方向之外，从任何方向做正交投影（也就是看它的影子），得到的都是同一个 n 边形。比如正四面体从不同方向看，影子有时是三角形有时是四边形，就不算。这个概念由 Shephard 在四十多年前提出，已有结果只覆盖部分情形，完整的刻画尚未得到。问题是要把所有 n-等投影凸多面体刻画出来，说清它们的组合结构必须满足什么条件。

（AI 起草，未经人工审校）

原文摘录

Seeing Garabed Gulbenkian's question (which was inspired by Joel Hamkins' question ), reminds me of an analogous problem which I believe remains open, and which some might find intriguing. Define an equiprojective polyhedron $P \subset \mathbb{}R^3$ as one whose orthogonal projections—with the exception of projections in directions parallel to a face—are all $n$-gons for the same $n$. The definition is due to Shephard, 45 years ago.
