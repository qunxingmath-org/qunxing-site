题面

含 n 个凸包顶点的最小点集规模 g(n)（"快乐结局"问题）。已知 g(3)=3, g(4)=5, g(5)=9, g(6)=17（Szekeres–Peters 2006 计算机定值）；g(7)=? 开放。猜想 g(7)=33（$500 悬赏）。
校准（子线程提醒）：空六边形 h(6)=30 已由 SAT 定值（Heule 等 2024, arXiv:2403.00737）——非 g(7)，媒体常混淆；空 7-gon 无有限界（Horton 集）。

人话版

一句话：要保证平面上能挑出 7 个点组成凸七边形，最少需要多少个点？

把 n 个点放在平面上，要求任意三点不共线（一般位置）。g(n) 是最小的整数，使得任何 g(n) 个处于一般位置的点里，都能挑出 n 个点，它们恰好是一个凸 n 边形的顶点。这就是「快乐结局问题」的核心常数。已知 g(3)=3、g(4)=5、g(5)=9、g(6)=17，而 g(7) 仍未知，普遍猜测是 33。要注意别把它和另一类「空多边形」常数搞混：输入特别提醒，空六边形的个数已经定值为 30，那是另一个量，不是 g(7)。

（AI 起草，未经人工审校）

已知结果与进展

  • 33 ≤ g(7) ≤ 37；空六边形 h(6)=30（SAT 2024，区分）；2025-12 新 SAT 编码论文（Dumitru）获部分锚定子族 UNSAT
  • Suk 2016：ES(n) ≤ 2^{n+o(n)}
