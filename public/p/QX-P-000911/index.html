题面

n 次平面多项式系统的临界周期（周期函数局部极值）最大个数 T(n)：是否 ≥C·n²log n？

形式化表述

如上。

人话版

一句话：平面多项式系统的临界周期个数，能不能到达 n²log n 量级？

平面多项式微分系统是一组形如 ẋ=P(x,y)、ẏ=Q(x,y) 的方程，P、Q 是次数不超过 n 的多项式。若系统有一圈闭轨族，轨道周期会随初始条件变化，形成所谓的周期函数；在这个函数的局部极值处，周期对参数的变化率为零，叫临界周期，它们是分岔时周期轨道成批出现的地方。T(n) 是 n 次系统最多能有多少个临界周期。问题问：是否存在常数 C>0，使 T(n)≥C·n²log n？这比目前已证的下界都要强。

（AI 起草，未经人工审校）

Let T(n) be the maximum number of critical periods that a planar polynomial differential system of degree n can have. Is there a constant C>0 such that T(n) ≥ Cn^2 log n?
