Arnaudiès: which spaces admit continuous choice of factor lines for real forms?

题面

刻画这样的 Hausdorff 空间 T：T 上任何"逐点有 n 条不同实方向"的连续齐次多项式场都可连续选取 n 条直线。

形式化表述

T ∈ 𝒞 ⇔ ∀ 连续映射 P: T→(无重根实齐次 n 次型) ∃ 连续 s_i: T→RP¹, P(t)=Π l_{s_i(t)}。

人话版

一句话：在什么空间上，一族实系数齐次多项式可以连续地拆成一次因式？

设 T 是 Hausdorff 空间。给 T 上每一点配一个 n 次实齐次多项式（系数随点连续变化），并且每个多项式都恰有 n 条互不相同的实直线作为零点（无重根）。题目要刻画这样的 T：存在连续映射，把每个点对应的 n 条直线都连续地挑出来，使多项式恰好是这 n 条直线之积。这属于“连续选取”问题，直觉上与 T 的拓扑性质（如是否为单连通、有无环路障碍）有关；难点是要给出充要条件而不是只有充分条件。
