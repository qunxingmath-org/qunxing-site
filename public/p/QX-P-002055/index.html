互素多项式商 C^∞ 延拓（MO#506765 已答：永不可延拓）

人话版

一句话：在原点没定义的有理函数，能补成整块平面上的光滑函数吗？

设 p、q 是实系数二元多项式，没有公因式，且 (0,0) 是二者的孤立零点——存在一个去掉原点的圆盘，p、q 在其上都不为零。于是 p/q 在 R² 去掉原点处有定义。问题问：能否把 p/q 延拓成 R² 上处处连续、且所有阶偏导数都连续的 C∞ 函数。难点全在原点：即便沿每条方向的极限都存在，要让所有阶导数在原点「平坦」也极难。卡上 status 为 solved，标题注明已有回答：永不可延拓。

Is it ever possible to extend the function $\frac{p(x,y)}{q(x,y)}$ to a function $f(x,y)$ which is continuous on $\mathbb{R}^2$ and has continuous partial derivatives of all orders on $\mathbb{R}^2…
