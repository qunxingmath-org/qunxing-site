# 容纳所有自由 n-omino 的最小区域

## 题面

容纳所有自由 n-omino 的最小区域

## 人话版

**一句话**：要一块多大的画布,才能把每种 n 连方都单独摆进去？

n-omino 指由 n 个单位正方形边对边连成的图形,自由指把旋转和翻转看成同一个图形。问题问:要多大的一块区域,才能让每一个自由 n-omino 都放进它里面(每次只放一个,不要求同时放)。「多大」可以按面积算,也可以按直径或外接矩形算。n 很小时能逐个摆出来核对,随 n 增长图形种类爆炸式增加,精确的最小区域就难以确定。输入把这张卡标为「部分解决」,即部分 n 已有结论。
