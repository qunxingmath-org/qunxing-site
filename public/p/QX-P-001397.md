# Goodman 反函数闭形式/级数表示（Crux 283）

## 题面

求 f(x)=−2x ln x/(1−x²) 的反函数的闭形式或良好级数表示。

### 形式化表述

g: [0,1]→(0,1], f(g(y))=y；求 g 的闭式或收敛性良好的级数。

## 人话版

**一句话**：一个含 x·ln x 的简单函数的反函数，写得出闭形式吗？

函数 f(x) = −2x·ln x/(1−x²) 定义在 (0,1) 上：x 趋于 0 时它趋于 0，x 趋于 1 时它趋于 1，并且单调递增，所以它把 (0,1) 一一映到 (0,1)，反函数 g(y) 存在。麻烦在于 f 里同时有 x 的一次项和 ln x，方程 y = f(x) 无法用初等运算解出 x。题目问：g 能否写成闭形式？如果不能，能否给出一个“好的”级数表示（不必是幂级数，允许其它展开）。思路是看 f 在 0 或 1 附近的展开，再用级数反演把 g 拼出来，并估计收敛速度。

（AI 起草，未经人工审校）
