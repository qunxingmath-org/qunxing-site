题面

Catalan–Dickson 猜想（276 Lehmer five 之首；Guy–Selfridge 反方立场并存）

人话版

一句话：把「所有真因子加起来」反复做下去，每条轨道都终将停下吗？

对正整数 n，令 s(n) 为 n 的所有真因子（不含 n 自身）之和；从 n 出发反复取 s，得到一串数 n, s(n), s²(n), …，称为 aliquot 序列。Catalan 与 Dickson 猜想：每条这样的序列最终都会进入 1（对应素数，序列终止）或者进入一个循环，不会无限增长下去。反方立场则认为存在会无限增长的轨道。以 276 开头的序列是最有名的悬案之一，与 552、660、966、1074 一起被称为「Lehmer five」，它们至今没有被判定。
