# Erdos P19: Erdos-Faber-Lovasz conjecture chi = n

## 题面

n个K_n的边不交并图G, 是否χ(G)=n？(Erdős–Faber–Lovász猜想)

### 形式化表述

∀ edge-disjoint union of n copies of K_n: χ(G)=n. 已知: 大n成立(KKKMO21); n<10 Hindman; 有限小n待决。

## 人话版

**一句话**：n 个 K_n 边不交地并起来，颜色数恰好是 n 吗？

取 n 个 K_n 的副本，把它们放在同一个顶点集上，要求任意两个副本之间最多共用一个顶点、且共用时只共用那一个点——这样得到的图 G 有 n 个团，每条边只属于其中一个团。猜想是 χ(G)=n：一方面这些团每个都要用 n 种颜色，所以 χ(G)≥n；猜想说的是不需要更多。这个命题等价于一个关于线性超图边染色的经典猜想。题面记录：n 充分大时已由 KKKMO21 证明，n<10 的情形也已验证，而 n 在中间的一段有限范围内仍待定。
