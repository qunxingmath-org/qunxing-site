# 17.64 Nottingham 群的 n-逼近：γ_i 商是否由 f(p) 稳定

## 题面

G 为无限 pro-p 群且 G/γn(G)≅J/γn(J)（J 为 Nottingham 群）称 n-逼近。是否存在 f(p)：f(p)-逼近的 γᵢ(G)/γᵢ₊₁(G) 同构于 J 的对应商？

### 形式化表述

见题面。

## 人话版

**一句话**：只要前 f(p) 层商群对得上，所有下中心因子就都对得上吗？

Nottingham 群 J=N(p) 是形式幂级数环 F_p[[t]] 上把 t 送到 t+高阶项的那些自同构组成的 pro-p 群。若 G 是无限 pro-p 群且 G/γ_n(G) 同构于 J/γ_n(J)（γ 表示下中心列），就说 G 是 J 的 n-逼近，即它与 J 在前 n 层商群上无法区分。问题问：能否只依赖 p 地选一个层数 f(p)，使得只要是 f(p)-逼近，就有 γᵢ(G)/γᵢ₊₁(G) 与 γᵢ(J)/γᵢ₊₁(J) 对所有 i 同构。原文指出，肯定回答会顺带推出 J 作为 pro-p 群有限表现（p>2 时现在已知成立）。

## 原文摘录

> 2010 辑问题 17.64，提出人：C. R. Leedham-Green〔batch_K二波〕
>
> Say that a group G is an n-approximation to the Nottingham group J =
> N(p) (as defined in Archive, 12.24) if G is an infinite pro-p group, and G/γn(G)
> is isomorphic to J/γn(J).
> Does there exist a function f(p) such that, if G is an
> f(p)-approximation to the Nottingham group, then γi(G)/γi+1(G) is isomorphic to
> γi(J)/γi+1(J) for all i?
> Cf. 14.56. Note that an affirmative solution to this problem trivially implies the
> now known fact that J is finitely presented as a pro-p group (if p > 2), see 14.55.
> C. R. Leedham-Green
>
> —— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21 (arXiv:1401.0300v50, 2026-11-02)
