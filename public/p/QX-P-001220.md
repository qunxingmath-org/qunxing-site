# Kobon三角形问题

## 题面

Kobon Fujimura问题。上界⌊n(n−2)/3⌋（Clément–Bader渐近紧）；具体n值常达不到上界（n=17等缺口）；精确K(n)多未知。

### 形式化表述

K(n) = max 三角形数。

## 人话版

**一句话**：n 条直线最多能围出多少个互不干扰的三角形？

画出 n 条直线，要求任意三条不交于同一点。数一数那些内部不被其他线段穿过的三角形区域有多少个，在所有摆法里取最大值，记作 K(n)。这就是以 Kobon Fujimura 命名的 Kobon 三角形问题。已知的上界是 ⌊n(n−2)/3⌋，它来自每条直线最多能参与多少个三角形，而且这个上界在 n 很大时能被逼近；但对具体的 n 常常达不到，例如 n=17 就已知有缺口。所以 K(n) 的精确值大多未知，问题就是把它算出来。

（AI 起草，未经人工审校）

## 原文摘录

> K(n) = n条直线排列（无三线共点）中可形成的'不含其他线穿过其内部'三角形最大数。确定K(n)。
>
> —— Wikipedia: Kobon triangle problem

## 已知结果与进展

渐近上界(1/3)n²+O(n)紧；小n精确值表（K(7)=11?等）；某些n（如17）构造缺口。

## 边界与约定

- 日期: 2026-11-21；添加者: SOL验证Agent（C层抽样轨道C）；性质: 仅列检查点
- 定义边界: 三角形由3条排列线围成（无其他线穿过内部=empty）；排列的仿射等价（平行线禁止?——Kobon排列通常一般位置含斜率互异——无平行约束须核对）
- 基准: K(3)=1、K(7)=?小值表核对；上界不可达的n清单（n=17缺口）
- 建议独立验证: 小n排列构造搜索（brute force扫描构型）对照已知值
