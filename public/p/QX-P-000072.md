# Kourovka 20.53：非迷向酉图距离正则，交数组 {q(q−1),(q+1)(q−2),q+1;1,1,q(q−2)}

## 题面

非迷向酉图距离正则，交数组 {q(q−1),(q+1)(q−2),q+1;1,1,q(q−2)}。q 非素数幂时存在这样的图吗？

### 形式化表述

∃distance-regular graph with this array for non-prime-power q ?

## 人话版

**一句话**：交数组里出现 q 的图，只对素数幂的 q 存在吗？

距离正则图是一类高度对称的图：从任一顶点出发，到距离 i 的点有多少、再往距离 i+1 的点有多少，只由 i 决定、与选哪个顶点无关；这些数排成所谓交数组。非迷向酉图是一族具体构造，它的交数组是 {q(q−1), (q+1)(q−2), q+1; 1, 1, q(q−2)}，其中 q 是素数幂；这类图的自同构群在顶点集与边集上都可迁，q = 3 时还已知它是距离传递的。问题问：若 q 不是素数幂，还存在具有这个交数组的距离正则图吗？要肯定它，需要真的造出图；要否定它，需要对所有非幂的 q 排除可能。

（AI 起草，未经人工审校）

## 原文摘录

> 提出人：A. A. Makhnev
> A nonisotropic unitary graph Γ is distance-regular with intersection array
> {q(q −1), (q + 1)(q −2), q + 1; 1, 1, q(q −2)} for some prime power q. The group
> G = Aut(Γ) acts transitively on the vertex set and on the edge set of Γ. It is known
> that Γ is distance-transitive if q = 3. Does there exist a distance-regular graph with
> such an intersection array if q is not a prime power?
> A. A. Makhnev
>

## 边界与约定

- 最小参数: q=6（最小非素数幂候选）起查；交数组 {q(q−1),(q+1)(q−2),q+1;1,1,q(q−2)} 在 q=6: {30,20,7;1,1,24}——可行性（谱/组合）可先机器排查再谈构造。
- 退化情形: 交数组可行性参数（v、k、b_i、c_i 一致性、 Krein 条件、距离正则谱）——非素数幂 q 下"酉图"无经典定义，问句仅要求图存在（不要求来自酉极形），声称解答不得偷换为"酉极形上的图"。
- 约定依赖: distance-regular 与 distance-transitive 区分（q=3 距离传递已知为背景）；"nonisotropic unitary graph" 的经典定义依赖 q=素数幂，q 非素数幂时命题自动退化为纯交数组存在性。
- 建议独立验证方法（仅描述，不执行）: 用距离正则图谱计算（Brouwer–Cohen–Neumaier 参数方程）对 q=6,8,10,… 做可行性筛，独立于 Makhnev 学派枚举；可行者再交构造途径。
