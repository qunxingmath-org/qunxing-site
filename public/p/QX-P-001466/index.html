题面

二进串集 B 由规则生成（奇长串可两端加 0、偶长串可两端加 1）。b_n=|B∩{0,1}ⁿ|。求 liminf b_n^{1/n} 与 limsup b_n^{1/n}。（(a) 部已证 1.6<λ₁,λ₂<1.9 的指数界）

形式化表述

确定 liminf b_n^{1/n} 与 limsup b_n^{1/n}（已知均 ∈(1.6,1.9)，数值 ~1.78 未收敛）。

人话版

一句话：按奇偶长度交替加 0 加 1，串的数量到底按什么指数涨？

从单个串 1 出发，反复用两条规则造新串：长度是奇数时，可以在左右两端各添一个 0；长度是偶数时，可以在两端各添一个 1。这样长出的全部二进制串组成集合 B。b_n 表示 B 中长度为 n 的串的个数。问题问的是增长阶：b_n 开 n 次方，当 n 趋于无穷时上极限和下极限分别是多少。已知这两个数都落在 1.6 与 1.9 之间，数值实验看起来在 1.78 附近，但还没有收敛的证据。
