# 18.47 三个类换位子生成群的轨道判定

## 题面

由三个给定类换位子生成的群：a) 在 Z 上只有有限轨道可判定？b) 在其支撑的非负整数上传递可判定？（困难例 ⟨τ1(2),4(6), τ1(3),2(6), τ2(3),4(6)⟩。）

### 形式化表述

见题面 a/b。

## 人话版

**一句话**：三个类换位子生成的群，它的轨道行为能被算法判定吗？

类换位子是把一个同余类 r mod m 与另一个同余类 s mod n 整体对调的置换（m、n 互素），它们作用在整数集 Z 上。题目问两个判定问题：给定三个类换位子，a) 算法能否判定该群在 Z 上是否只有有限条轨道；b) 算法能否判定它是否在其支撑的非负整数上传递。原文特别指出一个难例：某个具体的三生成群恰好在 N∖0(6) 上传递当且仅当 Collatz 3n+1 猜想成立，可见判定问题与著名的未解猜想纠缠在一起。

## 原文摘录

> 2014 辑问题 18.47，提出人：S. Kohl〔batch_K二波〕
>
> Is it algorithmically decidable whether a group generated by three given class
> transpositions (for the definition, see 17.57)
> a) has only finite orbits on Z?
> b) acts transitively on the set of nonnegative integers in its support?
> A difficult case is the group ⟨τ1(2),4(6), τ1(3),2(6), τ2(3),4(6)⟩, which acts transitively on
> N \ 0(6) if and only if Collatz’ 3n + 1 conjecture is true.
> S. Kohl
>
> —— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21 (arXiv:1401.0300v50, 2026-11-02)
