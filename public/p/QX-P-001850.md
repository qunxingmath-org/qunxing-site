# Ryser–Brualdi–Stein 拉丁方横贯猜想

## 题面

Ryser–Brualdi–Stein 拉丁方横贯猜想

## 人话版

**一句话**：每个 n 阶拉丁方，都能挑出 n−1 个互不同行同列同符号的格子吗？

n 阶拉丁方是填了 n 种符号的 n×n 表格，每行每列每种符号各出现一次。横贯指从中挑出 n 个格子，两两不同行、不同列、不同符号；只差一个格子的叫部分横贯。Ryser 猜想说奇数阶拉丁方必有横贯；Brualdi–Stein 猜想则说任何 n 阶拉丁方都有长度为 n−1 的部分横贯，后者更强也更统一。这个差值虽只有 1，却正是难点所在；题卡标为部分解决，说明已有部分情形被处理。
