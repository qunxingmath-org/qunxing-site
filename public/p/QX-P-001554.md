# 20.55 派生长 2 与 4、特征标表相同的可解群对存在？

## 题面

是否存在派生长分别为 2 与 4、特征标表完全相同的非同构有限可解群对？（派生长 n 与 n+1 的对已构造，Mattarei 1992。）

### 形式化表述

∃G,H 可解, dl(G)=2, dl(H)=4, 同特征标表, G≄H。

## 人话版

**一句话**：派生长差两步的两个可解群，能有完全一样的特征标表吗？

特征标表记录群的所有不可约复特征标在各共轭类上的取值，是很强的同构不变量，但并不完备：存在特征标表相同却不同构的群。派生长是导群列的长度，衡量群离阿贝尔有多远。题目问：是否存在有限可解群 G 与 H，派生长分别为 2 与 4，却拥有完全相同的特征标表？原文注明：Mattarei (1995) 已构造出派生长为 n 与 n+1（任意 n≥2）的同特征标表非构群对，而差两步的情形仍未知。
