# n-立方体顶点 n-单纯形互不全等计数

## 题面

n-立方体顶点 n-单纯形互不全等计数

## 人话版

**一句话**：在 n 维立方体的 2ⁿ 个顶点里挑 n+1 个，能挑出多少种互不全等的单纯形？

n 维立方体的顶点是全体坐标取 0 或 1 的 n 元组，共 2ⁿ 个。从中选 n+1 个点，若它们不落在同一张超平面上，就围成一个 n 维单纯形；形状由这些点两两之间的距离（等价地由各条边的差向量）决定，平移、旋转、翻折都不改变形状。题目问：把这些单纯形按全等分类后一共有多少类，并给出关于 n 的公式或递推。这是有限计数：固定 n 时每个顶点子集都能逐一算出边长多重集，可以用计算机核对前若干项；但类别数随 n 增长很快，硬枚举只能验证小情形，代替不了证明。
