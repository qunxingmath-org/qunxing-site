# 4-多胞形肥度是否有界（fat 4-polytopes 问题）

## 题面

是否存在绝对常数 c 使所有凸 4-多胞形的肥度 (f1+f2)/(f0+f3) ≤ c？

### 形式化表述

sup_P fatness(P) < ∞ ?

## 人话版

**一句话**：所有四维多胞形的肥度，会不会一起冲到无穷大？

四维多胞形的组合信息常记成 f-向量 (f0,f1,f2,f3)：f0 是顶点数，f1 是棱数，f2 是二维面数，f3 是三维面数。「肥度」定义为 (f1+f2) 除以 (f0+f3)，是刻画四维多胞形组合形状松紧程度的一个不变量。问题问：是否存在一个与多胞形无关的常数 c，使任何凸四维多胞形的肥度都不超过 c。若答案是否定的，就要给出肥度越来越大的具体一族多胞形。

（AI 起草，未经人工审校）
