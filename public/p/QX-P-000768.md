# Agrawal 多项式同余素性判据猜想

## 题面

n>1、r 为不整除 n 的素数：若 (X−1)^n ≡ X^n−1 in (Z/nZ)[X]/(X^r−1)，则 n 素或 n²≡1 (mod r)（Agrawal 猜想）。

### 形式化表述

AKS 型单同余素性判据的确定性条件。

## 人话版

**一句话**：一个多项式同余式，能同时抓住素数与 n²≡1 (mod r) 的合数吗？

在环 (Z/nZ)[X]/(X^r−1) 里比较两个多项式：(X−1)^n 与 X^n−1。当 n 是素数时，二项式展开模 n 会使所有中间项消失，恒有 (X−1)^n≡X^n−1，俗称「新生之梦」。Agrawal 猜想把这个方向反过来用：设 n>1、r 是不整除 n 的素数，只要这个同余式成立，n 要么本来就是素数，要么是满足 n²≡1 (mod r) 的合数。也就是说，除了 n²≡1 (mod r) 这一族例外，同余式就是素性判别式。难点在于合数情形不能靠简单代入排除。
