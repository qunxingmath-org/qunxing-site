# Kourovka 16.4：非平凡共轭类 C,D 使 CD 也是共轭类——G 可以是非交换单群吗

## 题面

非平凡共轭类 C,D 使 CD 也是共轭类——G 可以是非交换单群吗？（Arad-Herzog 猜想：不能）

### 形式化表述

nontrivial classes C,D with CD a single class ⇒ G not simple ?

## 人话版

**一句话**：两个非平凡共轭类相乘恰好还是一个类，这在单群里会发生吗？

CD 表示所有 cd（c∈C，d∈D）组成的集合。题设是 C、D 都是非平凡共轭类，且乘积 CD 恰好本身也是一个共轭类，问 G 能否是非交换单群。一般群中这种「类乘积封闭成类」的情形会导致很强的结构约束，Arad 与 Herzog 猜测非交换单群不可能出现。回答否就要给出一般性证明（通常要借助单群分类）；回答是就需给出具体单群与两类。

（AI 起草，未经人工审校）
