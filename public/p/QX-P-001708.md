# 拟完全数存在性（ω≥8 新进展 2026）

## 题面

拟完全数存在性（σ(n)=2n+1；**ω≥8 新进展=Toyohara–Tao–Yao 2026**）

## 人话版

**一句话**：约数和恰好比自身两倍多一，这样的整数存在吗？

σ(n) 是 n 的全部正因子之和（含 1 与 n）。完全数满足 σ(n)=2n，例如 6=1+2+3；拟完全数要求 σ(n)=2n+1，比完全数多 1。至今一个都没找到。已知的限制有两条：σ(n)=2n+1 必须是奇数，而 σ(n) 为奇数当且仅当 n 是完全平方或两倍完全平方；再往下论证能把候选压到奇数的平方，并且 n 的不同素因子个数 ω(n) 不能太少。卡上记有 2026 年一项把 ω≥8 纳入的新进展，但没说明是排除了 ω≥8 还是反之，须查原文确认。若能找到一例，只需列出它的因子逐个相加核对。
