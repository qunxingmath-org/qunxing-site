# Kourovka 14.95：（Leedham-Green-Neumann-Wiegold 类-宽度问题）p-群类 c 与宽度 b：c ≤ b+1 吗

## 题面

（Leedham-Green-Neumann-Wiegold 类-宽度问题）p-群类 c 与宽度 b：c ≤ b+1 吗？

### 形式化表述

c(P) ≤ b(P)+1 ?

## 人话版

**一句话**：p-群的幂零类，能比它的共轭类“宽度”最多多 1 吗？

对有限 p-群 P，幂零类 c(P) 是最小的 k，使 k 次换位子全部为 1，可以理解为群“离交换有多远”。宽度 b(P) 定义为使 p^{b} 等于 P 中最大共轭类的大小：共轭类越大说明群越不交换，b 就是该大小的 p 的指数。Leedham-Green、Neumann、Wiegold 提出：p≠2 时是否总有 c(P) ≤ b(P)+1？已知最好的界是 c < (p/(p−1))·b + 1，与猜测只差常数因子；而 p=2 时对每个 n 都有例子使 c(T_n) ≥ b(T_n)+n，所以这条整齐的线性关系只能在奇素数下追问。
