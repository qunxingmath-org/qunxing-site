# batch_I I-006：若 Ω 同时为 W^{1,p} 与 W^{1,q}（1≤p<q≤∞）延拓域（存在有界延拓算子 E:W

## 题面

若 Ω 同时为 W^{1,p} 与 W^{1,q}（1≤p<q≤∞）延拓域（存在有界延拓算子 E:W^{1,r}(Ω)→W^{1,r}(Rⁿ)，r=p,q），是否对一切 p<r<q 也是 W^{1,r} 延拓域？

### 形式化表述

(Ω 为 W^{1,p}-ext domain) ∧ (Ω 为 W^{1,q}-ext domain) ⇒ ∀r∈(p,q): Ω 为 W^{1,r}-ext domain？

## 人话版

**一句话**：两个端点指数都能延拓，中间的指数就一定也能延拓吗？

W^{1,p}(Ω) 是由 Ω 上本身与一阶弱导数都 p 次可积的函数组成的空间。若存在有界线性算子 E，把 W^{1,r}(Ω) 中的函数延拓成定义在整个 Rⁿ 上的 W^{1,r} 函数且保持有界，就称 Ω 是 W^{1,r} 延拓域，光滑边界或 Lipschitz 边界的区域都是。问题问：若同时是 W^{1,p} 与 W^{1,q} 延拓域（p<q），中间的 r 是否自动也成立？直觉上 Sobolev 空间在两端的延拓性质之间可以插值，但插值只保证得到依赖两侧范数的弱型估计，能否直接得到单个指数 r 上的算子并不显然。

（AI 起草，未经人工审校）

## 原文摘录

> Let $\Omega\subset\mathbb{R}^n$ be a bounded domain. Suppose that there there is a bounded extension operator $$ E:W^{1,p}(\Omega)\to W^{1,p}(\mathbb{R}^n) \quad \text{and} \quad E:W^{1,q}(\Omega)\to W^{1,q}(\mathbb{R}^n), $$ where $1\leq p<q\leq\infty$ (or $1<p<q<\infty$ if you find it easier). Open problem. Does it follow that $$ E:W^{1,r}(\Omega)\to W^{1,r}(\mathbb{R}^n) $$ for all $p<r<q$ ? Some partial results are known, but the general case seems to be difficult.

## 边界与约定

- 边界：1≤p<q≤∞；'同一算子E'vs'分别存在'两读法——原问写同一E（需保留原文约定）。
- 独立验证建议：反例候选域（分形边界）数值验证W^{1,r}延拓失败。
