# Sustainable 树的完全刻画与渐近占比

## 题面

完全刻画哪些树是 sustainable（对每条边 e，存在另一条边 f 使换边后邻接谱半径不减）；并决定 sustainable 树在 n 顶点树中的渐近占比。

### 形式化表述

树 T sustainable := ∀e∈E(T) ∃f∉E(T) 使 ρ(T−e+f) ≥ ρ(T)。目标A: 完全刻画；目标B（作者自留）: lim_{n} #{sustainable trees on n vertices}/#{trees on n vertices} 是否为 0；目标C（作者自留）: generalized tree-shift 序上的阶结构。

## 人话版

**一句话**：换掉一条边谱半径不降，这样的树占所有树的多少？

对一棵树 T，记它的邻接谱半径为 ρ(T)，也就是最大特征值，粗略衡量“谱意义上的连通程度”。称 T 是 sustainable 的，如果对每条边 e，都能找到一条不属于 T 的边 f，使把 e 换成 f 后得到的树满足 ρ(T−e+f) ≥ ρ(T)；也就是说，任何一条边都不是“最后的关键”，总能换个地方补回甚至提高谱半径。问题分几层：完整刻画哪些树是 sustainable；sustainable 树在 n 个顶点的树中占多大比例（是否趋于 0）；以及换边序上的阶结构。已知最大度 Δ(T) ≥ n/2+1 的树一定不 sustainable。
