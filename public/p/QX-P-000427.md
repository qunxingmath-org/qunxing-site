# 平方数和集扩张（Green 问题 60/61，2条合一）

## 题面

平方数集 A 是否有 |A+A|≥|A|^{1+c}？反向：A+A 含前 n 个平方数时 |A|≥n^{1−o(1)}？（已知 ≥n^{2/3−o(1)}）

### 形式化表述

两问如上。

## 人话版

**一句话**：平方数内部的集合，和集一定会变大吗？反过来又能压多小？

这是两个方向相反的问题。正向：设 A 是平方数集合的一个子集，问它的和集 A+A={a+a'} 是否一定比 A 大不少，即是否存在常数 c>0 使 |A+A|≥|A|^{1+c}。若成立，说明平方数内部没有「近似子群」式的结构。反向：已知 A+A 包含了前 n 个平方数，问 A 至少要多大；目前只知道 |A|≥n^{2/3−o(1)} 这样一个下界，而天然猜测是接近 n^{1−o(1)} 的量级。两个问题都在考察平方数序列作为加法结构的刚性。

（AI 起草，未经人工审校）

## 原文摘录

> |A+A|≥|A|^{1+c} for A⊂{squares}? Converse: if A+A contains the first n squares, is |A|≥n^{1−o(1)}? (known ≥n^{2/3−o(1)})
>
> —— Ben Green, '100 open problems'（arXiv 讲义，2024；清单 2025-12 更新版仍列 open）

## 已知结果与进展

- Green 清单 60/61；已知 n^{2/3−o(1)}（Green 清单注记）。

## 边界与约定

- 边界：A⊂平方数全集；'前n个平方'。
- 独立验证建议：平方子集数值算|A+A|增长指数。
