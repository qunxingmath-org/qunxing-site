# batch_I I-129(提取2)：环面可嵌入图类（toroidal graphs）的禁用子式完全集是什么？（R–S 保证有限但证明无效

## 题面

环面可嵌入图类（toroidal graphs）的禁用子式完全集是什么？（R–S 保证有限但证明无效）

### 形式化表述

列出全部 ∉toroidal 的子式极小图；已知 >17000 个（Myrvold–Woodcock），且作者明示已知清单不太可能完备。

## 人话版

**一句话**：环面能画下的图，究竟被哪些“最小坏图”卡住？

一个图画在环面上可以做到边不交叉，就叫环面图。如果某个图 G 画不下，但删点删边、缩边之后能缩成另一个更小的、同样画不下的图 H，就说 G 的“坏”来自 H；这种子式极小的坏图叫禁用子式。Robertson–Seymour 定理保证这种现象的极小图只有有限多个，但证明只说“存在”，不给算法。已知清单已超过一万七千个，作者自己也说这份清单大概还不完整。要解决它，就得把所有极小坏图找齐并证明找齐了。

## 原文摘录

> Finding the set of forbidden minors for the class of toroidal graphs (finite graphs that can be embedded in the torus with no crossings). By the Robertson–Seymour theorem, this set is finite, but it is only partially known, and the finiteness proof is ineffective. A recent paper by Myrvold and Woodcock states, among other things, that the current list of known obstructions (over 17000 forbidden minors!) is unlikely to be complete.

## 已知结果与进展

Robertson–Seymour：子式封闭族有有限禁用集（非构造性）；Myrvold–Woodcock：当前 17000+ 禁用子式；评论（Chow/Towsner）：Σ₂ 型陈述+反证法结构 ⇒ 无法由 R–S 挖出上界（Henry Towsner 指对角化论证最优性）。
