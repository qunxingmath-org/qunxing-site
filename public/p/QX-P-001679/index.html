题面

Sumner 全能锦标赛猜想（大 n 已证；2026-08 上界 18n/7）

人话版

一句话：要装下所有 n 点有向树，锦标赛至少得多大？

锦标赛是完全图的一种定向：任意两点之间恰有一条有向边。有向树是把一棵树（连通无圈图）的每条边定向一次得到的图。Sumner 的全能锦标赛猜想通常表述为：2n−2 个顶点的锦标赛一定含有每一个 n 个顶点的有向树作为子图，即这样的锦标赛对全体 n 点有向树「万能」。难点在于有向树形状随 n 急剧增多，一条证明要同时对付所有形状。卡上注明 n 充分大时的情形已有结果，并记录了形如 18n/7 的上界，一般情形仍开放。
