# Fonollosa multiset-sum 最小模猜想（2026）

## 题面

对 n≥2 与 N<2^n−2^{⌊log₂n⌋}，不存在 n 个 mod N 剩余构成的集合满足 multiset-sum 条件（即 super-increasing 集 {1,3,7,15,…} 不能再缩小上界 N）。

### 形式化表述

定义（FC Arxiv/2607.08366/MinModulus.lean 核录）: 有限集 A⊂ℤ/Nℤ 称为 valid mod N，若从 A 中取 |A| 个元素构成的重数多重集（multiset m: A→ℕ, Σm(a)=|A|）中，"全 1 多重集"（每个元素恰取一次）是**唯一**其元素和 ≡0 (mod N) 的多重集。minModulus(n)=2^n−2^{⌊log₂n⌋}。
猜想（Fonollosa 2026 Conjecture 1, FC 类标 research open, question）: ∀n≥2, ∀N<minModulus(n): 不存在 valid mod N 的 n 元集 A。
（补全注记 2026-11-21，SOL验证Agent：原形式化的"multiset-sum 条件"未定义——已按 FC verbatim 补全（unique multiset-sum = 全 1 多重集唯一零和）。原路径更正: FC 现行文件 **Arxiv/2607.08366/MinModulus.lean**（论文 arXiv:2607.08366, J. A. R. Fonollosa "Minimum modulus for the unique multiset-sum problem"）；pool 译述的"super-increasing 集 {2^k−1} 极小性"为解释性表述，FC 的 Theorem A（@[category research solved]）证明 minModulus n 处存在 valid 集（存在性方向已证），猜想方向（更小 N 不存在）开放。另: PR #7057（2026-10-09 merged）为该文件添加 collision witnesses and bounds——近年活跃记录。）

## 人话版

**一句话**：模数小到某个界以下时，唯一零和的那套剩余元就不存在了吗？

设 A 是模 N 的剩余类里的一个 n 元集。从 A 里一共取 n 个元素（可以重复取，用重数 m: A→N 记录，要求各重数之和为 n），得到一种『多重集和』。若在所有这些多重集里，恰好只有『每个元素取一次』这一种的和 ≡ 0 (mod N)，就称 A 在模 N 下有效。卡片记 minModulus(n) = 2^n − 2^⌊log₂n⌋，猜想是：只要 N < minModulus(n)（n ≥ 2），就不存在有效的 n 元集。来源还记录 minModulus(n) 处存在有效集这一方向已被证明，所以剩下的是这个上界能不能再压小。

## 边界与约定

- 最小参数: n=2（minModulus=4−2=2; N<2 即 N=1——模 1 退化，注意 ZMod 1 的平凡性）；n=3（8−2=6; N=2..5 可全枚举 valid 性）；n=4（16−4=12; N=2..11 枚举 2^4 子集×多重集验证）。
- 退化情形: |A|≤1 平凡 valid（FC 注记，故 n≥2）；N=1（ZMod 1 平凡环——全部和为 0，全 1 多重集不唯一 → invalid ✓ 边界自洽）；A 中元素重复？A 为 Finset（集合无重复）——多重集抽取才产生重复。
- 约定依赖: multiset 定义（m: A→ℕ）；"零和"按 mod N；valid 的唯一性针对恰 |A| 个元素的重数多重集。
- 结构性锚点: collision witness（PR #7057 新增）= 对候选 N 找到非全 1 零和多重集即证明 invalid——反例方向的机器可验结构；Theorem A 的构造集是极小性的下界锚点。
- 建议独立验证方法（仅描述，不执行）: 对 n≤8 枚举全部 A⊂ZMod N 与全部重数多重集，独立核验 valid 性与 Conjecture 1（与 PR #7057 途径不同实现）；对声称反例（N<minModulus 的 valid 集）多重集穷举复核。
