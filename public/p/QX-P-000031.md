# WOWII 猜想 40：f(G) ≥ ⌈(p(G)+b(G)+1)/2⌉

## 题面

非平凡连通图的最大诱导森林阶 ≥ 顶点不相交路覆盖最小数与最大二部诱导子图阶之和加一的一半上取整。

### 形式化表述

∀连通图 G, |V|≥2: f(G) ≥ ⌈(p(G)+b(G)+1)/2⌉。

## 人话版

**一句话**：诱导森林、路覆盖、二部诱导子图，这三个数之间藏着一个不等式吗？

f(G) 是最大诱导森林的顶点数：删掉最少的点，让剩下的图不含圈。p(G) 是最小路覆盖数：用尽量少的点不交的路盖住所有顶点。b(G) 是最大二部诱导子图的顶点数：删最少的点使剩下的图不含奇圈。这三者都在刻画『图的圈结构有多复杂』，猜想把它们缝在一起：对任意顶点数至少 2 的连通图 G，都有 f(G) ≥ ⌈(p(G)+b(G)+1)/2⌉。要否定它只需要一个反例图，要证明它则需要对所有连通图给出统一论证。

（AI 起草，未经人工审校）

## 边界与约定

- 最小参数: K₂（等号基线）；小 n 全穷举（n≤10：三参数均可精确计算——f/b 经枚举诱导子图、p 经 DP/匹配）。
- 退化情形: 单点图域外（nontrivial 限定 |V|≥2）；p(G) 的单点路径计入与否（标准 path cover 允许单点路径——约定须声明，影响 p 值与 RHS）；二部图自身（b=n）。
- 约定依赖: 路覆盖=顶点不相交路并覆盖 V（路为子图，长度可为 0）；诱导森林/二部子图均为点导出；⌈⌉ 上取整。
- 结构性锚点: p(G)+b(G) 的组合直觉（路覆盖分解 + 二部诱导结构）与 f 的下界衔接；Albertson–Berman（f≥n/2）为同族强度参照——本条 RHS 与 n/2 的相对大小随 p+b 变化。
- 建议独立验证方法（仅描述，不执行）: nauty/geng 全穷举 n≤10 连通图，三参数独立精确计算（f、b 用子集枚举，p 用 DP），逐图验证不等式；对 p 的单点路径约定做两种读法分别验证；与 cb-0272/FC Lean 形式化交叉对照。
