题面

数列 a 自 8 起每次乘 1.5 下取整；b 按奇偶 +2/−1 计分。b 是否永远非负？（等价于某 6 态图灵机不停机）

形式化表述

∀n: b_n ≥ 0，其中 b_n 如上递推。等价: BB(6) 相关机器不停机。

人话版

一句话：这个每步乘 1.5 取整的数列，计分器会不会某一步跌到负数？

从 a₀=8 出发，每步取 a_{n+1}=⌊3a_n/2⌋，也就是乘 1.5 后向下取整。另有一个计分器 b₀=0：看当前的 a_n，若为偶数就把 b 加 2，若为奇数就减 1。问题问：b_n 是否恒不为负。因为 a 的奇偶由取整细节决定，看起来像随机的正负对消；一旦某个时刻 b 掉到 −1 以下，问题立刻被否定。输入指出这个问题等价于某台 6 状态图灵机永不停机，因此它属于忙海狸 BB(6) 一类极难判定的情形——不能靠跑有限步来证明。

（AI 起草，未经人工审校）

原文摘录

Antihydra: a_0=8, a_{n+1}=⌊3a_n/2⌋; b_{n+1}=b_n+2 if a_n even else b_n−1, b_0=0. Conjecture: b_n ≥ 0 for all n (equivalently, the associated 6-state Turing machine never halts). (bbchallenge BMO P2; conjecture-bench cb-0229)

已知结果与进展

部分和模拟未见 b 变负；bbchallenge 社区持续跟踪；理论工具缺位（3x/2 的 2-adic 结构）。

边界与约定

  • 边界：a_0=8起点；b计分规则奇偶分支。
  • 独立验证建议：大n部分和程序模拟（2-adic分块加速）推b_n最小值纪录。
