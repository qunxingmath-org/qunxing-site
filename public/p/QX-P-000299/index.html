题面

零框 surgery 得 #ⁿ(S¹×S²) 的链可经 handle-slide 化为零框 unlink。

形式化表述

如上。

人话版

一句话：surgery 之后只剩 S¹×S² 的链环，能不能靠几次滑动变成平凡链环？

链环是若干个互不相交的圈。零框 surgery 是沿链环的每条分支钻掉一圈管、再按“零框”的方式贴回去，从而把 S³ 改造成一个新三维流形。Property R 的经典形式说：若对某个结做零框 surgery 得到 S¹×S²，那么这个结只能是平凡结。广义版本处理 n 条分支：若得到的流形是 n 个 S¹×S² 的连通和，就断言这个链环可以只靠 handle-slide（把一条分支沿着另一条上的一段管滑过去）变成零框平凡链环。否定它要给出一个反例链环。

（AI 起草，未经人工审校）

原文摘录

Generalized Property R conjecture (Gompf): if 0-framed surgery on an n-component link L yields #ⁿ(S¹×S²), then L can be handle-slide transformed to the 0-framed unlink.

—— 提出: R. Gompf (1980s 推广)

登记: conjecture-bench cb-0196; arXiv:0908.2795

已知结果与进展

n=1（Property R 本体）已证；n≥2 开放。

边界与约定

  • 边界：0框surgery；handle-slide链不计交叉变化。
  • 独立验证建议：候选链的不变量计算（HF/Surgery判定#ⁿ(S¹×S²)）+ slide序列搜索。

相关进展与声称解决

  • - [PARTIAL] n=1 已证（Property R 本体）。
  • - [DISPUTED-变体] 同调版广义 Property R 已被证伪（arXiv:2603.05664, 2026-03）；原拓扑版（本条）仍开放。
