# Kalai 布尔函数噪声敏感性猜想

## 题面

阈值型布尔函数的噪声敏感性定量刻画（Kalai 猜想）。

## 人话版

**一句话**：阈值型布尔函数对随机翻动比特有多敏感，能被定量说清吗？

布尔函数把 {0,1}^n 上的输入映成 0 或 1，可以想成一次投票的结果。噪声敏感性衡量「随机翻动每个比特一小部分后，函数值跟着改变的概率」：概率大说明结果对细微扰动敏感，概率趋于 0 说明稳定。阈值函数指每个变量的权重固定、结果由加权和是否超过阈值决定。Kalai 的猜想要对这类函数给出噪声敏感性的定量刻画：何时敏感、何时稳定。题面只给了概括表述。
