# 16.21 SL_n(F) 中每元为 n 个 α-相似矩阵之积？

## 题面

α∈SL_n(F) 非中心、n>2。SL_n(F) 的每个非中心矩阵是否都是 n 个相似于 α 的矩阵之积？

### 形式化表述

见题面。

## 人话版

**一句话**：任意非中心矩阵，都能写成 n 个与给定 α 相似的矩阵之积吗？

取域 F 上的行列式为 1 的 n×n 矩阵群 SL_n(F)，设 n>2，α 是其中一个非中心矩阵（不与所有矩阵交换）。两个矩阵叫相似的，指存在可逆矩阵 P 使它们形如 P⁻¹MP。题目问：SL_n(F) 中每个非中心矩阵，是否都能写成恰好 n 个矩阵的乘积，而每个因子都相似于 α。相似类的选取不自由，所以这是很强的分解要求；α 只要求非中心，n>2 是题设给的范围。
