题面

a 的 n 次根可由固定长度模表达式计算（Shunia 猜想；mathlib4 PR #42050 由 LLM 生成提交，尚未通过社区审查）。

形式化表述

∃固定长度表达式模板 T: ∀a,n（适用范围见原论文）: T(a,n) = ⌊a^{1/n}⌋（或精确根，视原论文 6.1 的精确表述）。

人话版

一句话：求 a 的 n 次整数根，真能靠一个长度固定的模表达式算出来？

给定正整数 a 和 n，⌊a^{1/n}⌋ 是 a 的 n 次根向下取整。通常的算法要么依赖浮点、要么循环次数随规模增长。Shunia 在来源 6.1 提出的猜想断言：存在一个长度固定的表达式模板 T，形如先用模幂 (x+1)^{k+1} mod m 与 (x+1)^k mod m 作比再减一，使 T(a,n) 恰好给出 ⌊a^{1/n}⌋（或原论文意义上的精确根），并且模板本身的大小不随 a、n 增长。若成立，这就是一个『常数长度』的开方算法。要否定它，只需找出使该表达式给出错误结果的 (a,n)。

（AI 起草，未经人工审校）

原文摘录

The n-th root of a can be computed by the fixed-length modular expression ((x+1)^{k+1} mod m)/((x+1)^k mod m) − 1 (Shunia, open conjecture 6.1 of arXiv:2404.00332; mathlib4 PR #42050, LLM-generated, state=open draft)。

边界与约定

  • 最小参数: (a,n) 网格数值测试——公式在精确整数算术下对任意 (a,n,m) 可直接计算验证；k、m 选取规则的钉死是第一检查点。
  • 退化情形: a 为完全 n 次幂（精确根情形）vs 非幂（⌊a^{1/n}⌋ 情形——公式目标须区分）；a=0,1；n=1（公式应返回 a 自身——自检锚点）；m 的下界（m 不足时模运算截断破坏公式——原文条件所在）。
  • 约定依赖: 模乘除法的精确性（(x+1)^k mod m 的除法须为整除——公式成立前提）；"固定长度表达式"=与 a,n 无关的运算步数结构。
  • 结构性锚点: mathlib4 PR #42050 的 Lean 形式化（LLM 生成 draft）——审计其证明步骤等价于核对原论文论证；任何反例 (a,n) 直接证伪原论文证明。
  • 建议独立验证方法（仅描述，不执行）: 独立实现公式在 (a,n)∈[1,10^4]×[2,10] 网格测试（不同实现）；Lean 证明人工审计（PR diff 逐条）；对声称成立的公式核对 k/m 选取在边界 a 附近的行为。
