# Kourovka 14.90：P 为丰富度 a、类 c 的 p-群

## 题面

P 为丰富度 a、类 c 的 p-群。存在 t=t(a) 使 γi(G)=ζ_{c-i+1}(G)（i≥t）吗？

### 形式化表述

∃t(a): lower central meets upper central pattern for i≥t ?

## 人话版

**一句话**：丰富度固定后，下中心列最终会与上中心列逐项重合吗？

对有限 p-群 P，γ_i(P) 是下中心列第 i 项（反复取换位子），ζ_j(P) 是上中心列第 j 项（中心及其中心的原像）。幂零类 c 是下中心列变到 1 的位置；丰富度 a 是衡量「下中心列与上中心列相互靠近的程度」的量。问题问：是否存在只依赖 a 的 t=t(a)，使 i≥t 后总有 γ_i(G)=ζ_{c−i+1}(G)。原文说明 a=0 时 t=1（极大类群），a=1 时可取 t=3。

> Let P be a finite p-group of abundance a and nilpotency class c. Does there
> exist an integer t = t(a) such that γi(G) = ζc−i+1(G) for i ⩾t? This holds for a = 0
> with t = 1, since P has maximal class; it can be proved that for a = 1 one can take
> t = 3.
> G. Fern´andez–Alcober
