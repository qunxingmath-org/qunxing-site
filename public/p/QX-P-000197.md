# 无限 Sidon 集的密度下界（EP#39；原批次 A-005）

## 题面

是否存在无限 Sidon 集 A，使对所有 ε>0 有 |A∩[1,N]| ≫_ε N^{1/2−ε}？（Ruzsa 构造达 N^{1/2−o(1)}，指数上的 o(1) 发散。）

### 形式化表述

∃ 无限 Sidon 集 A: ∀ε>0, ∃c_ε>0, ∀N≥1: |A∩[1,N]| ≥ c_ε N^{1/2−ε}。

## 人话版

**一句话**：无穷 Sidon 集能有多大？能不能几乎追上 √N 这个天花板？

Sidon 集指这样的整数集合：所有形如 a+b（允许 a=b）的两数和，其表示方式至多一种——也就是任给一个和，最多只有一对 {a,b} 能凑出它，加性上最「不重复」。计数上有个硬天花板：若 A⊂[1,N] 有 |A| 个元素，两两之和约有 |A|²/2 个、都落在 [2,2N] 内，于是 |A|≲√N。题面记录的构造只做到 N^{1/2−o(1)}，比 √N 差一点趋于 0 的指数损失。问题问能否把这点损失压到任意小：对每个 ε>0 都有 |A∩[1,N]|≫_ε N^{1/2−ε} 对全体 N 成立。
