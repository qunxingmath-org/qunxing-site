题面

A_n={x: 存在 n 阶连通简单图恰有 x 棵生成树}。研究 |A_n| 增长率；猜想 |A_n|=ω(kⁿ) 对一切 k。

形式化表述

|A_n|=ω(kⁿ) ∀k∈N？（Sedláček：|A_n|=ω(n)；不知是否 ω(n²)）

人话版

一句话：n 个点的连通图能有多少种不同的生成树个数？这个数量增长多快？

生成树是连通图里恰好连起所有顶点、又不含圈的边子集；它的个数记作 τ(G)，是图的一个整数不变量。令 A_n 为所有“某个 n 阶连通简单图的生成树个数”组成的整数集合，也就是问 n 个点的图能取到多少种不同的 τ 值。已知 |A_n| 是 ω(n)（比 n 增长得快），但 |A_n| 是否也是 ω(n²) 并不清楚；题目提出的猜想更强：对每个固定的正整数 k，|A_n| 都比 kⁿ 增长得快。难点：τ 的取值受图的组合结构强约束，要造出足够多互不相同的值。

（AI 起草，未经人工审校）

原文摘录

This problem in some ways related to this post. Let $A_n$ be the set of all integers $x$ such that there exist a connected simple graph of order $n$ having precisely $x$ spanning trees. Study the growth rate of $|A_n|.$ The question was raised by J.Sedlacek in his paper entitled: On the number of spanning trees of finite graphs, Cas. Pro. Pest Mat., Vol. 94 (1969) 217-221.

提问: Jernej（2012-06-27），票数 8，无 accepted 答案（2026-11-20 API 核验）；标签: graph-theory,extremal-graph-theory,co.combinatorics,open-problems

已知结果与进展

提问者给出下界 |A_n|=ω(√n·e^{2π√(n/log n)/√3})（割点构造+素数分拆）；|A_n|≤n^{n−2}；n=12 时 |A_n|=739026332；Igor Pak（a100823）：块构造+带根森林生成函数乘积公式思路（未完成增长率证明）。
