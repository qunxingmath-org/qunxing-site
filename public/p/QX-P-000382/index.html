题面

每个 IΔ₀ 模是否都有末端扩张为 IΔ₀+Ω₁ 的模型？

形式化表述

∀M⊨IΔ₀ ∃N⊨IΔ₀+Ω₁: N 末端扩张 M（M 是 N 的初始段）。

人话版

一句话：每个有界算术模型，都能往上接一个满足 Ω₁ 的更大模型吗？

IΔ₀ 是把数学归纳法限制在「所有量词都有界」的公式上得到的算术理论，它是研究有界算术的起点。模型 M 的末端扩张 N 指 N 是 M 的扩张，且 M 的元素在 N 中仍排在所有新元素之前，即 M 是 N 的一个初始段。Ω₁ 是一条额外的公理模式：它要求每个有界公式只要在每个标准数上都成立，就处处成立，等价于「不存在非标准的可定义截断」。问题问：给定任意一个 IΔ₀ 模型，能否总把它末端扩张成满足 IΔ₀+Ω₁ 的模型。
