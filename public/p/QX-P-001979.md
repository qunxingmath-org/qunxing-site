# n 元格实现为有限群子群格？

## 题面

n 元格能否实现为有限群的子群格

## 人话版

**一句话**：随便画一个 n 元格，它一定是某个有限群的子群格吗？

把有限群 G 的全体子群按包含关系排起来：两个子群有交作为下确界，有它们生成的子群作为上确界，于是得到一个格，叫 G 的子群格。反过来问：给定一个有 n 个元素的抽象格，是否存在有限群，使它的子群格与这个格同构。答案不是永远为是——有一些格可以证明不可能来自任何有限群，所以真正的问题是要挑出可实现的那批格，或对每个 n 判定有还是没有实现。卡片只有一行主题，n 是否固定、格是否事先给定都未写明。
