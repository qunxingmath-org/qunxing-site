# 有理坐标十字空间齐次性

## 题面

有理坐标十字空间 (R×Q)∪(Q×R) 齐次性

## 人话版

**一句话**：平面上至少一个坐标是有理数的那些点，能被同胚搬来搬去吗？

拓扑空间 X 叫齐次，指对 X 中任意两点 x、y，都存在从 X 到自身的同胚 f 使 f(x)=y；也就是说从拓扑角度看，X 里的点没有「特殊」与「普通」之分。本卡的 X 取作 (ℝ×ℚ)∪(ℚ×ℝ)，作为 ℝ² 的子空间并带通常拓扑：它是全体「至少有一个坐标是有理数」的点。它有一些已知的漂亮性质，例如道路连通；要问的是有没有那样的同胚，即 X 是否齐次。要证否只需在 X 里找出两个点，说明它们不可能被任何自同胚互相送到。
