# 21.31 Byott 猜想：Hol(N) 中正则子群皆可解

## 题面

（Byott 猜想）N 有限可解群，则 Hol(N) 中任意正则子群也可解。（Hopf–Galois 结构与 skew brace 计数的核心。）

### 形式化表述

N 可解 ⇒ Hol(N) 的正则子群可解。

## 人话版

**一句话**：可解群的全形里，每个正则子群都必可解吗？

群 N 的全形 Hol(N) 是 N 的自同构群与 N 自身的平移共同生成的置换群，作用在 N 的元素上。子群 R≤Hol(N) 称为正则的，指它在 N 上传递且每个非单位元都没有不动点——等价于 |R|=|N| 且作用自由传递。Byott 猜想：若 N 是有限可解群，则 Hol(N) 中任何正则子群也可解。原文注明这条猜想与 Hopf–Galois 结构的计数、以及 skew brace 的分类密切相关，因为正则子群正是这些结构的组合对应物。
