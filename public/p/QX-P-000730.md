# Erdős #114：首一多项式 lemniscate 长度极大化

## 题面

在 n 次首一复多项式中，lemniscate |p(z)|=1 的长度由 p(z)=z^n−1 取得最大（Erdős #114）。

### 形式化表述

length{|p|=1} ≤ length{|z^n−1|=1} 对全体首一 n 次多项式。

## 人话版

**一句话**：在 |p(z)|=1 圈出的曲线里，哪条首一多项式的周长最长？

设 p 是 n 次首一复多项式（最高次项系数为 1）。集合 {z : |p(z)|=1} 是复平面上一条由若干闭曲线组成的图形，称为双纽线，可以量出它的总长度。Erdős 的问题是：在所有 n 次首一多项式中，这条曲线的总长度是否以 p(z)=z^n−1 时为最大。后者的双纽线是 n 段圆弧组成的对称图形，长度可显式算出。要解决它，需对所有首一多项式证明该长度上界。
