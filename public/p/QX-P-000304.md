# Cho–Choi–Park 独立支配猜想（偶最大度情形）

## 题面

无孤立点图（偶最大度 D）的独立支配数满足给定二次不等式。

### 形式化表述

∀G 无孤立点, 最大偶度 D: (D+2)² i(G) ≤ (D²+4) n。

## 人话版

**一句话**：没有孤立点的图，独立支配数能被最大度和点数一起压住吗？

支配集 D 是这样的顶点集：每个不在 D 里的顶点都与 D 中某个点相邻。若 D 内部还没有边（两两不相邻），就叫独立支配集；独立支配数 i(G) 是这种集合的最小规模。D 记最大度，即一个顶点最多能连几条边。Cho–Choi–Park 猜想针对没有孤立点、且最大度取偶数值 D 的图，断言 (D+2)²·i(G) ≤ (D²+4)·n，其中 n 是顶点数。这类不等式通常靠局部计数与贪婪选取支配点来证：先控制住每个点能“管到”的范围，再整体累加。

（AI 起草，未经人工审校）

## 原文摘录

> Cho–Choi–Park conjecture: if a graph has no isolated vertices and maximum even degree D, then (D+2)²·i(G) ≤ (D²+4)·n, where i(G) is the independent domination number. (cb-0205; odd case cb-0206)
>
> —— 提出: Y. Cho, Y. Choi, M. Park (2020/2021)
