# Erdos P66: does 1_A*1_A(n)/log n converge to a nonzero limit?

## 题面

Erdős猜不存在: 是否存在基A使1_A*1_A(n)/log n收敛到非零极限?

### 形式化表述

Erdős猜答案为否; 已知 |1_A*1_A(n)−log n| 不可为 o(√(log n)) (Erdős–Sárközy), Horváth (2007)改进常数。

## 人话版

**一句话**：表示函数除以 log n 真能收敛到一个非零常数吗？

r_A(n) 是 n 写成 A 中两元素之和（允许相同元素）的方法数。若每个足够大的 n 都有 r_A(n)>0，就称 A 为二阶加性基。随机取密集集合时，r_A(n) 大致随 log n 增长，于是有人问：是否存在一个基 A，使 r_A(n)/log n 收敛到某个正数？Erdős 猜测不存在。已有的结果给出 |r_A(n)−log n| 不能小于 √(log n) 量级这类限制，但离判定收敛性还很远。
