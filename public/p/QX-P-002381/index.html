Kourovka 20.84: can a nilpotent group of class 3 have a nontrivial fifth dimension subgroup?

题面

设 $G$ 是群，$\mathbb ZG$ 是整群环，$I(G)$ 是增广理想。定义第 $n$ 维数子群
$$
D_n(G)=G\cap\bigl(1+I(G)^n\bigr),
$$
其中把群元素嵌入群环的单位元。令 $\gamma_n(G)$ 为下中心列第 $n$ 项。

问： 是否存在幂零类恰为 $3$ 的群 $G$，使得
$$
D_5(G)\neq\{1\}?
$$

原文摘录

Does there exist a nilpotent group of class 3 with a non-trivial 5-th dimension subgroup?

—— E. Rips，Kourovka Notebook 20.84，2026，第170页

已知结果与进展

  • 基本包含关系。 对任意群有 $\gamma_n(G)\leq D_n(G)$。因此 class 3 时 $\gamma_4(G)=\gamma_5(G)=1$，但这不自动推出 $D_5(G)=1$；本题正是问这一包含能否严格。
  • 有限 metabelian 2-群有部分结果。 Gupta 证明：若 $G/\gamma_2(G)$ 至多为两个循环群的直和，则 $D_5(G)=\gamma_5(G)$；并对 $G/\gamma_2(G)=C_1\times\cdots\times C_n$、前 $n-1$ 个 $C_i$ 阶为 $2$、最后一个阶至少 $4$ 的情形证明同一结论。[Theorems 2–3，PDF第2–5页](https://doi.org/10.1155/2016/5342926)
  • class 3 的已知 2-群例方向相反。 Gupta 在 §3 给出两个 class 3 的 2-群，满足 $D_4(G)\neq1$ 而 $D_5(G)=1$。这说明第 4 与第 5 维数子群的行为不同，但没有给出本题的肯定例。[§3.1–3.2，第5–7页](https://doi.org/10.1155/2016/5342926)
  • 模 $p$ Jennings 系列不是同一对象。 GAP 的 JenningsSeries 递推 $$ J_1=G,\qquad J_{i+1}=[J_i,G]\,J_{\lfloor i/p\rfloor+1}^{\,p} $$ 用于有限 $p$ 群的模 $p$ 维数与 Loewy 因子，不能未经论证等同于整数 $D_n(G)$。
  • 一般问题仍开放。 截至检索日未找到 class 3 且 $D_5\neq1$ 的群，也没有证明所有 class 3 群都有 $D_5=1$。

边界与约定

  • 维数子群在整群环 $\mathbb ZG$ 中定义，使用增广理想的整数幂。
  • 原题没有有限性、无挠性或 $p$-群限制；若只研究有限 2-群，应明确标为特例。
  • $\gamma_n(G)\leq D_n(G)$ 是包含关系，不是一般等式。
  • “class 3”指幂零类恰为 3，不是小于等于 3。
  • $D_4\neq1$ 而 $D_5=1$ 的例不能回答本题；需要 $D_5$ 本身非平凡。
  • Lazard 对应的类 $<p$ 条件在 class 3 时只覆盖 $p\geq5$，对 $p=2,3$ 不能直接套用。

相关进展与声称解决

  • [PARTIAL] 有限 metabelian 2-群的若干生成元/阿贝尔化条件下 $D_5=\gamma_5$。
  • [PARTIAL] class 3 的 2-群中 $D_4\neq1$、$D_5=1$ 的明确例子。
  • [RELATED] Jennings 系列、Frattini 子群、Lazard 对应与模 $p$ 维数子群是相关但不同的工具。
  • [OPEN] 一般 class 3 群的非平凡 $D_5$ 正例或全称否定，截至2026-11-25未检出。
