题面

任意 n 边树 T，完全图 K_{2n+1} 可分解为 2n+1 个 T 的拷贝。

形式化表述

∀n≥1, ∀n 边树 T: K_{2n+1} 有 T-分解。

人话版

一句话：随便一棵 n 条边的树，都能把 K₂ₙ₊₁ 的边不多不少地铺满吗？

完全图 K_{2n+1} 有 (2n+1)n 条边，恰好是一个 n 边树的边数的 2n+1 倍。分解的意思是把 K_{2n+1} 的边集拆成若干块，每块作为子图都同构于给定的树 T，块与块之间不共用边、也不漏边。Ringel 猜想断言：不管挑哪棵 n 边树（路径、星形、随便什么形状），这种拆法都存在。它的形状无关性才是难点：证明必须对“所有树”一次性成立，而不能逐棵处理。输入注明 n 充分大时已有结果，对全部 n 仍开放。

（AI 起草，未经人工审校）

原文摘录

Ringel's conjecture (1963): every tree T with n edges decomposes K_{2n+1} into 2n+1 copies of T. (Proved for sufficiently large n by Keevash; all n open)

—— 提出: G. Ringel (1963)

进展: Keevash arXiv:2001.02665 (2020)

已知结果与进展

充分大 n 已证（Keevash 2020, arXiv:2001.02665）；一般 n（尤其中小 n）开放。

边界与约定

  • 边界：K_{2n+1}顶点数；T为任意n边树。
  • 独立验证建议：小n（≤10）穷举所有n边树的分解存在性（程序）。

相关进展与声称解决

  • - [PARTIAL] 大 n 已证（Keevash）；Ringel–Wilson 一般设计理论线。
