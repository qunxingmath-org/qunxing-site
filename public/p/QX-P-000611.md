# （来源 C-018）n 个平面点两两距离 ≤1 时，最大化最小点间距（max-min 装填），求参考与一般 n 的精确值/界

## 题面

n 个平面点两两距离 ≤1 时，最大化最小点间距（max-min 装填），求参考与一般 n 的精确值/界

补充：回答（orangeskid, 2026-03-02, 2票）：推荐两本俄文教材（元素性处理此类问题），自述未能找到完全相同的问题；Added：可重述为最大化 min/max 距离比。评论（user1728960 2026-03-04）：可粗略重述为 packing n 个单位圆最小化凸包宽度，但无固定形状具有该性质。

### 形式化表述

求 d(n) = max_{A_1..A_n} min_{i<j} |A_i A_j|，约束 max_{i<j} |A_i A_j| ≤ 1。等价于：直径 1 的点集中最大化最小间距（与等半径圆 packing 对偶：固定 r=最小间距/2 则是 n 个半径 r 圆的 packing 使凸包直径≤1）。求 d(n) 的精确值或已知文献。

## 人话版

**一句话**：直径不超过 1 的 n 个点，最近的两个能离得多远？

在平面上放 n 个点，要求任意两点的距离都不超过 1（直径至多为 1），同时希望最近的那一对尽量远。记 d(n) 为在所有满足直径约束的 n 点配置中，「最近两点距离」能取到的最大值，也就是最优的「均摊最稀」。它可以翻译成圆装填：以最小间距的一半为半径在每点放一个圆，这些圆互不重叠，且整体直径受限。输入提到可把目标改写成最大化最小距离与最大距离之比，并指出这类问题在文献中只找到零散处理。
