题面

当 2^n 与 3^m 不相邻（差 ≠1）时，二者之间是否必含素数？

形式化表述

∀m,n≥1 [|3^m − 2^n| ≥ 2 → ∃素数 p 介于 2^n 与 3^m 之间]。

人话版

一句话：2ⁿ 和 3ᵐ 之间只要差得不止 1，就一定有素数吗？

Bertrand 假设说在 n 与 2n 之间总有素数，可以看作相邻量级之间必有素数的指数版本。这里把两个量级换成 2 的幂与 3 的幂：对正整数 m、n，若 |3^m−2^n|≥2（也就是两个数不相邻），问 2^n 与 3^m 之间是否必定存在素数。两者大小关系不定，需要分情况讨论；它们又可以挨得很近（如 8 与 9），此时整数区间里一个数都没有，所以差为 1 的情形必须排除，这也说明条件不能放宽。

  • Baker 线型下界 |3^m−2^n| ≫ 2^n/n^C 与素数间隔 p_{k+1}−p_k ≤ p_k^{0.525}（BHP 2001）⇒ 对充分大 min(m,n) 可证；中小情形可计算枚举——"证明+计算"组合尚无完整文献。
