# 两组点间相异距离计数（EP#661；原批次 A-030）

## 题面

对充分大的 n，是否存在平面上两组各 n 个点，使跨组不同距离 d(x_i,y_j) 的个数为 o(n/√(log n))？

### 形式化表述

∀大 n，∃ X={x_1..x_n}, Y={y_1..y_n}⊂R²: |{d(x,y): x∈X, y∈Y}| = o(n/√(log n))。

## 人话版

**一句话**：两组各 n 个点之间，能凑出的不同距离可以远少于 n 个吗？

取平面上两组点 X={x₁,…,x_n} 与 Y={y₁,…,y_n}，看这 n² 个跨组距离 d(x_i,y_j) 里一共出现多少种不同的数值。问题问：对充分大的 n，能否设计 X 和 Y，使不同距离的个数只有 o(n/√(log n))，也就是比 n 还少一个 √(log n) 因子以上。单个点集内部的相异距离问题是同一类问题的经典版本，下界大约在 n/√(log n) 这个尺度；这里只统计两组之间、不统计组内的距离，允许的结构更自由，因此有可能做得更稀疏。

（AI 起草，未经人工审校）

## 已知结果与进展

- 全局版下界 n/log n（Guth–Katz）；双集版上界构造开放（题页记录）。

## 边界与约定

- 边界：X=Y退化为全局版；点允许重合与否需注明（原文some points未言互异）。
- 独立验证建议：候选构造（如格点/曲面平移对）程序计数相异距离。
