题面

对每个实数 ξ 与素数 p，inf_{q≥1} q·‖qξ‖·|q|_p = 0。

形式化表述

如上。

人话版

一句话：乘上 p-进因子后，q‖qξ‖|q|_p 还能任意接近 0 吗？

‖x‖ 表示 x 到最近整数的距离；|q|_p 是 p-进绝对值，等于 p^(−v)，其中 p^v 是整除 q 的 p 的最高次幂，所以 q 越被 p 整除，这个因子越小。经典 Littlewood 猜想说 inf_{q≥1} q‖qξ‖‖qα‖ = 0 对所有实数 ξ、α 成立；本题只留一个实参数 ξ，把第二个因子换成 |q|_p。断言：对每个实数 ξ 与每个素数 p，下确界都是 0，即总能找到 q 让三者乘积任意小。

（AI 起草，未经人工审校）
