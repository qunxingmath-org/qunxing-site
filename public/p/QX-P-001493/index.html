题面

Fibonacci 半群 <L,R|LRR=RLL> 上的 Bernoulli 游走熵 H(p) 是否单峰且在 p=1/2 取最大？对其它有对称性的有限生成半群呢？

形式化表述

H(p) := lim (1/n)H(游走 n 步分布) 是否关于 p 在 [0,1] 单峰、峰在 1/2？

人话版

一句话：在这个只有一条关系的半群里掷硬币，熵的最大值一定在中点吗？

半群 <L,R | LRR=RLL> 由两个生成元 L、R 和一条关系 LRR=RLL 确定，因为它和 Fibonacci 数列有关，常叫 Fibonacci 半群。在上面做一个 Bernoulli 游走：每步以概率 p 写 R、以概率 1−p 写 L，于是走 n 步得到一个长度 n 的字的分布。把所得字的经验熵除以 n，取 n 趋于无穷的极限，得到熵率 H(p)。问题问：H(p) 作为 p 的函数是否单峰，并在 p=1/2 处取到最大值？对自由半群（两个生成元无关系），H(p) 就是经典二元熵，显然在 1/2 处取最大。加了关系之后这种对称性是否还保持，正是问题所在。

原文摘录

Consider the Fibonacci semi-group $<L,R|LRR=RLL>$ with a Bernoulli walk $P(R)=p, P(L)=1-p$. Is the entropy $H(p)$ an unimodal function with maximum at p=0.5? Is this true for all finitely generated semi-groups (with some symmetries)? For the free semi-group $<L,R>$ (the Shift space) it is well known and easy to prove that $H(p)=-(plog(p)+(1-p)log(1-p))$.

已知结果与进展

自由半群：H(p)=−p log p−(1−p)log(1−p)（经典）；有限/交换（Pascal）半群：H≡0（user6976 评论澄清）；一般增长率为正的半群 H(p) 上界为指数增长率；Fibonacci 半群 H(p) 无任何分析结果（OP 自述连单峰性都无证明）。
