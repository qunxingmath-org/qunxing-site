Which n allow a triangle to be dissected into n congruent triangles?

题面

求所有正整数 n：存在一个三角形可被剖分为 n 个彼此全等的三角形。已知若干可行值与不可行值（7、11 不可行等）；19 是否可行未知。

形式化表述

刻画 S = { n∈N : ∃三角形 T 可剖分为 n 个两两全等的三角形 }。（已知部分成员与非成员；19∈S? 未决。）

人话版

一句话：哪些 n 能让一个三角形正好切成 n 个一模一样的三角形？

把一块三角形用直线段剖分成 n 个小三角形，要求这 n 个小三角形两两全等，也就是能通过平移、旋转或翻转互相重合；大三角形的形状可以自己挑选。求所有可行的正整数 n 构成的集合 S。这个过程叫「剖分」，n=1 时取原来的三角形即可。已知有些 n 可行、有些不可行（如 7、11 不行），而 19 是否可行还没有定论。难点在于 n 大时要设计出整体自相似又不留下空隙的摆法，而且可行性随 n 变化并不单调。

（AI 起草，未经人工审校）

已知结果与进展

  • 采集记录：EP#633（相关分类）2026 年已解决；7、11 不可行；19 未知。
  • Laczkovich–Szekeres 等经典刻画（直角/特殊情形）为背景。

边界与约定

  • 边界：n=1平凡；'剖分'需无重叠无缝隙；全等含镜像约定。
  • 独立验证建议：小n情形可几何+代数（角度方程有理性）检验；19∈S?以坐标构造或角度约束搜索。
