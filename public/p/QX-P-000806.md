# OEIS A063880：σ(n)=2·usigma(n) ⇒ n≡108 (mod 216)

## 题面

每个满足 σ(n)=2·usigma(n)（usigma=单位因子和）的正整数 n 都满足 n≡108 (mod 216)。

### 形式化表述

σ(n)=2·usigma(n) ⇒ n ≡ 108 (mod 216)。

## 人话版

**一句话**：σ(n)=2·usigma(n) 的解，真会全部落进模 216 的单一剩余类？

σ(n) 是 n 的所有正因数之和。单位因数指满足 gcd(d, n/d)=1 的因数 d，也就是每个素因子的幂要么整个取、要么完全不取；把这些单位因数加起来记作 usigma(n)。题目断言：只要正整数 n 满足 σ(n)=2·usigma(n)，就一定有 n≡108 (mod 216)。这个结论很强：108=4·27，说明 n 必须被 4 整除、且恰好带上一个 3 的幂这样的约束。要证明它，就得从等式出发，逐素数比较两边指数，把 n 的素因子分解形式完全锁定。
