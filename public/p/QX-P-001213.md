# Erdős–Oler猜想（三角形内装圆）

## 题面

Oler (1961)不等式给出一般下界；Erdős–Oler猜想断言三角形数处等号取到（阶梯函数在三角形数处平坦）。三角形内装n圆的精确值表是活跃计算对象。

### 形式化表述

对三角形数n: A(n)=A(n−1)（最小三角形边长函数）。

## 人话版

**一句话**：装到三角形数个圆时，再多装一个真的不需要更大的三角形吗？

记 A(n) 为「能容纳 n 个单位圆（半径 1、两两不重叠）的最小等边三角形边长」。A(n) 随 n 递增，是一个阶梯函数。Oler 在 1961 年用格点方法给出了 A(n) 的一个下界不等式。Erdős 与 Oler 猜想：当 n 是三角形数（1、3、6、10、…，即 k(k+1)/2）时，这个下界可以取到，表现为阶梯函数在这些 n 处是平的——也就是装到 n 个圆时，所需的三角形并不比装 n−1 个更大。要证明它需要给出达到下界的显式排布；小 n 的精确值是目前活跃的计算对象。
