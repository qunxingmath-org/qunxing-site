# 补连通非凸集闭凸包线段面

## 题面

补连通非凸集闭凸包必含线段面？

## 题面草稿（AI 起草，待核）

设 $X$ 是 Hilbert 空间，$C\subseteq X$ 是闭的、有界的、非凸的子集，并且补集 $X\setminus C$ 连通。问：$\operatorname{conv} C$（$C$ 的凸包）的边界是否必定含有线段？（歧义：原文的「line segment」是否指非退化线段未作说明，通常理解为至少含两个不同点的线段。）

## 人话版

**一句话**：补集连通的非凸闭集，它的凸包边界一定含一条线段吗？

在 Hilbert 空间 X 里取一个闭的、有界的、非凸的子集 C，并要求 X∖C（C 外面那部分）连通，也就是 C 不把空间切成两块。conv C 指包含 C 的最小凸集，它的边界是凸包的外壳。题目问：这层外壳上是否一定含有一条线段（至少两个不同点连成的一段）。难点在于条件很弱：C 可以是奇形怪状的闭集；原文提示的思路是用 Bishop–Phelps 定理说明支撑点在边界上稠密，但由此走到「边界含线段」还有距离。
