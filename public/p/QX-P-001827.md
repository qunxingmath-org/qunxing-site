# 自指标准差递推渐近

## 题面

自指标准差递推 x_{n+1}=Stdev 的渐近

## 人话版

**一句话**：每一步都取前面所有项的标准差，这样长出来的数列涨多快？

设 x_1,x_2,… 是一列实数，规定 x_{n+1} 等于 x_1,…,x_n 的标准差，也就是这 n 个数偏离平均值的程度。每一项由它前面所有项决定，这类递推叫自指递推。题目问 n 很大时 x_n 的增长阶：是像 c√n 那样增长，还是别的幂次或对数速度，常数 c 又是多少。可行的路子是先数值计算猜出形式，再把递推近似成关于经验分布的微分方程去验证。
