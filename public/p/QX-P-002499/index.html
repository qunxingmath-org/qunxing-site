If G times Z is of type F, must G be of type F?

题面

设 $G$ 为离散群。回忆：

  • $G$ 为 type $F_n$，若存在 $K(G,1)$，其 $n$-骨架只有有限多个胞腔；
  • $G$ 为 type $F_\infty$，若存在 $K(G,1)$，每个维数的骨架都只有有限多个胞腔，但总维数可以无限；
  • $G$ 为 type $F$，若存在有限 CW 复形 $K(G,1)$。

问题（Zaremsky，Section 1，Problem 21）：是否对每个离散群 $G$，都有
$$
G\times\mathbb Z\text{ 为 type }F
\quad\Longrightarrow\quad
G\text{ 为 type }F?
$$

题源指出，这等价于如下有限维有限性问题：若 $G$ 为 type $F_\infty$ 且
$$
\operatorname{cd}_{\mathbb Z}(G)<\infty,
$$
是否必有 $G$ 为 type $F$？反向的乘积构造 $K(G,1)\times S^1$ 在 $G$ 已为 type $F$ 时显然成立；困难的是从直积的有限分类空间恢复因子的有限分类空间。

原文摘录

In view of (a), one might wonder whether all torsion-free groups of type $F_\infty$ are in fact of type $F$. This is not the case. The first counterexample was given by Brown and Geoghegan [4]. That example, however, is infinite dimensional. So one can still ask whether every finite-dimensional group of type $F_\infty$ is of type $F$.

—— Kenneth S. Brown，*Cohomology of Groups*，2008，§2.2 Remarks 2.7(b)，第11页，[作者PDF](https://pi.math.cornell.edu/~kbrown/papers/cohomology_hangzhou.pdf)

已知结果与进展

  • $F_\infty$ 单独不推出 $F$：[Brown–Geoghegan 1984](https://pi.math.cornell.edu/~kbrown/scan/1984.0077.pdf) 证明 Thompson 群 $F$ 是无挠、无限维的 $FP_\infty$ 群，却不是有限维的 $FP$ 群。这是“有限维条件不可删”的经典反例，不是本题有限维情形的反例。
  • 有限维 + $FP_\infty$ 已能给出有限投射消解：Brown 2008 Remarks 2.12(a) 说明，逐维用有限生成模构造消解，最后终止的核是投射模，因此得到有限长度、有限生成投射消解，即 type $FP$。这一步已经解决。
  • 剩余障碍是投射模未必自由：Remarks 2.12(b) 指出，抵达投射核 $K$ 时不能保证 $K$ 自由；有限自由消解存在当且仅当 $K$ 稳定自由。于是问题与 $\mathbb ZG$-模的稳定自由性相连。
  • $F$ 与 $FL$ 的关系已知：Brown 指出 $G$ 为 type $F$ 当且仅当 $G$ 有限表现且具有有限长度、有限秩自由消解（type $FL$）。因此“有限投射”到“有限自由”的跨越正是关键缺口。
  • 低维与常见群类不提供全称解：$\operatorname{cd}_{\mathbb Z}G=1$ 的无挠群是自由群；有限生成时是 type $F$。自由群、无挠算术群及许多几何群类都有有限分类空间，但任意外群仍未被统一覆盖。
  • 上同调限制映射有部分定理：[Meir 2010](https://arxiv.org/html/0911.3267v2) Proposition 3.1 证明，$FP_\infty$ 且具有 virtual finite cohomological dimension 的群，其上同调环为 Noetherian 环，有限指标子群的限制核有限生成。这是上同调环有限性，不产生有限 $K(G,1)$。
  • 当前缺口：截至本次基础查新，没有找到有限维 $F_\infty$ 群必为 $F$ 的全称证明，也没有找到 $G\times\mathbb Z$ 为 $F$ 而 $G$ 不为 $F$ 的反例。Zaremsky 2026-10-08 官方清单仍保留该问题。

边界与约定

  • 离散群是默认范畴：不把拓扑群、概形或层范畴的有限性条件混入；题面中的 $\mathbb Z$ 是加法无限循环群。
  • $F$、$F_\infty$、$FP$、$FP_\infty$、$FL$ 不可互换：有限 $K(G,1)$、逐维有限分类空间、有限投射消解、逐维有限生成投射消解、有限自由消解是不同条件。
  • 有限维假设针对积分上同调维数：$\operatorname{cd}_{\mathbb Z}(G)<\infty$ 自动排除非平凡有限子群；virtual finite cd 只要求某个有限指标子群有限维，是更弱的假设。
  • 直积不是悬挂：$G\times\mathbb Z$ 与 mapping torus $G\rtimes_\varphi\mathbb Z$ 不同。后者允许非平凡单值化，本题固定平凡作用。
  • 不能从 $F_\infty$ 反例直接否定有限维版本：Thompson 群的 $\operatorname{cd}_{\mathbb Z}$ 为无穷，正好落在题设之外。
  • $FP$ 不自动是 $FL$：有限生成投射模可能非自由；只证明消解在某一维终止不足以得到有限 $K(G,1)$。
  • 有限表现 + $FP_\infty$ 也不自动是 $F$：Brown 将其列为 Question 2.9；这说明不能仅凭有限表现和逐维同调有限性收尾。
  • 等价表述的证明责任：本卡采用 Zaremsky 的等价表述组织验收，但若只研究其中一个有限维 $F_\infty$ 版本，必须明确它如何覆盖直积版本，不能把未写出的推导当作已知。

相关进展与声称解决

  • [KNOWN-COUNTEREXAMPLE-INFINITE-CD] Brown–Geoghegan 1984：无挠 $FP_\infty$ 而非常规有限维 $FP$ 的群存在。
  • [KNOWN-FINITE-PROJECTIVE] Brown 2008：$FP_\infty$ + 有限维 ⇒ $FP$。
  • [KNOWN-F-FFL] $F$ ⇔ 有限表现 + $FL$；困难集中在有限自由消解。
  • [PARTIAL-LOW-DIMENSION] $\operatorname{cd}_{\mathbb Z}G=1$ 时无挠 $G$ 自由，有限生成情形已解决。
  • [PARTIAL-COHOMOLOGY-RING] Meir 2010：$FP_\infty$ + virtual finite cd ⇒ 上同调环 Noetherian，限制核有限生成。
  • [OPEN-FINITE-DIMENSION] 有限维 $F_\infty$ 群是否必为 $F$，仍无全称证明或反例。
  • [OPEN-DIRECT-PRODUCT] $G\times\mathbb Z$ 为 $F$ 是否推出 $G$ 为 $F$，仍开放。
  • [NO-CLAIM-FOUND] 本次未发现 2025–2026 年针对本命题的 AI 全称证明或确认反例。通用检索出现的“universal group of type F∞ machine-checked”是另一构造/形式化主题，不能当作本蕴含命题已解；formal-conjectures 代码搜索需登录。
