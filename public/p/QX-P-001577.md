# 21.42 存在不自相似的 T(3,3)-群吗

## 题面

T_{d,c}=d 生成、无挠幂零类 c 的群类。已知 T_{d,2} 全自相似、T(2,3) 自相似、存在不自相似的 T(4,3)（Berlatto–Santos 2025 arXiv:2509.16947）。存在不自相似的 T(3,3)-群吗？

### 形式化表述

∃不自相似 T(3,3)-群？

## 人话版

**一句话**：三个生成元、无挠、幂零类 3 的群里，会有一个不自相似吗？

T_{d,c} 记 d 个生成元、无挠、幂零类为 c 的群构成的类；自相似指能忠实态闭地作用在正则单根树的自动机上。原文给出的已知情况是：T_{d,2}（幂零类 2）的群对一切 d 都自相似；T_{2,3}（幂零类 3、2 个生成元）也自相似；而 T_{4,3} 中存在不自相似的群（Berlatto 与 Santos，2025）。题目问夹在中间的 T_{3,3}：是否存在不自相似的三生成无挠幂零类 3 群？
