# 18.65 Guralnick–Malle：[C,C] 皆 p-元 ⇒ C⊆O_p(G)（p≠5）

## 题面

猜想：p≠5，C 为 p-元共轭类，若任意 c,d∈C 有 [c,d] 为 p-元，则 C⊆O_p(G)。（Guralnick–Malle Thm 1.4 为更强的 CC⁻¹ 版本；2024-25 Parker/Tong-Viet/Guralnick 变体活跃。）

## 人话版

**一句话**：一个 p-类里任意两个元素的交换子都是 p-元，能推出什么？

取素数 p≠5。G 是有限群，C 是 G 中的一个共轭类，且 C 的元素都是 p-元（阶为 p 的幂）。O_p(G) 是 G 的最大正规 p-子群。猜想说：若对任意 c,d∈C，交换子 [c,d] 也是 p-元，则整个 C 必落在 O_p(G) 里。也就是说，这样的类只能住在正规 p-子群中。排除 p=5 是因为那里存在已知的例外构型。输入提到同作者有一个更强的 CC⁻¹ 形式定理，以及近年的相关变体工作。
