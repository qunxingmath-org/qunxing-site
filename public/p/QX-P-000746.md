# Graham–Sloane 调和树标号猜想

## 题面

每个 n 顶点树都有到 Z_{n−1} 的顶点标号（恰一个标号用两次）使边和模 n−1 两两互异（Graham–Sloane 调和标号猜想）。

### 形式化表述

∀ 树 T，∃ harmonious labeling mod (n−1)。

## 人话版

**一句话**：给树的顶点按模 n−1 编号，能让所有边和互不相同吗？

设 T 是有 n 个顶点的树。调和标号指给每个顶点指定一个 Z_{n−1} 中的标号（模 n−1 的整数），要求恰好有一个标号被用两次、其余各用一次；并且对每条边取两端标号之和（模 n−1），使 n−1 条边得到的和两两不同。Graham 与 Sloane 猜想每个树都存在这样的标号。原始输入标明该问题已部分解决。要解决它，需对所有树给出显式构造或存在性证明。
