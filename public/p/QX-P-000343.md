# Is every Scott set the standard system of a model of PA (uncountable case)?

## 题面

Scott问题：是否每个Scott set（对Δ₀₁可定义封闭+满足弱König引理的实数族）都是某个PA模型的标准系统？可数情形已解决（Scott定理）；不可数情形开放。

### 形式化表述

判定 ZFC ⊢ '每个Scott set 𝒳 是某模型 M⊨PA 的标准系统 SS(M)'（任意基数𝒳）。已知：可数✓；PFA下proper+算术封闭的ℵ₁ Scott set✓（Gitman）。

## 人话版

**一句话**：不可数的 Scott 集，也一定是某个算术模型的标准系统吗？

把自然数的子集看成实数。一族实数 𝒳 若对 Δ⁰₁ 可定义封闭、并满足弱 König 引理（无穷二叉树上若有任意长的有限路径，就有一条无穷路径），就叫 Scott set。对皮亚诺算术（PA）的模型 M，能被 M 中的元素「编码」的实数全体称为标准系统 SS(M)，它总是 Scott set。Scott 定理证明：可数 Scott set 都能反过来实现为某个 PA 模型的标准系统。问题问不可数情形是否同样成立；在 PFA 一类力迫公理下，性质良好的 ℵ₁ 情形已有结论。
