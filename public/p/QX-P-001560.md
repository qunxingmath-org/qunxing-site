# 20.100 无 2..n+1 阶元的群中 n 元集的排列邻项幂互异

## 题面

（Sun）G 不含阶在 {2,…,n+1} 中的元素，则任意 |A|=n 的子集可排列为 a₁,…,a_n 使 a₁（=a₁¹）, a₂², …, a_nⁿ 两两不同（第 i 元取 i 次幂）？n≤3 已证。〔余量波2修正留痕 2026-11-21：原译误将 a_i^i 幂次写成 a_i²（全部平方），按原文改写；原引文未动。〕

### 形式化表述

[无{2..n+1}阶元G, |A|=n] ∃排列: a₁, a₂², …, a_nⁿ 两两互异。〔余量波2修正留痕 2026-11-21：按原文幂次改写。〕

## 人话版

**一句话**：群里挑 n 个元素，总能排一排让各自不同次幂两两互异吗？

设 n 为正整数，G 是不含 2、3、…、n+1 阶元素的群。取任意 n 元子集 A⊆G，问能否把 A 里的元素排成一列 a₁,a₂,…,aₙ，使 a₁（即 a₁ 的 1 次幂）、a₂²、a₃³、…、aₙⁿ 这 n 个元素两两不同？注意第 i 个元素取的是 i 次幂。原文注明该猜想对 n≤3 已证；条件「不含 2 到 n+1 阶元素」正是为了避免 aᵢⁱ 退化成低次幂而撞车。
