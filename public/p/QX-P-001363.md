# 2 的幂的十进制无零数字（CRUX 410）

## 题面

2^n 的十进制表示不含数字 0 的 n 是否只有有限多个？（"86 猜想"：2^86 是最后一个。）

### 形式化表述

#{n≥1: 2^n 的十进制不含 '0'} < ∞？

## 人话版

**一句话**：2 的幂越写越长，什么时候十进位里就再也躲不开 0 了？

考察 2 的十进制写法：2, 4, 8, 16, 32, 64, 128, 256, 512, 1024,… 其中 1024 含 0，但 2⁸⁶ 写成十进制仍然没有数字 0。问题问：这种不含 0 的 2 的幂是否只有有限多个。随着指数增大，数字位数按 n·log₁₀2 增长，而某一位是 0 的概率随位数增加迅速变大，因此在概率上期望只有有限多个；但这类数字问题没有有效工具，严格的有限性至今没有被证明。

## 已知结果与进展

- 2^86 为已知最大无零幂（Khovanova 博客 2011；Sloane Numberphile "Problems with Powers of Two"）；启发式 (9/10)^d 衰减；底 3 类似（69..20000 无零）。无定理。
