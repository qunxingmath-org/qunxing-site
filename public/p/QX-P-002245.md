# 与 n 互素有限表同余于连续素数？

## 题面

与 n 互素的有限表可否同余于连续素数

## 人话版

**一句话**：一组两两互素的模数,能不能恰好按某一段连续素数来取余数？

「与 n 互素的有限表」指若干个模数 n₁,…,n_k,它们两两互素(最好还与外层那个 n 互素)。每个模数配一个余数,就得到一组同余条件;由孙子定理,这组条件在模它们的乘积下唯一确定一个剩余类。问题问:能否选出一组两两互素的模数与余数,使解恰好与某一段连续素数同余(即解模 p 的余数按顺序对上连续素数)。输入把这张卡标为「部分解决」,即已有一部分情形定案。
