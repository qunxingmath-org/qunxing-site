# Do all staged tree models have toric structure?

## 题面

staged tree模型（离散统计模型，有根有向树+同色节点条件概率相同）的理想是否均为toric理想？原文识别出具有toric理想的类并研究其代数几何，全类判定开放。

### 形式化表述

对每个staged tree T，判定其模型理想 I_T ⊂ K[p_e] 是否为toric理想（素理想+参数化生成）。已知若干类toric（原文+后续'不toric的Bayesian网络'文献有反例类）。

## 人话版

**一句话**：一棵带颜色的树给出的统计模型，背后是不是都藏着 toric 结构？

staged tree 模型是离散统计模型的一种：把随机过程画成一棵有根有向树，同一种颜色的节点共用同一组条件概率参数，于是每个模型对应一个由参数写出的多项式映射，其像是一族概率分布。如果在合适的坐标下这个像能写成用单项式参数化的形式，它的定义理想就叫 toric 理想，模型也就具有 toric 结构。已知有些类是 toric 的，也已知有些贝叶斯网络不是；是否所有 staged tree 模型都 toric，仍开放。
