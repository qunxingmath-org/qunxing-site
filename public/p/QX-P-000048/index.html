题面

对一切 n≥5，x_n = tan(arctan1+…+arctan n) 不是整数。

形式化表述

设 x₁=1, x_{n+1}=(x_n+n+1)/(1−(n+1)·x_n)（等价 FC 形式: x_n=(x_{n−1}+n)/(1−n·x_{n−1})，n≥2；另有高斯整数表示 x_n=B_n/A_n, (A_n,B_n) 来自 ∏_{k=1}^n (1+ki) 的实/虚部，A_n=0 时为极点非整数）；则 ∀n≥5: x_n∉ℤ。
（核对修正注记 2026-11-21，SOL验证Agent：原形式化递推分母"1−n·x_n"差一位——正确为 1−(n+1)x_n（FC Arxiv/2607.05739/TanArctanSum.lean verbatim 核录 x_n=(x_{n−1}+n)/(1−n·x_{n−1})）；原式在 n=1 处即除零（1−x₁=0），而真值 x₂=tan(arctan1+arctan2)=−3 有限。小例锚点（按修正递推）: x₃=0∈ℤ、x₄=4∈ℤ（故猜想从 n≥5 起）、x₅=−3/5∉ℤ ✓。来源链更正: FC 现行路径 Arxiv/2607.05739/TanArctanSum.lean，参考文献含 AMM08（J. Number Theory 128 (2008) 1807-1846）与 2026 后续论文 arXiv:2607.05739（ exceptional set E={n≥5: |x_n|>n/2+1} 等部分结果）。）

人话版

一句话：把 arctan 1 到 arctan n 加起来再取正切，结果可能是个整数吗？

x_n 定义为 tan(arctan 1 + arctan 2 + … + arctan n)。用正切加法公式可以把它写成递推：x_{n+1} = (x_n + n + 1)/(1 − (n+1)x_n)，每步都是有理运算，所以 x_n 总是有理数（除非分母为 0，此时是极点，也不算整数）。猜想是：从 n = 5 起 x_n 永远不是整数。卡片给出的锚点：x₃ = 0、x₄ = 4 都是整数，所以起点定在 5；x₅ = −3/5 不是。要否定它，只需找到一个 n ≥ 5 使 x_n 恰为整数；要证明它，需要对递推的分子分母做数论控制。

已知结果与进展

  • Amdeberhan–Medina–Moll (2008) 提出并给出数值证据与部分 n 的整除性分析；
  • 形式化条目 status=open（formal-conjectures Arxiv 家族）。
  • [2026 后续] arXiv:2607.05739（FC 引用）：定义 exceptional set E={n≥5: |x_n|>n/2+1} 并给出部分结果——未关闭主命题（FC 类标 research open, question，2026-11-21 核录）。

边界与约定

  • 最小参数: n=5（x₅=−3/5 非整数 ✓ 基线）；n=6..30 数值扩展（修正递推或高斯整数递推均可精确有理计算）。
  • 退化情形: A_n=0 的极点情形（FC 明确规定极点不算整数值——声称证明须处理该约定）；x_n 的符号/象限（tan 值与角度象限由 B_n/A_n 有理值承载）；n=3,4 整数例外（域外起点）。
  • 约定依赖: arctan 主值分支；递推与高斯整数表示的等价性（需 (1+ki) 乘法封闭性）；"整数"按 ℤ（极点除外）。
  • 结构性锚点: A_n、B_n 的增长与整除性——AMM08 的 p-adic/整除分析（x_n 的分母结构）是主要已知方法；2607.05739 的 exceptional set 结果给出 |x_n| 规模的部分控制。
  • 建议独立验证方法（仅描述，不执行）: 高斯整数乘积递推独立算 A_n,B_n 至 n≤10^4，统计整除例外（与 AMM08/2607.05739 途径不同实现）；对声称证明检查其对 A_n 零点与 exceptional set 的处理。
