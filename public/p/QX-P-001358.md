# Hofstadter Q 序列的结构问题

## 题面

Hofstadter Q 序列是否有理论结构：Q(n) 是否对一切 n 良定义？Q(n)/n → 1/2？特殊子列规律？

### 形式化表述

∀n: Q(n) 有定义且有限；lim Q(n)/n = 1/2？（Pinn "世代"结构是否严格化。）

## 人话版

**一句话**：Hofstadter 的 Q 序列，究竟有没有可描述的结构？

Hofstadter 的 Q 序列由 Q(1)=Q(2)=1 与 Q(n)=Q(n−Q(n−1))+Q(n−Q(n−2)) 递归定义，前几项是 1,1,2,3,3,4,5,5,6,6,6,8,…。每一项的自变量要回退 Q(n−1) 或 Q(n−2) 那么多，所以必须先知道这些值不大于 n；若某步索引超出已定义范围，序列就没法定义下去。已知 Q(n) 在计算范围内始终有定义，但没人证明它对所有 n 都良定义；同样未知的是 Q(n)/n 是否趋于 1/2。特殊子列（如 Q(2k+1)、Q(3·2^k+1)）的规律也缺少理论解释。

（AI 起草，未经人工审校）

## 原文摘录

> Douglas Hofstadter（AMM [1986, p.186]；Guy 1987 p.965 记录 "several small rumblings ... rather than answers"；Golomb 1988 "Sequences Satisfying Strange Recursions"）：Q(1)=Q(2)=1, Q(n)=Q(n−Q(n−1))+Q(n−Q(n−2))。Q(2k+1)、Q(3·2^k+1) 等特殊值规律、混沌行为无理论。
>
> —— Guy 1987 综述 p.965；OEIS A005185
