# 16.83(b) 自由局部幂零 n-Engel 群周期部分的素因子集 π(E_n)

## 题面

E_n 为可数生成自由局部幂零 n-Engel 群，π(E_n) 为其周期部分元素阶的素因子集。已知 2,3,5∈π(E₄)。π(E_n) 是否……（完整问题见原文）。

## 人话版

**一句话**：n-Engel 条件放宽后，周期部分的素因子集会最终稳定吗？

自由局部幂零 n-Engel 群，指由可数多个元素自由生成、满足 n-Engel 恒等式（把 [x,y] 与 y 反复取交换子 n 次后得 1）且局部幂零的群。E_n 的周期部分由其中所有有限阶元素组成，π(E_n) 是这些元素阶的素因子集合。已知 2、3、5 都在 π(E_4) 里。问题是：当 n 越来越大时，这个素因子集合是否最终不再变化，即 π(E_n)=π(E_{n+1}) 对一切足够大的 n 成立。
