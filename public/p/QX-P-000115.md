# Polynomial representing all nonnegative integers (Poonen)

## 题面

是否存在 f(x,y) ∈ Q[x,y] 使 f(Z×Z) = N（全体非负整数）？（Lagrange 四平方、Gauss 三角数定理的两变量多项式 analogue）

### 形式化表述

∃? f ∈ Q[x,y]: f(Z²) = N。

## 人话版

**一句话**：一个二元有理系数多项式，整点取值能正好是整个非负整数集吗？

问题要用一个二元多项式 f(x,y)，系数为有理数，只喂给它整数点，要求 f(ℤ×ℤ) 恰好等于 {0,1,2,…}——每个非负整数都取到，而负数一个也不出现。作为对照：Lagrange 四平方定理说每个非负整数都是四个平方数之和，于是 x₁²+x₂²+x₃²+x₄² 用四个变量就能取遍 ℕ；Gauss 的三角数定理也给出三变量的类似结论。这里把变量压到两个，并且不允许出现负值或漏项，条件非常紧，所以是否可能仍是悬而未决的问题。

- 边界：N含0；f(Z²)须无负值/非整值——声称答案时须同时验证'无非负整数漏项'与'无非整数/负值'。
