Does the hypergraph Ramsey-type function F^(t)(n,α) jump only at α = 0?

题面

超图2染色Ramsey函数F^(t)(n,α)随α从0到1/2是否仅在α=0处跳变? ('clear up this mystery'——$500)

形式化表述

F^(t)(n,α)单调性/跳变结构。已知: α=0为Ramsey函数; t=3时Conlon–Fox–Sudakov证F^(3)(n,α)≪√(log n)对固定α>0——即t=3仅在α=0一次跳变; 一般t下界≫(log n)^{c_α}。

人话版

一句话：把密度从 0 往上抬，Ramsey 函数是一直滑落还是只掉一次？

F^(t)(n,α) 是一类带密度参数的 t-阶超图 Ramsey 型函数：只保留密度为 α 的那部分 t-边，问多大的顶点集才能强制出现指定的结构。α=0 时它退化成普通的超图 Ramsey 数，α 一正就掉下来。Erdős 的问题是：这个函数是否只在 α=0 处发生一次跳变，之后便平缓？t=3 已有结论，说明确实只有 α=0 一个跳变点；一般的 t 只得到下界估计，整体结构仍未定。

已知结果与进展

  • [SOLVED-CASE] t=3: 仅α=0一次跳变 (Conlon–Fox–Sudakov)。
  • [OPEN] t≥4。

边界与约定

  • 边界：α∈(0,1/2]固定；每色各≥α·C(|X|,t)。
  • 独立验证建议：t=4小α随机构造偏差界数值检验。
