# x³+y³+z³=c 可判定性

## 题面

x³+y³+z³=c 可解性的算法可判定性

## 人话版

**一句话**：给定 c，判断 x³+y³+z³=c 有没有整数解，能有算法吗？

方程 x³+y³+z³=c 要求 x、y、z 都是整数，c 是给定的整数。有的 c 很容易解（如 c=29 有解），有的 c 被同余条件直接排除（例如 c≡±4 (mod 9) 时无解），但同余条件不充分，剩下的情形要靠大规模搜索。题卡问的是：是否存在一个算法，对任意输入的 c 都能判定方程是否有解并停机。这类问题属于 Hilbert 第十问题的三次推广，已知的不可判定性结果还没有覆盖它。
