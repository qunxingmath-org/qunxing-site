题面

H(q,c)=⟨a,b,c,d | [b,a]=[d,c]⟩ 指数 q、幂零类 c。a) M(H(8,12)) 的 Schur 乘子指数是否 32？b) M(H(7,13)) 是否 49？（群过大无法直接计算。）

形式化表述

exp M(H(8,12))=?32; exp M(H(7,13))=?49。

人话版

一句话：大到算不动的两个群，它们的 Schur 乘子指数真是 32 和 49 吗？

H(q,c)=⟨a,b,c,d | [b,a]=[d,c]⟩ 是四个生成元、指数 q、幂零类 c 的群。Schur 乘子 M(G) 是群同调 H₂(G,Z)，它衡量 G 的「中心扩张空间」；这里问的是 M(H(8,12)) 的指数是否为 32，以及 M(H(7,13)) 的指数是否为 49。原文注明难点在于这两个群太大，现有的 p-商算法用 32 位算术处理不了，需要有 64 位算术版本才能直接计算。

原文摘录

Kourovka Notebook 第 2022 辑问题 20.113（第21版 (2026) 正文仍在列），提出人：M. R. Vaughan-Lee

Let H(q, c) = ⟨a, b, c, d | [b, a] = [d, c], of exponent q, nilpotent of class c⟩.
a) Is it true that the Schur multiplier M(H(8, 12)) has exponent 32?
b) Is it true that the Schur multiplier M(H(7, 13)) has exponent 49?
The difficulty is that these groups are too big to compute using current versions
of the p-Quotient Algorithm, which use 32 bit arithmetic. So to tackle these groups
it would help to have a version of the p-Quotient Algorithm using 64 bit arithmetic.
M. R. Vaughan-Lee

—— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21 (arXiv:1401.0300v50, 2026-11-02, E. I. Khukhro & V. D. Mazurov 编)
