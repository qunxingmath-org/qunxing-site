题面

若 n | 1 + Σ_{k=0}^{n-1} k^{n-1} 则 n 为素数？（Giuga 型猜想）

补充：唯一回答（feralin, 2016-12-06）先给证明后自行更正：声称 n 必为素数的证明有误，并确认该问题是 Giuga 的公开猜想的表述变体。评论（Gottfried Helms 2017-02-26）确认 The question is an open conjecture of Giuga；讨论认为半边（n 为素数 ⟹ 整除）易证，反向（整除 ⟹ 素数）开放。

形式化表述

证明：若 n≥2 满足 n | 1 + Σ_{k=0}^{n-1} k^{n-1}，则 n 是素数。OP 已证 n 必为无平方因子数。回答作者（feralin）自认其证明有误并确认这是 Giuga 的公开猜想（Gottfried Helms 评论 2017-02-26 指出）。

人话版

一句话：让 n 整除那个幂和，n 就一定是素数吗？

取 n≥2，把 k 从 0 到 n−1 的 (n−1) 次幂全部加起来再加 1，问：如果 n 整除这个和，能不能断定 n 是素数。反方向可以直接算：n 为素数时每个 k^(n−1) 都同余 1（k 不被 n 整除的情形），和恰好被 n 整除。真正的难点是反方向——要证明任何满足整除关系的 n 都不可能是合数。输入提到提问者已证出这样的 n 必是无平方因子数，但完整结论仍是公开猜想，被称为 Giuga 猜想。
