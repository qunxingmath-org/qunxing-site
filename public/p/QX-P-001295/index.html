题面

非阿基米eld域上有理函数（deg≥2）：排斥周期点是否在classical Julia集（type I点集）中稠密？Okuyama在Lyapunov指数条件下证明稠密性；一般情形开放。

形式化表述

对一切deg≥2非阿基米德有理函数 f，证 J_cl(f) ⊆ closure(repelling periodic points)；已知：Berkovich Julia集上dense；cubic情形已由Truong 2026解决。

人话版

一句话：换到非阿基米德域上，排斥周期点还填得满 Julia 集吗？

在复数域上，次数至少为 2 的有理函数的 Julia 集有一个经典事实：排斥周期点在 J 中稠密。排斥周期点指满足 f^n(x)=x 且 |(f^n)′(x)|>1 的点。把底域换成完备的非阿基米德域（如 Q_p 或 C_p）后情形分化：Berkovich 意义下的 Julia 集上稠密性已知，而只取 K 中 type I 点得到的经典 Julia 集是否同样稠密，仍是一般情形下的开放问题，目前只掌握若干特殊情形；已有结果也指出 Berkovich 版本的稠密性并不能直接推出经典版本。

原文摘录

It is an open problem whether repelling periodic points are dense in the classical Julia set of a non-archimedean rational function of degree more than one.（Y. Okuyama, arXiv:1106.3363 摘要）

已知结果与进展

Hsia猜想背景；Okuyama 2011条件稠密性；Truong 'Density of repelling periodic points for cubic rational maps'（arXiv:2610.21559, 2026）cubic正答；次数≥5开放。

边界与约定

  • 最小参数/退化: deg=1退化（周期点有限——稠密性平凡假）；deg≥2为问题域（形式化✓）。
  • 分支/等号: classical Julia set（type I点）vs Berkovich Julia集两层——本条仅classical层；良约化vs劣约化（type II型点结构）分支；p≥5时cubic由tame结果已知（Truong文内口径——res char 2,3为本圈新贡献）。
  • 独立验证建议（与查新途径不同源）: 小域C_2,C_3上二次/三次有理函数族数值周期点计算，检验classical Julia稠密性；4次候选族的数值探测。
