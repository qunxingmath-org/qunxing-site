题面

极大Sidon集尺寸函数F(N): 对每个固定k, N充分大时 F(N+k)≤F(N)+1 ?

形式化表述

∀k≥1 ∃N₀: ∀N≥N₀, F(N+k)≤F(N)+1. (Erdős: 或可k≈ε√N.)

人话版

一句话：把区间拉长 k 个数，最大 Sidon 集最多只能多一个元素吗？

F(N) 表示 [1,N] 里能放下的最大 Sidon 集的大小，其中 Sidon 集要求所有两两之和互不相同。猜想是：固定任意整数 k ≥ 1，只要 N 充分大，把候选范围从 N 扩大到 N+k、多出 k 个整数，最大 Sidon 集最多只能多出 1 个元素，即 F(N+k) ≤ F(N)+1。直觉是多给几个整数几乎帮不上忙，但要把『几乎』变成对所有大 N 都成立的严格不等式，需要对 Sidon 集的加性结构做很细的分析。

（AI 起草，未经人工审校）

已知结果与进展

  • [BACKGROUND] Erdős: 甚至可能对k≈εN^{1/2}成立(加强版)。
  • [BACKGROUND] F(N)~√N渐近已知(Erdős–Turán), 单调微结构未知。

边界与约定

  • 最小参数: k=1 为最小实例（F(N+1)≤F(N)+1 是否对所有大 N 成立——单步增量）；k=2,3,… 各自独立阈值；OEIS A143824 数值序列为直接验证材料。
  • 退化情形: N 小（命题仅渐近；有限 N 的反例不影响主命题但影响加强版）；k 与 N 的关系分界（固定 k vs k≈ε√N）——任何声称证明必须声明覆盖哪个版本。
  • 约定依赖: Sidon=B₂（和两两至多重合一次）；F 为精确极大值（非渐近记号）。
  • 结构性锚点: F(N)∼√N 与增量 ≤1 的相容性检查——若 F(N+k)−F(N) 平均 ≈k/√N→0，猜想方向自然，但"充分大后 ≤1"需要微结构控制；声称证明的交换/压缩论证必须在极值集上生效。
  • 建议独立验证方法（仅描述，不执行）: 独立重算 F(N) 至 N=10^6（分支定界/SAT，与 OEIS 已知值交叉），检验增量序列 F(N+1)−F(N) 是否出现 ≥2 的跳跃及其位置；对声称证明在小 k 机器模拟其论证的关键不等式。
