# Graceful Tree 猜想（Gnang 声称证明未获接受）

## 题面

Graceful Tree 猜想（另有 SOLVED_CLAIMED 低强度：Gnang 未审）

## 人话版

**一句话**：任意一棵树，能不能把 0 到 n 标到顶点上让边差全不同？

设树 T 有 n 条边、n+1 个顶点。若能把 0, 1, …, n 这 n+1 个整数一一对应地标到顶点上，使得每条边两端标号之差的绝对值互不相同，就称 T 有一个优雅标号（graceful labelling）。因为边差只能落在 1 到 n 这 n 个值上，而边正好是 n 条，所以「互不相同」等价于它们恰好取遍 1 到 n。猜想说：每棵树都有这样的标号。反例是一棵有限的树，可以穷举验证，因此命题可被有限计算否定。输入另注明：曾有一份声称的证明未被接受。
