# batch_I I-074：已知分布 F 的 n 个 i.i.d. 样本中 m 个最小值之和：期望是什么？其 PDF/CDF？

## 题面

已知分布 F 的 n 个 i.i.d. 样本中 m 个最小值之和：期望是什么？其 PDF/CDF？

### 形式化表述

E[Σ_{i=1}^m X_{(i)}] 与 Σ X_{(i)} 的分布（一般 F）。

## 人话版

**一句话**：n 个样本里最小的 m 个加起来，它的期望和分布怎么算？

从分布 F 里独立抽取 n 个数，从小到大排好，记作 X₍₁₎≤X₍₂₎≤…≤X₍ₙ₎，这叫次序统计量。最小的那个最容易描述：P(X₍₁₎>x)=(1−F(x))ⁿ，于是它的期望可以写成一个积分。现在把最小的 m 个加起来，问这个和的期望有没有类似的封闭公式，以及它的概率密度和分布函数长什么样。单个次序统计量的公式是标准的；但“若干个次序统计量之和”的一般公式仍未解决，因为它们之间有次序约束，联合分布要处理“谁比谁小”的划分。

（AI 起草，未经人工审校）

## 原文摘录

> Let $\mathbf X = [X_1, X_2, \ldots, X_n]^\mbox{T}$ be a vector random variable drawn from a known distribution with CDF $F(x)$. The CDF for the minimum value in $\mathbf X$ is clearly $P[\min_{i=1\ldots n} X_i \leq x]$ $=$ $1 - \prod_{i=1\ldots n} P[X_i>x]$ $=$ $1 - (1 - F(x))^n$. The expected value for the minimum value in $\mathbf X$ is therefore $\int_0^\infty 1 - (1 - (1 - F(x))^n)dx$. I am interested in the sum of the $m$ smallest values ( i.e. , order statistics) in $\mathbf X$.
