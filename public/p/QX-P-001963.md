# Σ(2+sin n)ⁿ/(3ⁿnᵃ) 收敛

## 题面

Σ(2+sin n)ⁿ/(3ⁿnᵃ)（a∈(0,1)）收敛性

## 人话版

**一句话**：a 在 0 与 1 之间时，(2+sin n)ⁿ/(3ⁿnᵃ) 的级数收敛吗？

通项是 (2+sin n)^n/(3^n·n^a)。因为 2+sin n 最大到 3（当 sin n 极其接近 1 时），底数与分母的 3^n 相当，所以每项大小主要由「sin n 离 1 有多近」决定：绝大多数 n 上 2+sin n 明显小于 3，项指数级变小；但偶尔 sin n 极其接近 1，此时项几乎不衰减，只靠 n^a 压住。原文指出 Borwein–Bailey–Girgensohn 书的第 35 题正是 a=1 的情形，已由 Boppana 解决：把 n 分成「tame」（sin n 离 1 有 1/√n 量级间隔）与「wild」两类分别估计。题目问 a∈(0,1) 时的收敛性。
