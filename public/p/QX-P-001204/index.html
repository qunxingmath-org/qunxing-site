题面

Kung–Traub (1974)猜想：n点迭代法最优阶2^(n-1)。n=2、3的达界方法已知；一般n开放。

形式化表述

最优阶 opt(n) = 2^(n-1)？

人话版

一句话：每步算 n 次函数值，收敛阶最多只能到 2^(n−1) 吗？

求方程 f(x)=0 的根时，一类常用算法是「无记忆多点迭代法」：每一步对 f 作 n 次求值，再用这 n 个值算出下一个近似点，且不使用之前各步的历史信息。收敛阶衡量近似误差每步缩小多快，阶为 q 大致意味着误差的指数按 q 次方衰减。Kung 与 Traub 在 1974 年猜想：这类方法的收敛阶最多是 2^{n−1}，并问能否达到。n=2 与 n=3 已有达到这个界的构造，一般 n 仍未定。

（AI 起草，未经人工审校）

原文摘录

无记忆多点迭代法（每步n次函数求值）的收敛阶至多2^(n-1)；是否存在达到者。

—— Wikipedia: Kung–Traub conjecture

已知结果与进展

n=2（Newton类两步法）、n=3达界方法已知；一般n的构造与上界均开放；数值文献中大量'最优阶方法'文章依赖该猜想的特殊情形。
