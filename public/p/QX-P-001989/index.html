题面

PTE 型均衡剖分集合刻画

人话版

一句话：把一个图形切成 n 块面积相等的三角形，哪些 n 真能做到？

均衡剖分指把一个多边形（通常是三角形或正方形）用互不重叠的三角形铺满，并且每块面积都相同；能这样做到的块数 n 组成该图形的剖分谱。经典例子是 Monsky 定理：正方形不可能被切成奇数块面积相等的三角形，所以它的谱里没有奇数。题目要给的是这类“PTE 型”剖分的谱的完整刻画，即哪些 n 可实现。卡片只留了缩写 PTE，原包没有给出它的展开，因此还应先确认它指的是哪种附加条件（例如对块数因子的限制）。
