# 拓扑 n-流形嵌入 R^{2n}？

## 题面

拓扑 n-流形能否嵌入 R^{2n}

## 人话版

**一句话**：不管多奇怪,一个 n 维拓扑流形总能塞进 2n 维欧氏空间吗？

n 维拓扑流形指局部长得像 R^n 的空间,但不要求有光滑结构;嵌入指把它作为子空间放进去且保持原有拓扑。光滑情形有经典的嵌入定理:紧 n 维光滑流形能嵌入 R^{2n}。拓扑流形没有光滑结构可借助,是否仍能嵌进 2n 维就没有现成结论。问题问:这个维数预算对拓扑流形是否仍然够用。输入把这张卡标为「部分解决」,即部分维数已有结论。
