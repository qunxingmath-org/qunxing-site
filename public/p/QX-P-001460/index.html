题面

双素数常数 C₂=∏_{p>2}(1−1/(p−1)²)≈0.66016 的无理性是否有证明/参考？（如无，求明示开放的出处）

形式化表述

C₂ ∈ Q 是否成立——公认 open。

人话版

一句话：那个约等于 0.66016 的素数乘积，凭什么说它是无理数？

双素数常数定义为 C₂ = ∏(1 − 1/(p−1)²)，其中 p 取遍所有大于 2 的素数，数值约等于 0.66016。它出现在孪生素数猜想相关的启发式公式里，是那种“猜出来的密度”中的常数因子。直觉上这种无穷乘积像是无理数，但直觉不等于证明：由素数构成的无穷乘积，目前没有通用判别法能判定它的无理性。问题就是问：有没有人真的证明了 C₂ 是无理数？如果没有，能否指出把它明确记为未解决问题的文献。

（AI 起草，未经人工审校）

原文摘录

It seems intuitively clear that the twin prime constant $$ C_2 = \prod_{p > 2} \left(1-\frac{1}{(p-1)^2} \right) \approx 0.66016 $$ is irrational . Can anyone please give a reference to a short proof of this (e.g. in an introductory number theory textbook)? If this is in fact an open problem, could you please give a reference to some source explicitly stating so?
