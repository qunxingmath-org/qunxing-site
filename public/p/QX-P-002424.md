# 是否不存在完全的不相交 coNP 对

## 题面

设 $A,B\subseteq\{0,1\}^*$ 是两个语言。若 $A,B\in\mathrm{coNP}$ 且 $A\cap B=\varnothing$，称 $(A,B)$ 为**不相交 coNP 对**。

称 $(A,B)\le_m^p(A',B')$，如果存在一个总的多项式时间可计算函数 $f$，使得对所有 $x$：

$$
x\in A\Rightarrow f(x)\in A',\qquad x\in B\Rightarrow f(x)\in B'.
$$

若 $(A,B)$ 是不相交 coNP 对，且每个不相交 coNP 对都多一归约到 $(A,B)$，则称 $(A,B)$ 为**完全不相交 coNP 对**。

问：是否完全不相交 coNP 对不存在？即 Pudlák 的 $\mathrm{DisjCoNP}$ 猜想是否成立？

### 形式化表述

`no_complete_disjoint_coNP_pair`：

$$
\neg\exists A,B,\quad \operatorname{IsCompleteCoNPPair}(A,B).
$$

## 原文摘录

> When comparing different disjoint coNP-pairs, one can use the same polynomial reduction as used for disjoint NP-pairs; hence one can also ask similar questions. […] Conjecture (DisjCoNP) There exist no complete disjoint coNP pair (with respect to polynomial reductions).
>
> —— Pavel Pudlák，*Incompleteness in the finite domain*，§5.2，p. 26，2017，[arXiv:1601.01487v2](https://arxiv.org/pdf/1601.01487)。

## 已知结果与进展

- **原始状态：**Pudlák §5.2 实读指出，“是否存在完全不相交 coNP 对”的答案比 P-可分性问题更不清楚，但作者仍倾向否定；随后正式提出 $\mathrm{DisjCoNP}$。[Pudlák p. 26](https://arxiv.org/pdf/1601.01487)
- **对 TFNP 的推出：**Proposition 5.3 证明：若存在完全 TFNP 问题，则存在完全不相交 coNP 对。因此 $\mathrm{DisjCoNP}$ 成立可推出 TFNP 无完全问题。[Pudlák p. 26](https://arxiv.org/pdf/1601.01487)
- **对 SAT 证明系统的推出：**§6.3 实读转述，SAT 的 p-最优证明系统蕴含完全 NPMVt 函数；结合 Proposition 5.6 与 5.3，得到完全 TFNP 问题及完全不相交 coNP 对。因此 $\mathrm{DisjCoNP}$ 蕴含 SAT 无 p-最优证明系统。[Pudlák p. 31](https://arxiv.org/pdf/1601.01487)
- **相对化进展：**Khaniki Theorem 5.1 构造 oracle $\mathcal V$，使 $\mathrm{DisjCoNP}^{\mathcal V}$ 成立而 $\mathrm E^{\mathcal V}=\mathrm{NE}^{\mathcal V}$。这回答了 Pudlák 关于相对化分离的一部分问题，但不证明无 oracle 的主猜想。[Khaniki §5](https://arxiv.org/html/1904.01362v2)
- **当前形式化状态：**`no_complete_disjoint_coNP_pair` 在本地 Lean 中为 `research open/sorry`；NP 对版本与 coNP 对版本分别列条。
- **与 DisjNP 的关系：**Pudlák 将两者作为不同猜想列入分类；oracle 结果也说明不能轻率地把它们视为同一命题的取补。

## 边界与约定

- **三个层次不可混淆：**NP 对要求两侧都在 NP；不相交 NP 对还要求 $A\cap B=\varnothing$；完全 NP 对进一步要求所有不相交 NP 对可归约。本题把前两步中的 NP 换成 coNP，结论则换成“不存在完全对”。
- **同一归约函数：**$f$ 必须同时保留第一侧与第二侧；不是分别寻找 $f_A,f_B$，也不是只要求归约保持不交性。
- **完全性的范围：**目标对必须接受**所有**不相交 coNP 对的归约，不能只接受来自证明系统或 TFNP 的 canonical pairs。
- **有限域标题的含义：**Pudlák 的 “finite domain” 指所研究计算与证明长度有指数有限界；不是把语言限制为某个固定有限集合，也不是有限长度输入。Lean 中决策问题取全部 `List Bool`。
- **无 oracle 与相对化：**Theorem 5.1 的 $\mathrm{DisjCoNP}^{\mathcal V}$ 包含 oracle，不能消除主问题中的 oracle 量词。
- **开放方向：**Pudlák §8 明确把刻画 TFNP 的 canonical coNP 对列为获取 $\mathrm{DisjCoNP}$ 证据的开放方向。
- **查重。**QX-P-000255 实读为“完全不相交 NP 对是否存在”，与本题的 coNP 及否定结论不同；QX-P-000264 为另一组 p-optimal/finite-domain 猜想。70 份草稿和实时题库未发现本题的精确重复。

## 相关进展与声称解决

- **[PARTIAL] Pudlák Proposition 5.3：**完全 TFNP $\Rightarrow$ 完全不相交 coNP 对；给出主猜想的条件后果。
- **[PARTIAL] SAT p-optimality 链：**SAT p-最优证明系统 $\Rightarrow$ 完全 NPMVt 函数 $\Rightarrow$ 完全 TFNP $\Rightarrow$ 完全 coNP 对。
- **[PARTIAL] Khaniki 2022：**构造使 $\mathrm{DisjCoNP}$ 成立的相对化世界，并分离其他猜想；不解决无 oracle 版本。
- **[CLAIM] 未定位到无 oracle 的 DisjCoNP 证明、反例或构造。**按正式名称、Lean 名、§5.2、2022–2026、oracle 与中英文检索，未找到可信的一般解。
