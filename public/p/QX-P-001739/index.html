素数间隔排序问题（f(n)=排序不动点数；SE API 2026-11-21 仍活跃）

人话版

一句话：把前 n 个素数间隙按大小排好，原来还有几个待在原位？

先看素数序列 p₁=2, p₂=3, p₃=5, …，相邻两项之差 gᵢ=p_{i+1}−pᵢ 叫素数间隙，例如 1, 2, 2, 4, 2, 4, 2, 4, 6, …。取前 n 个间隙，把它们从小到大排序，再与原来的排列逐一比较：位置没变的那些就是不动点，个数记作 f(n)。题目问这个 f(n) 增长得有多快，或者它的确切取值规律。每个具体的 f(n) 都只要算出前 n 个素数就能验证，所以这是可计算的问题；难处在于 n 很大时素数间隙的分布极不规则，排序后的位移难以预测。卡上注明 2026-11 这个提问仍活跃。
