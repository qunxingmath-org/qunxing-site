# batch_I I-134：给定 [n] 上的区间集 I，选 k 个区间使覆盖的点数最大（Max-K Interval Select

## 题面

给定 [n] 上的区间集 I，选 k 个区间使覆盖的点数最大（Max-K Interval Selection）。该问题是否多项式可解/NP-难？

### 形式化表述

判定/优化版复杂度：∃多项式算法 vs NP-hard？（加权推广亦问）

## 人话版

**一句话**：从一堆区间里挑 k 条盖住最多的点，这到底难不难？

给定有序点集 S={1,2,…,n}，一个区间 INV(a,b) 覆盖从 a 到 b 的所有整数点。现在有一族区间 I，要求从中恰好选出 k 个，使它们合起来覆盖的 S 中点数尽可能多——同一个点被多个区间盖住只算一次。问题问：这个优化问题有没有多项式时间算法，还是 NP-难。难点在于“只算一次”这种重叠扣除让问题不再是简单的排序贪心；加权版本（每个点有权重）也一并问。

## 原文摘录

> I came up with the following problem, but do not know how to analyze it. Let $S$ be an ordered set of integers with size $n$ (i.e., $S=\{1,2,...,n\}$). An interval $INV(a,b)$ covers the elements in $S$ from $a$ to $b$ $(1 \leq a < b \leq n)$. For example, $INV(3,5)$ covers the element of $\{3,4,5\}$. Now I am trying to analyze the following problem: Given a set of intervals $I$, select $k$ intervals $R$ from $I$ (i.e., $R\subseteq I$ and $|R|=k$), such that $R$ covers the most of $S$.
