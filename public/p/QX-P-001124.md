# Kourovka 12.88：两个 fg 群可有同一局部有限 Cayley 图？

## 人话版

**一句话**：两个有限生成群能共用同一张 Cayley 图，而一个周期、一个不周期吗？

无向图称为群 G 的局部有限 Cayley 图，指：顶点可与 G 的元素一一对应，并且存在 G 的有限生成集 X（满足 X=X⁻¹ 且不含单位元），使顶点 g、h 相邻当且仅当 g⁻¹h∈X。题设还要求这张图局部有限，即每个顶点的邻居个数有限。题目问：是否存在两个有限生成群，共用同一张局部有限 Cayley 图，而其中一个是周期群（每个元素有限阶）、另一个不是周期群？共用一张图意味着两个群的「一步之内能走到哪」完全一样，但元素阶的行为却截然不同。这是把几何（图）与代数（元素阶）解耦的极端例子。

## 原文摘录

> 〔12.88 〕提出人：V. I. Trofimov
> An undirected graph is called a locally finite Cayley graph of a group G if its vertex set can be identified with the set of elements of G in such a way that, for some finite generating set X = X−1 of G not containing 1, two vertices g and h are adjacent if and only if g−1h ∈X. Do there exist two finitely generated groups with the same locally finite Cayley graph, one of which is periodic and the other is not periodic? V. I. Trofimov
>
