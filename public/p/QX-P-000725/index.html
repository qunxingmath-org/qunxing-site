题面

不存在 2-full（每素因子次数≥2）的 n 使 n+1 为 3-full（每素因子次数≥3）（Erdős #366）。

形式化表述

¬∃n: n 2-full ∧ n+1 3-full。已知仅 8|9 与 12167|12168 两对（逆序）。

人话版

一句话：会不会有一个数所有素因子都至少平方，而它加一都至少立方？

若整数 n 的每个素因子的指数都至少是 2，称 n 为 2-full（即 powerful 数）；指数都至少是 3 则称 3-full。问题断言：不存在 n 使 n 是 2-full 而 n+1 是 3-full。原始输入提到已知反向的两对例子 8 与 9、12167 与 12168。要解决它，需要对所有正整数 n 证明这种相邻组合不可能出现。

（AI 起草，未经人工审校）
