# Erdos P15: convergence of sum (-1)^n n/p_n

## 题面

级数 Σ(-1)^n · n/p_n (p_n为第n个素数) 是否收敛？

### 形式化表述

级数 ∑_{n≥1} (−1)^n n/p_n 是否收敛（Leibniz型交错但通项不单调递减的初等素数级数）。注: n/p_n→0（因 p_n∼n log n），非绝对收敛（∑ n/p_n 发散）。
（核对修正注记 2026-11-21，SOL验证Agent：原注"n/p_n→1"失准——p_n∼n log n 故 n/p_n∼1/log n→0；通项确趋于 0，但不单调。"非绝对收敛"正确。已修正并留痕。）

## 人话版

**一句话**：素数倒数搭起来的交错级数 Σ(−1)^n·n/p_n，到底收不收敛？

p_n 是第 n 个素数。把 n 除以 p_n 再按正负交替相加，问这个无穷级数是否收敛。由素数定理 p_n 约等于 n·ln n，所以通项 n/p_n 约等于 1/ln n，趋于 0 但非常慢；取绝对值后的级数发散。因此它像一个通项不单调递减的交错级数，莱布尼茨判别法用不上，这正是难点。只需回答收敛还是不收敛。

（AI 起草，未经人工审校）

## 已知结果与进展

- [PARTIAL] Tao [Ta23] (2023, CAMS 2024发表 10.1090/cams/29): 在HL素数元组猜想强形式下级数收敛。
- [PARTIAL] Sawhney: 相关变体级数在c>2时绝对收敛。
- [PARTIAL] Weisenberg: 有界素数间隙(Zhang 2014)蕴含相关级数发散(不同级数)。

## 边界与约定

- 最小参数: 部分和 S_N=∑_{n≤N}(−1)^n n/p_n 可精确数值计算（素数表确定性生成）——Erdős 建议的计算机探索路线；小 N 手工核验（S_1=−1/2, S_2=−1/2+2/3=1/6, …）。
- 退化情形: 起始指标 n=1；符号约定 (−1)^n 与 (−1)^{n+1} 不影响收敛性判定；绝对收敛已被排除（∑ n/p_n 发散），故任何声称证明必须真正用到交错结构/部分和的自消性，而非绝对收敛估计。
- 约定依赖: "收敛"=普通（条件）收敛；p_n 为第 n 个素数的标准编号。
- 结构性锚点: Tao 2023 条件性结果依赖 HL 素数元组猜想强形式——声称无条件证明须说明如何绕开该强度；Weisenberg 相异级数（有界间隙⟹发散）说明"相邻级数发散"与本题收敛可并存，声称证明不得混同两级数；Sawhney 变体 c>2 绝对收敛为相邻精确结果。
- 建议独立验证方法（仅描述，不执行）: 独立计算 S_N 至 N=10^8（现成素数表+高精度求和，与 Tao/EP 途径不同）观察部分和衰减/震荡形态；对声称证明核查其对素数间隙的量化依赖是否与已知无条件界（如 Baker–Harman–Pintz）相容。
