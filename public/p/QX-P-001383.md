# Zowe 次线性映射的线性控制问题（AMM 6051）

## 题面

问：无附加条件时，向量值次线性映射是否总被某线性映射逐点控制？

### 形式化表述

∀ 次线性 p: X→Y ∃ 线性 T: Tx ≤ p(x) ∀x？（Y 任意有序向量空间。）

## 人话版

**一句话**：只要求次线性，是不是就总能找到一个线性映射处处压在它下面？

次线性映射 p: X→Y 指满足 p(x+y) ≤ p(x)+p(y) 和 p(λx)=λp(x)（λ≥0）的映射，可以把它看成一种“带尺度的长度”。Y 是有序向量空间，里面的元素能比较大小。问题问：对每个这样的 p，是否总能找到一个线性映射 T: X→Y，使 Tx ≤ p(x) 对所有 x 都成立。这相当于问 Hahn–Banach 型控制定理在没有额外条件（比如 X 是实向量空间、Y 是实数轴、或 p 取非负值）时还成不成立，难点正在于 Y 只是一般的序向量空间。
