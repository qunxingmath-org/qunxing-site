题面

确定与 Sidon 集相关的自相关常数的精确值；当前已知区间 [1.292, 1.50286…]，能否改进任一侧。

形式化表述

C₁a := 最大的常数 C 使得对一切非负 f: ℝ→ℝ 有 max_{−1/2≤t≤1/2} ∫_ℝ f(t−x)f(x)dx ≥ C·(∫_{−1/4}^{1/4} f(x)dx)²。（与加性组合中 Sidon 集最大尺寸相关。）
FC OptimizationConstants/1a.lean 结构（2026-11-21 核录）: 已解定理 c1a_lower_bound（1.2748 ≤ C₁a，M2010 线）与 c1a_upper_bound（C₁a ≤ 1.5029）；三个 open 子项（均 research open, question value）: ①改进上界 1.5028628587…（T2026）；②改进下界 1.292（PBV2026）；③确定精确值 C₁a=?。
目标: 缩小 [1.292, 1.5028628587…] 任一侧或确定精确值。
（补全注记 2026-11-21，SOL验证Agent：原形式化将定义推给 FC 条目——已按 FC 1a.lean verbatim 补全变分定义；引用链: Tao 优化常数项目页 + M2010（Matolcsi–Máté–Vinuesa, arXiv:0907.1379）+ Y2026 + T2026（Together AI EinsteinArena）+ PBV2026（Piterbarg–Bajaj–Vincent, GitHub sidon-autocorrelation）。）

人话版

一句话：那个把函数自相关压到最低的常数，精确值究竟是多少？

C₁a 的定义是一个变分问题的答案：在所有非负函数 f: R→R 中，把『f 与自己的卷积在最优点处的最大值』与『f 在 [−1/4,1/4] 上积分的平方』相比，取这个比值能保证的最小常数。这个常数和加性组合里 Sidon 集的最大尺寸直接相关，所以曲线下压得越低，关于 Sidon 集的结论就越强。卡片记录：已知 1.292 ≤ C₁a ≤ 1.5028628587…，下界来自 PBV2026，上界来自 T2026，另外还有更早的 1.2748 下界与 1.5029 上界。问题要的是精确值，或者至少把任一侧显著改进。

（AI 起草，未经人工审校）

原文摘录

Determine the exact value of the autocorrelation constant related to Sidon sets; current bounds 1.292 ≤ C_{1a} ≤ 1.5028628587… (T2026 upper, PBV2026 lower).

—— formal-conjectures OptimizationConstants 1a

已知结果与进展

  • Tao (2026) 优化常数项目给出上界；PBV2026 给下界 1.292；
  • 两侧界均为近年结果，方法（数值优化+组合构造）可延续。

边界与约定

  • 最小参数: f 的试探函数族（区间特征函数/高斯/多峰构造）数值优化；步长函数离散化近似（T2026 的 1.5028… 来自步长函数族）。
  • 退化情形: f≡0（两侧为 0——下界方向自动满足）；∫_{−1/4}^{1/4} f=0（右边退化无约束）；f 缩放不变性（两侧同为二次型——常数定义良定）。
  • 约定依赖: 自相关 max 取于 t∈[−1/2,1/2]；积分域 ℝ 与 [−1/4,1/4]；C 的"最大常数"=对一切 f 的下确界比值。
  • 结构性锚点: 已证界 1.2748（M2010 解析）与 1.5029（数值）之间的缺口即题目空间；PBV2026 multi-scale arcsine 方法与 T2026 AI 搜索构造为两端现成路线。
  • 建议独立验证方法（仅描述，不执行）: 独立数值优化（步长函数离散化+全局搜索）复算两端界（与 T2026/PBV2026 实现不同源）；对声称解析证明审查其 f 族的完备性（对一切非负 f 的量词）。

相关进展与声称解决

  • 无；项目设计本身即为"逐步改进常数"。
