题面

给定小的光滑 H（端点任意阶消失），是否存在曲线图使"曲边三角形面积"S(x)=H(x)？有何非显然限制？

形式化表述

∀H∈C^∞_c 型（小, 端点平脱）: ∃图(曲线) 使 S(x)=H(x)?（S 为图与两斜边围成的面积，t-截面问题平面玩具版）

人话版

一句话：想让“曲边三角形”的面积函数正好等于给定的 H(x)，总能画出一条曲线吗？

设平面里有一条曲线（函数的图像），它与两条斜边围出一块曲边三角形，其面积随横坐标 x 变化，记作 S(x)。题目问：给定一个小的光滑函数 H（在区间端点附近以任意阶趋于 0），是否存在一条曲线，使它的曲边三角形面积函数恰好是 S(x)=H(x)？如果一般不行，又有哪些不那么显然的限制？难点：S 是由曲线与两条固定斜线共同决定的，改动曲线会整体影响 S 的形状。

（AI 起草，未经人工审校）

原文摘录

Let $S(x)$ be the area of the yellow curvilinear triangle. I'd like to find a graph for which $S(x)=H(x)$ where $H $ is some prescribed function (small, smooth, vanishing near the endpoints to any order you wish, etc.). Is it always possible or there are some non-obvious hidden restrictions?

已知结果与进展

Zare（a66976, 票2）：a.e. 处 S'(x)=右腿长−左腿长，端点条件下 |S'|≤√2 型约束 ⇒ 排除某些 H（如 10⁶exp(−1/(x(1−x))²) 在内点导数 1.132）；fedja：该限制属"trivial restriction"类，真实 obstructing 机制未知；滞后微分方程途径数值不稳定。
