# 稀疏"素数+基"集合（EP#32；原批次 A-004）

## 题面

是否存在 A⊂N：计数函数 o((log N)^2)，且每个充分大整数均可写成素数 p 与 a∈A 之和？界能否达到 O(log N)？（第三子问：使 |A∩[1,N]| ≫ log N 的 liminf ≥1，Ruzsa 已肯定解决。）

### 形式化表述

存在 A⊂N 与 N₀，使得 ∀n≥N₀ ∃素数 p、a∈A: n=p+a，且 |A∩[1,N]| = o((log N)^2)（强化：≤ C·log N）。

## 人话版

**一句话**：一个只有 log N 量级元素的集合，能补上所有素数的缺口吗？

要找集合 A⊂N，使每个充分大的整数 n 都能写成 n=p+a，其中 p 是素数、a∈A。问 A 能有多稀：计数函数 |A∩[1,N]| 是否可以只有 o((log N)²)，甚至强到不超过 C·log N。粗算一下就知道 log N 是天然的门槛：若 A 在 [1,N] 里只有 m 个元素，能表示出的 p+a≤2N 的整数最多 m·π(N)≈m·N/log N 个，要覆盖 2N 个数就得 m≳log N。题面注明其中第三子问已由 Ruzsa 给出肯定答案，主要的上界问题仍悬着。
