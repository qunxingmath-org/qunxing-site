# an+b 与 bn+a 同素

## 题面

an+b 与 bn+a 可同为素数

## 人话版

**一句话**：两个交叉的一次式 an+b 与 bn+a，能同时取到素数吗？

给定正整数 a、b，考虑两个一次式：an+b 和 bn+a。单个式子的素数取值有 Dirichlet 定理撑腰（a、b 互素时有无穷多个 n 使 an+b 是素数），但两个式子同时为素数就没有现成定理，它属于「多个线性型同时取素数」这一族问题，最简的线性情形（n 与 n+2 同时为素数，即孪生素数）都还没解决。题目问：是否总能找到 n 使两者都为素数，以及需要什么条件。像 a、b 都取奇数这种情形，取 n 为奇数时 an+b 是偶数，奇偶性会直接掐掉一半候选。
