Carlson 模型与 Sierpiński 集（MO#209894 官方交叉帖同悬置）

人话版

一句话：所有可数生成 σ-代数都能延拓测度，就有 Sierpiński 集？

Sierpiński 集指一个不可数的实数集，它的每个不可数子集都不是 Lebesgue 零测集。假设：每个包含 [0,1] 上 Borel σ-代数、且可数生成的 σ-代数，都容许一个延拓 Lebesgue 测度的测度。这个假设在 Carlson 模型中成立（把 ω₂ 个随机实数加到 CH 的模型中）。原文指出：在 Carlson 模型里确实有 Sierpiński 集（新加的随机实数全体就是 ω₂ 大小的一个），而在「Lebesgue 测度有全延拓」的假设下也有（Gitik–Shelah 定理）。问的是：光靠上面那条假设，能否推出 Sierpiński 集存在。

（AI 起草，未经人工审校）

原文摘录

Suppose that every countably generated sigma algebra extending the Borel sigma algebra on $[0, 1]$ admits a measure extending the Lebesgue measure (This is true in Carlson's model which is obtained by adding $\omega_2$ random reals to a model of CH). Must there be a Sierpinski set, i.e., an uncountable set of reals all of whose uncountable subsets are Lebesgue non null?
This is true in Carlson's model (the set of random reals added constitutes an $\omega_2$-sized Sierpinski set) and this is also true if there is a total extension of Lebesgue measure (via Gitik-Shelah theorem).

—— Math StackExchange 问题 #644344，作者 hot_queen，CC BY-SA 3.0，https://math.stackexchange.com/questions/644344/carlsons-model-and-sierpinski-sets
