# Ryser 奇阶 Latin 方横贯猜想

## 题面

奇数阶 Latin 方必有横贯（n 个不同行、列、符号的单元格集）。

### 形式化表述

∀奇 n,∀n 阶 Latin 方: ∃横贯。

## 人话版

**一句话**：奇数阶 Latin 方里，总能挑出 n 个格子，行、列、符号各不同吗？

n 阶 Latin 方是 n×n 的表，每行每列都把 1..n 各填一次。横贯是选 n 个格子，使它们占据不同的行、不同的列，也填着不同的符号——相当于在 Latin 方里找一个“完美匹配”式的结构。Ryser 猜想断言：只要 n 是奇数，任何 n 阶 Latin 方都含有横贯。偶数阶时反例是存在的，所以“奇数”这个条件是本质的。否定它只要给出一个没有横贯的奇数阶 Latin 方；证明则要对所有奇数阶、所有 Latin 方同时成立。
