人话版

一句话：恰有两个非实共轭类时，四阶元素的中心化子为何是平方阶？

共轭类称为自逆的，指其中每个元素都与其逆元共轭。设有限群 G 恰有两个非自逆的共轭类，x 是其中一个类里的元素，且 x 的阶为 4。要证明：中心化子 C_G(x)（与 x 交换的全部元素构成的子群）的阶是平方数。原文说明已有特征标论证：G 恰有两个非实值的不可约特征标（「非实值特征标」的个数等于非自逆共轭类的个数），而 x 的阶为 4 这一条件把 x 上的特征标值限制成纯虚数，进而推出 |C_G(x)| 为平方。问题是要一个不靠特征标的群论证明。

Suppose the finite group $G$ has exactly two conjugacy classes that are not self-inverse (a conjugacy class is self-inverse if the elements in it are conjugate to their inverses). Let $x$ be an element of one of these classes, and suppose $x$ has order 4. Then the order of the centralizer $C_G(x)$ is a square.
Can anyone give a group-theoretic proof?
