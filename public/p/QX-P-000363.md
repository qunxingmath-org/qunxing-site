# Büchi问题（平方数列二阶差）

## 题面

Büchi (1980s，动机为Hilbert第十问题不可判定性强化)：整数上未知；有理数上已知为假；函数域ℚ(t)上已证；无已知非平凡长度≥5序列。

### 形式化表述

∃ M: ∀ x_1..x_M∈Z 若 x_{n+2}²−2x_{n+1}²+x_n²=2 ∀n 则 x_{n+1}=x_n±1。

## 人话版

**一句话**：平方数排成一列二阶差分恒为 2，会拖出多长的非平凡例子？

取一列整数 x₀, x₁, x₂, …，要求对每个 n 都有 x_{n+2}² − 2x_{n+1}² + x_n² = 2，即平方之后的二阶差分恒等于 2。取 x_n = x₀ + n 或 x₀ − n 时确实满足，这类称为平凡列。Büchi 的问题是：是否存在一个统一的长度上界 M，使任何长度超过 M 的这类数列都只能是平凡列？在整数上答案未知，在有理数上已知为否（存在非平凡的长列），在函数域上也有结论。它源自把 Hilbert 第十问题不可判定性作更强化的努力。

（AI 起草，未经人工审校）

## 已知结果与进展

Buell (Math. Comp. 1987)：长度4全分类（含(6²,23²,32²,39²)型）；Jaillet (2025, hal-05091876)：Buell定理注记；Xiao (2024)：对角二次方程组H10不可判定（Büchi路线完成）；Vidaux–Browkin等综述。

## 边界与约定

- 边界：'平方列'=每项为完全平方；平凡=等差±1平方列。
- 独立验证建议：长度5搜索程序（Buell分类扩展，S unit方程法）。
