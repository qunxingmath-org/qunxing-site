# (an+1)(bn+1)(cn+1) 为平方的频率

## 题面

(an+1)(bn+1)(cn+1) 为平方数的频率

## 人话版

**一句话**：(an+1)(bn+1)(cn+1) 恰好是平方数，这种情况有多常见？

给定三个正整数参数 a、b、c，让 n 从 1 取到 N，数一数使 (an+1)(bn+1)(cn+1) 为完全平方数的 n 有多少个。题目要的是这个计数随 N 的增长阶，也就是这种情形有多「频繁」。这类问题通常借偏序结构把它看成一个 2 维或 3 维的格点计数，再把条件翻译成对素因子指数的约束。题卡没有给出参数的一般性限制，具体 a、b、c 需按出处确认。
