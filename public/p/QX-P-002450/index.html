题面

求最小正整数 $N$，使完全图 $K_N$ 的任意红蓝边染色都含红色 $K_3$ 或蓝色 $K_{10}$。把红边看成图 $G$，则

$$
R(3,10)=\min\{（本机文件 forall） G\text{ 于 }N\text{ 点},\ \omega(G)\ge3\text{ 或 }\alpha(G)\ge10\}.
$$

截至 2026-11-24，已证

$$
\boxed{40\le R(3,10)\le41}.
$$

问题只剩一个二择一：是否存在 40 点、无三角形且独立数至多 9 的图？存在则 $R(3,10)=41$；不存在则 $R(3,10)=40$。

难度与知名程度

  • 难度：5/5。 上界计算处理约 1500 亿个中间图；40 点情形的度分布、正则情形和对称性排除仍开放。
  • 知名度：领域内高，大众中等偏低。 这是经典双色 Ramsey 数中久未闭合的精确值，2026 年仍有新 Lean 与 DRAT 子证书，但不是长期毫无进展的题目。

原文摘录

“We improve the upper bound on the Ramsey number R(3,10) from 42 to 41. Hence R(3,10) is equal to 40 or 41.”

—— Vigleik Angeltveit, *R(3,10)≤41*, arXiv:2401.00392v2, 2024，Abstract。

已知结果与进展

  1. 下界 40。 Exoo（1989）给出 39 点图。本次独立复核公开 graph6 证书：39 点、167 边、0 个三角形、独立数 9，故 $K_{39}$ 有避免红 $K_3$ 与蓝 $K_{10}$ 的染色。
  2. 上界 41。 Angeltveit（2024 预印本，2025 正式发表）以邻域粘合和穷举证明 $\mathcal R(3,10,41)$ 为空。论文未附完整可重跑枚举数据；本次未找到覆盖该上界的独立机器证书。
  3. 2026 年只完成部分。 Daugherty 等排除度 4；McCrea 排除 39 个度 7 接口；Chen 的 464 个立方体仅认证 365 个；Toledo 的 C35 Lean 定理排除一个诱导子图族。它们都明确不判定 40/41。

下面是可复跑的下界检查；输出应为 39 167 0 9。

```python
from itertools import combinations
from collections import Counter
s = 'fhcKICDK@GBH@C_HK@GOCcc@Gc@GQOc_P@D?KGCOOoG_OG_hA@?oGOSI@AA`GCKACSGGDHC@OG_aOGCSGcA_D_C_SOIGA_PC_???AaAaADABGCOAgH@COT?O_'
v = [ord(c) - 63 for c in s]
n = v[0]
bits = ''.join(f'{x:06b}' for x in v[1:])
pairs = [(i, j) for j in range(1, n) for i in range(j)]
adj = [0] * n
for k, (i, j) in enumerate(pairs):
if bits[k] == '1':
adj[i] |= 1 << j
adj[j] |= 1 << i
tri = sum((adj[i] >> j) & 1 and (adj[i] >> k) & 1 and (adj[j] >> k) & 1
for i, j, k in combinations(range(n), 3))
best = 0
def expand(P, size):
global best
best = max(best, size)
while P:
if size + P.bit_count() <= best:
return
bit = P & -P
P ^= bit
x = bit.bit_length() - 1
expand(P & ~adj[x] & ~bit, size + 1)
expand((1 << n) - 1, 0)
print(n, sum(a.bit_count() for a in adj) // 2, tri, best)
print(dict(sorted(Counter(a.bit_count() for a in adj).items())))
```

原文件（含末尾换行）SHA-256 为 9b48c399a89efd8f437fbedca6241f686223b0c77aa100553ab5450b68d52c63。

边界与约定

  • 红图取三角形自由，蓝图取独立 10 集；交换颜色对应 $R(3,10)=R(10,3)$。
  • 仅证明 40 点图不存在或给出一个 40 点例子都只解决一半；上界 41 已证，但完整验收仍需可复核依据。
  • $R(5,5)$、$R(3,9)=36$、$R(3,K_{10}-e)$、多色三角形数及 Schur 数均不是本题。
  • 有限范围搜索、局部 UNSAT、条件性结构定理和“未找到图”都不能代替全局不存在性证明。

相关进展与声称解决

  • [已否证的错误声称] Qiao（2015） 标题写 $r(3,10)=41$，但摘要又称其 RG(3,10) 为 10-正则；三角形自由图中每个邻域都是独立集，10 正则会立即产生独立 10 集。该文 OpenAlex 显示 0 引，未被 DS1 采纳。
  • [历史错误构造] DuHu 曾声称 $R(3,10)\ge41$；DS1 revision 18 明确记为错误，不能把旧搜索结果当反例。
  • [部分证书] 2026 C35、度排除、DRAT、SAT 与粘合均缩小搜索空间；最新实时案例图仍明确“不决定是哪一个”。
  • [未发现有效完整解决] 本轮没有找到同时给出 40 点不存在性证明或有效 40 点证书、并被独立核验的精确值解答。
