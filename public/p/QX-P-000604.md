# （来源 C-011）1 + 1/4 + 1/9 + … + 1/n² 何时为有理数平方？

## 题面

1 + 1/4 + 1/9 + … + 1/n² 何时为有理数平方？

补充：回答1（Will Jagy 2014-10-31, 3票）：(n!)² 归一化分子分解表 + 对奇次素因子出现区间的模式观察（2,3 除外），自注 pattern can probably be proved。回答2（Greg Hurst 2014-11-01）：H_r^{(2)} ∈ Q² 仅 2 例（r≤100000）。回答3（robjohn 2014-10-30）：第二问（H_n 非整数）完整初等证明；第一问 very hard。

### 形式化表述

求所有 n 使 H_n^{(2)} = Σ_{k=1}^n 1/k² ∈ (Q)²。已知 n=1,3 成立（1 与 49/36=(7/6)²）。robjohn 评论确认第二问（调和数 H_n 不是整数，n≥2）容易；第一问极难（robjohn: very hard, I don't see a way to approach it）。Greg Hurst（2014-11-01）用 Mathematica 验证前 100000 个部分和仅有 2 例。Will Jagy 给出分母 (n!)² 归一化后分子素因子模式的部分分析。

## 人话版

**一句话**：前 n 个倒数平方和，什么时候恰好是有理数的平方？

记 H_n^(2) = 1 + 1/4 + 1/9 + … + 1/n²，问哪些 n 使它等于某个有理数的平方。已知 n=1 给 1=1²，n=3 给 49/36=(7/6)²，这两个都成立；输入提到有人验证到十万以内只有这两例。做法上通常把和通分（分母可对齐到 (n!)² 的倍数）后研究分子的素因子分布，或落回分母中某个素数出现奇次幂的论证。要把「只有这两例」变成定理，需要排除所有更大的 n。
