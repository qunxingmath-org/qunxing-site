题面

紧凸集 X（局部凸 Hausdorff TVS）上的 l.s.c. 闭凸值自映射 F 是否必有不动点——当 X 不假设可度量化时？

形式化表述

X 紧凸（非度量 LCTVS）、F:X→X l.s.c. 且闭凸值 ⇒ ∃x∈F(x)？

人话版

一句话：紧凸集不能度量化时，下半连续的凸值映射还有不动点吗？

F 把集合 X 的每一点 x 送成一个子集 F(x)。称 F 凸值，指每个 F(x) 都是凸集；称 F 下半连续，粗略说就是 x 变动时 F(x) 不会突然收缩成一个更小的集合。经典结论（借助 Michael 选择定理）说：若 X 是局部凸 Hausdorff 拓扑向量空间里的紧凸集、并且 X 可度量化，那么任何这样的闭凸值映射都有不动点：存在 x 使 x∈F(x)。问题问：把“可度量化”这个前提拿掉之后，结论还成立吗。

（AI 起草，未经人工审校）

原文摘录

There is well-known fixed point theorem theorem for multivalued l.s.c. maps, based on Michael selection theorem: Suppose, that $X$ is compact, convex and metrizable in locally convex Hausdorff topological vector space. Then any l.s.c. map $F:X\rightarrow X$ which is closed and convex valued has a fixed point, i.e. $x\in F(x)$. The question is, what happens if we drop the assumption that $X$ is metrizable.

已知结果与进展

可度量化情形由 Michael 选择定理证明（Xian Wu 论文）；Majer 评论：USC 情形 Ky Fan 1951（Kakutani 推广）无需可度量化；l.s.c. 情形因无闭图使逼近选择取极限失效（OP 评论解释深层差异）。
