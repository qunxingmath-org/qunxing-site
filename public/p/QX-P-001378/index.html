Montgomery's lattice point problem for curves whose curvature is bounded between two values

题面

曲率受控（介于 1/a 与 2/a）的函数图在 [0,a] 上必靠近某格点（竖距 ≤ 2/√a）。

形式化表述

∀a≥8, ∀f: [0,a]→R, a^{-1}≤f''≤2a^{-1} ⇒ ∃(m,n)∈Z²: 0≤m≤a ∧ |f(m)−n|≤2a^{-1/2}。

人话版

一句话：曲率被夹在两个值之间的曲线，总会从某个格点身边 2/√a 内穿过吗？

格点指两个坐标都是整数的点 (m,n)。设 a≥8，函数 f 在 [0,a] 上满足 1/a ≤ f″ ≤ 2/a，即曲线的弯曲程度被夹在两个值之间，既不太直也不太弯；要证存在整数 m（0≤m≤a）和整数 n，使 |f(m)−n| ≤ 2/√a，也就是曲线在某个整数横坐标处离某个格点很近。难点：要把“曲率受控”翻译成对格点分布的定量估计。

（AI 起草，未经人工审校）

原文摘录

Hugh L. Montgomery，AMM E2759 (1979)，Rabinowitz 索引 p.416：若 0≤x≤a 上 a^{-1}≤f''(x)≤2a^{-1}（a≥8），证明存在格点 (m,n)，0≤m≤a，|f(m)−n|≤2a^{-1/2}。

—— Rabinowitz 索引 p.416

已知结果与进展
