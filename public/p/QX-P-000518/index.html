题面

有限 p-群 G 是否总有 exp(M(G)) | exp(G)？（M(G)=Schur 乘子）注：全群版本已被反例否定，p-群版本开放。

形式化表述

∀有限 p-群 G: exp(M(G)) | exp(G)。已知成立：nilpotency class ≤ p-1（Mashayekhy 等）、奇 p 且 class ≤ 2p-2（Xing–Zheng 2026）；p=2 情形更弱。

人话版

一句话：p-群的 Schur 乘子，其指数一定整除群本身的指数吗？

有限群 G 的 Schur 乘子 M(G) 是第二同调群 H₂(G,ℤ)，它同构于某个「最大」中心扩张的核。exp(G) 指 G 中元素阶的最小公倍数。Schur 指数猜想断言 exp(M(G)) 整除 exp(G)。题面说明：对一般群的版本已被反例否定，但限制到有限 p-群时仍开放；已知成立的情形包括幂零类 ≤p−1，以及奇素数 p 且幂零类 ≤2p−2。

已知结果与进展

  • 反例（一般群）：Moravec 2007 记录原猜想为假——修正采集"一般情形开放"表述。
  • p-群：class ≤ p-1（1011.2593 线）；奇 p class ≤ 2p-2（2611.11865）；exp(G) 与 |G'| 互素等条件成立。
  • 2611.11865 同时研究 critical-class 现象。

边界与约定

  • 边界：Schur乘子指数整除性；p-群限定。
  • 独立验证建议：小p小class GAP计算exp(M(G))验证。

相关进展与声称解决

  • [SOLVED-否定的前提] 全群版（反例）；[PARTIAL] p-群 class ≤2p-2（2026-11）。
  • p-群任意类无解决记录（2026-11-20 检索）。
