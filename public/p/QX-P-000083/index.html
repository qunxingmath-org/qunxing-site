形式化表述

∀固定 n≥5: f(n,p) 关于素数 p 单调递增？【以原文为准；12.55；n≥5 量词补全【2026-11-21 修正留痕】】

人话版

一句话：固定阶数的指数，p 越大，这种阶的群真的越多吗？

f(n,p) 表示阶恰好为 p^n 的群的同构类个数，其中 p 是素数。例如 f(1,p)=1、f(2,p)=2 对所有 p 都相同，而从 n = 3 起数值开始随 p 变化。A. Mann 的问题是：固定 n ≥ 5 后，f(n,p) 作为 p 的函数是否单调递增？卡片特别留痕说明『对任意固定 n ≥ 5』这个量词原先在译述里漏掉了，现在已补全——没有这个限定，问题就谈不上单调性。否定它只需找到某个 n ≥ 5 与 p₁ < p₂ 使 f(n,p₁) > f(n,p₂)，而这样的验证在 p 很小时可以用计算机枚举群来完成。

（AI 起草，未经人工审校）

边界与约定

  • 最小参数: n=5（最小实质档，数表已单调）与 n=8 起（数表未及档）为两段检查区；p 相邻对 (p,p') 的 f(n,·) 比较只需逐对。
  • 退化情形: "increasing"对素数序（2,3,5,7,11,…）全链单调 vs 逐对单调等价（全序集）；f(n,2) 与 f(n,3) 的小 n 反常（若存在）不构成反例（n≥5 限定）。
  • 约定依赖: 群计数=同构类数（GAP SmallGroups 口径）；n 固定、p 变动方向唯一。
  • 建议独立验证方法（仅描述，不执行）: 延拓 GAP 小群计数表到新素数档（n≤8 已有库），检验单调链断裂点；对渐近区（大 p）用 p-群枚举理论（Higman PORC 谱系）做单调性外推论证框架核对。
