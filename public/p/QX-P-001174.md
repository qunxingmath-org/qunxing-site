# Selfridge PSW 素性判据猜想（测试无误报）

## 题面

满足两个强条件的 n 必为素数（PSW 组合测试无误报）。

### 形式化表述

∀n>1 (n≡±2 mod 5): (2^{n−1}≡1 ∧ F_{n+1}≡0 mod n) ⇒ n prime。

## 人话版

**一句话**：同时骗过 Fermat 与 Lucas 两道关的合数，存在吗？

两类经典的素性检验各有漏洞：合数可以通过 Fermat 检验（2^{n−1}≡1 mod n），也可以通过 Fibonacci/Lucas 型检验（F_{n+1}≡0 mod n），这样的合数分别叫伪素数。Selfridge 在 1980 年代提出：若 n≡±2 (mod 5)，并且同时满足 2^{n−1}≡1 (mod n) 与 F_{n+1}≡0 (mod n)，则 n 必为素数——即把两道检验合起来，就再也没有假阳性。这是把一个实用算法变成确定性判据的关键一步。
