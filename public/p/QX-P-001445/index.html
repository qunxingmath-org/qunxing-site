题面

X⊂R² 称 good：存在有理距离集 S⊂R²\cl(X) 使每个 x∈X 都是 S 的极限点。Q1: [0,1]×{0} 是否 good？Q3: 是否存在不共线的无穷 good 集？

形式化表述

Q1: [0,1]×{0} 是否 good；Q3: ∃无穷 good 集 X 不含于任何直线。

人话版

一句话：一条线段，能被一堆“两两有理距离”的点逼近吗？

称平面点集 S 是有理距离集，如果 S 里任意两点的欧氏距离都是有理数。Erdős–Ulam 猜想问平面里有没有稠密的有理距离集，至今未解决。这里提一个玩具版：称 X 是 good 的，如果存在有理距离集 S，它与 X 的闭包不相交，并且 X 的每个点都是 S 的极限点。Q1 问 x 轴上的线段 [0,1]×{0} 是不是 good；Q3 问存不存在由无穷多个不共线的点组成的 good 集。难点是有理距离的约束极强，点集很难既稠密又保持距离有理。

（AI 起草，未经人工审校）

原文摘录

We call a subset $S\subset \Bbb{R}^2$ rationally distanced if all $s_1,s_2 \in S$ have rational Euclidean distance. The Erdos-Ulam conjecture asks if there is a dense subset of $\Bbb{R}^2$ which is rationally distanced. Inspired by this, I came up with the following toy problem. A subset $X \subset \Bbb{R}^2$ is good if there exists a rationally distanced $S \subset \Bbb{R}^2\setminus \overline{X}$ such that each $x\in X$ is a limit point of $S$ .

已知结果与进展

Wojowu：有理距离集必可数 ⇒ Q2 立得；单位圆上有稠密有理距离子集（(3/5+4/5 i)^{2n}）⇒ Q3 可能可由 Cantor 型闭子集构造；Myerson：平面内两两有理距离、无三共线无四共圆的 8 点是否存在都未知（现有纪录 7 点=integral heptagon，与本池 C-722 同族）；Will Brian 指出 Bernstein 集反例边界情形。
