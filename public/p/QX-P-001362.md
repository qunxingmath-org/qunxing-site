# 孤立数（solitary numbers）的密度是否为零

## 题面

没有"朋友"（同 I 值伙伴）的孤立数全体，其自然密度是否为 0？

### 形式化表述

d({n: I(n) 仅被 n 取得}) = 0？

## 人话版

**一句话**：那些找不到朋友的整数，会占到所有整数的百分之几？

对正整数 n，定义 abundancy index I(n)=σ(n)/n，即 n 的因数之和与 n 的比值，它刻画 n 有多丰裕。若存在 m≠n 使 I(m)=I(n)，则称 m 是 n 的朋友；没有朋友的 n 叫孤立数。例如 2、3、4、5 都是孤立数，而 6 与 28 的 I 都等于 2，因此互为朋友（它们都是完全数）。问题问孤立数全体在自然数中的自然密度是否为 0——也就是当 N 很大时，孤立数在 [1,N] 中占的比例是否趋于零。
