# 圆盘覆盖问题r(n)

## 题面

n=1..5已知精确；更大n只有上界构形+下界；正n边形内切类构形为候选最优。

### 形式化表述

r(n) := min 覆盖半径。

## 人话版

**一句话**：用 n 个同样大的小圆盘盖住单位圆盘，半径最小能到多少？

r(n) 是这样一个最小的 r：用 n 个半径都为 r 的闭圆盘，就能把半径 1 的整块单位圆盘完全盖住（允许重叠，也允许伸出边界）。n=1 时显然 r(1)=1；随着 n 增大 r(n) 递减，但下降得越来越慢。输入说明 n=1 到 5 的精确值已经知道，更大的 n 一般只有上界构形与下界估计，其中把 n 个圆心摆成正 n 边形（正多边形内切式构形）是常见的候选最优排布。要解决它，需要给出精确值并证明构形最优。

（AI 起草，未经人工审校）

## 原文摘录

> r(n) = n个半径r的圆盘覆盖单位圆盘的最小r。确定r(n)（n≥?精确值）。
>
> —— Wikipedia: Disk covering problem

## 已知结果与进展

小n精确（Melissen等）；一般n的界；与单位圆内点覆盖对偶。
