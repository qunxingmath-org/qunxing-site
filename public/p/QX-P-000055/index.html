题面

每个 n 阶拉丁方都含一个大小为 n−1 的部分横贯（即 n−1 个两两不同行、不同列、不同符号的单元格）。目前已对一切充分大的 n 证明（Montgomery），剩余为有限多个小阶数。

形式化表述

∀ 拉丁方 L（阶 n）: ∃ 部分横贯大小 = n−1；已知对 n ≥ N₀ 成立（Montgomery 2021/2023），剩余 n < N₀ 有限情形。

人话版

一句话：每个 n 阶拉丁方，都能挑出 n−1 个互不同行、列、符号的格子吗？

横贯是拉丁方里一组格子：两两不同行、不同列、不同符号，大小最多为 n；部分横贯就是允许少几个的版本。Brualdi 猜想：任何 n 阶拉丁方都存在大小为 n−1 的部分横贯。这张卡片的状态标着『部分解决』：Montgomery 对一切充分大的 n 证明了该结论，剩下的是有限多个小阶数没有逐一确认。所以剩余工作量不是新的渐近论证，而是把 n 小于那个阈值的情形逐个攻下——每个 n 需要造出横贯，或证明不存在。

（AI 起草，未经人工审校）

已知结果与进展

  • CB 快照 open（2026-07-23）；源 arXiv:2310.19779
  • Montgomery 2023 证充分大偶阶 n 的 n−1 部分横贯；Glock–Kühn–Lo–Montgomery–Osthus 2021 证大奇阶全横贯（含 n−1）；Hatami–Shor n−O(log²n)、GKLM+ n−√n−o(n) 旧下界
  • 剩余：小于 Montgomery 阈值的有限多个阶数——有限验证目标
  • CB 反例目标（finite=true）: A Latin square for which the maximum partial transversal has size at most n−2.
  • 族/风险注记: Ryser 全横贯猜想（偶阶全横贯）族相邻但不同命题；Montgomery 2021/2023 大n成果为本条主支撑

边界与约定

  • 最小参数: n=1 时 n−1=0（空横贯平凡成立）；n=2 时需大小 1（任一单元格）；小阶数 n≤8 可手工/SAT 全验。任何声称"全 n 证明"必须覆盖 Montgomery 阈值以下全部阶数。
  • 退化/边界约定: "大小 n−1"的精确性——n−O(log²n) 型旧结果不满足本条；等号情形（恰 n−1）不得用更大横贯替代。
  • 约定依赖: Montgomery 的 N₀ 为非有效巨大阈值——"有限验证目标"是原则性有限（剩余阶数有限集合），非实践可枚举；任何"SAT 已全部验完小阶"声明须给出 N₀ 的显式候选上界。
  • 建议独立验证方法（仅描述，不执行）: 对固定小阶 n 用 SAT/ILP 直接求最大部分横贯（与 CB 反例目标同构），独立于 Montgomery 的解析途径；n≤10 已有文献数值可交叉比对。
