# Margulis 对角群轨道闭性猜想

## 题面

n≥3 时 SL_n(ℝ) 对角群 D 的任何相对紧 D-轨道在 SL_n(ℝ)/SL_n(ℤ) 中是闭的。

### 形式化表述

相对紧 ⇒ 闭。

## 人话版

**一句话**：对角群那些有界的轨道，会不会都自动是闭的？

取 X=SL_n(R)/SL_n(Z)，这是模空间上的一类齐性空间，SL_n(Z) 在其中是一个格。D 是 SL_n(R) 里的对角群，即所有对角矩阵组成的子群（行列式为 1），它作用在 X 上。对 X 中一点 x，考察它的 D-轨道 D·x。若这条轨道包含在某个紧集里（称为相对紧），Margulis 猜想（n≥3）断言这条轨道一定是闭的。直观地说：有界就意味着不会无限逼近别的轨道却又不等于它，因此轨道不该有「极限点」逃出自己的闭包。

- 边界：n≥3；D为正对角群；SL_n(R)/SL_n(Z)空间。
- 独立验证建议：候选发散轨道构造沿Huang–Shi定理边界外情形。
