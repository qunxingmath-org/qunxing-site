# Erdos P82: F(n)/log n -> infinity (regular induced subgraph)

## 题面

每个n顶点图都含至少F(n)个顶点的正则诱导子图; 证明 F(n)/log n→∞。

### 形式化表述

F(n):=min over n-vertex graphs of (max regular induced subgraph order); 猜: F(n)≫log n·ω(n) ∀ω→∞. 已知 F(5)=3, F(7)=4。

## 人话版

**一句话**：每个图都藏着不小的正则诱导子图，它到底能有多小？

正则图指所有顶点度数相同的图。对每个 n 个顶点的图，取它能找到的最大正则诱导子图的顶点数；再在所有 n 顶点图里取这个数的最小值，记作 F(n)。问题问 F(n) 的增长速度：猜想它比 log n 快任意多倍，也就是 F(n)/(log n) 趋于无穷。目前连 F(5)=3、F(7)=4 这样的精确小值都只能逐个算出，一般下界还很弱。

## 已知结果与进展

- [PARTIAL] 已知精确小值: F(5)=3, F(7)=4。
- [PARTIAL] Dyson–McKay (2026): 上界改进 F(n)≪n^{1/2}; 相邻函数G(k)下界(9/163)k²。

## 边界与约定

- 最小参数: F(1)…F(7) 可全枚举；已精确 F(5)=3, F(7)=4；F(6) 为难度直觉节指出的待定值——显式微型开放实例，任何声称方法应可落地 F(6)。
- 退化情形: 0-regular（独立集）计入；1-regular（诱导匹配）；空顶点集不计；单点子图恒 0-regular ⇒ F(n)≥1。
- 约定依赖: "regular induced subgraph"=诱导子图所有顶点同度数（度在该诱导子图内计）；F(n) 定义中的 min-max 结构（最坏图的最优保证）。
- 结构性锚点: Erdős–Fajtlowicz–Stanton 已知 c·log n 下界与 DyMc26 的 √n 上界之间的巨大缺口即本题空间；任何声称 F/log n→∞ 的证明必须给出有效 ω(n) 或至少超越常数倍 log n 的显式增长率。
- 建议独立验证方法（仅描述，不执行）: 用 nauty/geng 穷举 n≤7 全部图验证 F(5)=3/F(7)=4 并确定 F(6)（OEIS A120414 交叉）；对声称下界构造在小 n 上机器复验其正则子图的度一致性。
