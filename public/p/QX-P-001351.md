# 五个 N 次单位根之和的最小值 f(5,N) 的精确渐近

## 题面

确定 f(5,N) 的精确渐近阶与常数（Hickerson 上界 O(N^{-2})，无穷多 N 更优；2021 年工作给 O(N^{-4/3}) 一致界与无穷多 N 的 O(N^{-7/3})）。

### 形式化表述

求 liminf_{N→∞} N² f(5,N)（或渐近等价形式）。

## 人话版

**一句话**：五个 N 次单位根相加，离原点最近能近到多少？

一个 N 次单位根指满足 z^N=1 的复数，也就是单位圆上正 N 边形的顶点。把 5 个这样的根（非零和）加起来，模可能很小；f(5,N) 是所有这样的和中模的最小值。Hickerson 证明 N 充分大时 f(5,N) < 8π/(√5·N²)，且对无穷多个 N 有更好的估计；近年工作给出一致界 O(N^{-4/3}) 以及对无穷多 N 的 O(N^{-7/3})。问题是要定出 N²·f(5,N) 的极限行为，也就是精确的渐近常数。

（AI 起草，未经人工审校）

## 原文摘录

> Peter Myerson 问题（AMM [1986, p.457]；Guy 1987 p.967）：f(5,N)=非零"5 个 N 次单位根之和"的最小模。Hickerson 证明充分大 N 时 f(5,N) < 8π/(√5 N²) 且对无穷多 N 更优；精确渐近常数未知。
>
> —— Guy 1987 综述 p.967

## 已知结果与进展

- Hickerson 上界；arXiv:2104.15057 (2021)：f(5,n)=O(n^{-4/3}) 一致、无穷多 n 达 O(n^{-7/3})，计算 n≤221000。
