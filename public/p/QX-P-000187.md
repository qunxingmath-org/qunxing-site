# Happy Ending 问题精确公式（EP#107；原批次 A-018）

## 题面

f(n) 为保证含凸 n 边形的平面（无三点共线）点集最小规模。证明 f(n)=2^{n-2}+1。已知 f(6)=17（Szekeres–Peters 2006）；下界 2^{n-2}+1（ES 构造）；上界 2^{n+O(√(n log n))}（Holmsen–Mojarrad–Pach–Tardos），Suk 2016 得 2^{(1+o(1))n}。

### 形式化表述

求证 f(n) = 2^{n-2}+1（n≥7 起未知；等价于把上界从 2^{n+O(√(n log n))} 压到 2^{n-2}+1）。

## 人话版

**一句话**：要逼出凸 n 边形，2^{n−2}+1 个点这个数刚好够吗？

平面上取一组没有三点共线的点。f(n) 是最小的 m，使得任意 m 个这样的点里必定能挑出 n 个，它们恰好构成一个凸 n 边形的顶点。Erdős 与 Szekeres 造出一批点，数量达到 2^{n−2}+1 却仍不含凸 n 边形，所以 f(n) 至少是 2^{n−2}+1；猜想这也就是精确值。上界一侧长期停在 2^{n+O(√(n log n))}，后来改进到 2^{(1+o(1))n} 的量级。已知 f(6)=17，所以要证的是 n≥7 的全部情形。

（AI 起草，未经人工审校）

## 已知结果与进展

- Erdős–Szekeres (1935): 2^{n-2}+1 ≤ f(n) ≤ C(2n-4, n-2)+1。
- Suk (2016): f(n) ≤ 2^{(1+o(1))n}。
- Holmsen–Mojarrad–Pach–Tardos: f(n) ≤ 2^{n+O(√(n log n))}（页面记录当前最好）。

## 边界与约定

- 边界：n=3..6已知精确值；'无三点共线'前提。
- 独立验证建议：n=7候选f(7)∈{33..?}可程序穷举空隙点集验证下界。

## 相关进展与声称解决

- [PARTIAL] Suk 2016 上界 2^{(1+o(1))n}；HMPT 上界 2^{n+O(√(n log n))}；f(6)=17 已知。
