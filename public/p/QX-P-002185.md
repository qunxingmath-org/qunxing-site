# oligomorphic 群拓扑同构是否光滑

## 题面

oligomorphic 群拓扑同构是否光滑

## 人话版

**一句话**：两个 oligomorphic 群拓扑同构，这个判定问题有多「光滑」？

oligomorphic 群指可数结构上的自同构群，且对每个 n 只有有限多个 n 元轨道；例：对称群 S_∞ 就是 N 上的全对称群。这类群作为拓扑群（取点稳固子群给出的拓扑）编码了对应结构的许多信息。在 Borel 归约的框架里，等价关系按难易分层：「光滑」是最简单的一档，指该等价关系可归约到实数上的相等关系。题目问：在全体 oligomorphic 群上，「拓扑同构」这个等价关系是否光滑。卡片只留标题。
