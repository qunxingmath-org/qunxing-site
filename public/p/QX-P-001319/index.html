题面

C²多项式自同构的稳定性理论（Dujardin-Lyubich弱J*-稳定性）：某稳定性性质是否等价于J*（鞍点周期点闭包）上的结构稳定性？

形式化表述

判定：weak J*-stability ⟺ structural stability on J*（对dissipative多项式自同构）。

人话版

一句话：弱 J*-稳定和 J* 上的结构稳定，其实是同一件事吗？

考虑 C² 上次数 ≥2 的多项式自同构，即由多项式给出、有逆也由多项式给出的映射。J* 是鞍点周期点（一个特征值模大于 1、另一个小于 1 的周期点）全体的闭包，是这类映射的核心动力集。weak J*-stability 指在扰动下 J* 上的动力行为在弱意义下保持；结构稳定性指存在邻域内的映射都与它共轭。问题问这两个性质是否等价：一般动力系统里结构稳定比 J*-稳定强得多，在这里或许恰好一致。

（AI 起草，未经人工审校）

原文摘录

It is an open question whether this property is equivalent to structural stability on the Julia set J* (that is, the closure of the set of saddle periodic points).（Berger-Dujardin, arXiv:1409.4449 摘要）

—— arXiv 预印本（发表版 ENS 2017）

已知结果与进展

原文发表版 Ann. Sci. Éc. Norm. Supér. 50 (2017) 449-477；Dujardin-Lyubich 2013（cited 77）理论框架；Buzzard-Jenkins结构稳定性不稠密；Dujardin-Lyubich PLMS 2025（不连通Julia集双曲模型）；Dujardin 2023综述。

边界与约定

  • 最小参数/退化: Jacobian行列式模<1（dissipative）边界；J*空情形退化（无鞍点——双曲自同构基线支）。
  • 分支/等号: weak J*-stability与J*上结构稳定性的定义精确形式未内联（Dujardin-Lyubich 2013为标准出处——核对受限轻微）；Hénon族为测试域。
  • 独立验证建议（与查新途径不同源）: Hénon映射参数平面上鞍点分叉判据数值实现，比较两稳定性概念的参数域边界。
