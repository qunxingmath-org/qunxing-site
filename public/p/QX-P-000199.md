# Roller Coaster 排列猜想（原批次 A-034）

## 题面

定义 f(π) = 排列 π 的全部子排列中"递增/递减连续段（run）计数"之和。主猜想：对所有 n，roller coaster 排列同时最大化所有子排列的该计数，且有显式公式；Odd Sum 猜想：端点交错排列达到最大。

### 形式化表述

（细节依 OPG 原页公式）对 n≥4，存在 π∈S_n 使 ∀σ∈S_n、∀子排列 π'≤π 与 σ'≤σ 有 f(π')≥f(σ')，且最大值由显式公式给出；以及 Odd Sum 最优性。

## 人话版

**一句话**：有没有一种排列，连同它所有的子排列都把 run 数拉到最大？

排列 π 的一个 run 是它的一段极长的连续上升或连续下降片段（相邻两项一直同向增减）。对每个排列 π，把它的所有子排列（即删去若干元素后保序得到的排列）的 run 总数记作 f(π)。Roller Coaster 猜想断言：存在一类「roller coaster」排列，使它对每个 n 都同时把所有子排列的这个计数推到最大，并且最大值有显式公式。Odd Sum 猜想进一步猜：端点交错（大小关系一上一下交替）的排列达到这个最大值。题面注明公式细节见 OPG 原页。

## 原文摘录

> (OPG, Ahmed–Snevily 2013) Let S_n ... 长度 n 的排列中，使排列与其所有子排列同时最大化交替 run 总数的 "roller coaster permutation"；主猜想给出精确最大值公式，Odd Sum 猜想给出端点交替型构造的最优性（公式细节见题页）。
>
> —— Bull. ICA (2013)；OPG 编录页（2013-10-14 发布，Importance High）

## 已知结果与进展

- Adamczak (arXiv:1605.02415, 2016)：交替结构、"递归交替"强条件研究。
- Adamczak (arXiv:1703.08735, v2 更新 2025-12)：partition number 上界 P_max(n) ≤ ⌊⌈(n−2)/2⌉/2⌋+2；n<15 实验数据支持近乎紧。
- 主猜想与 Odd Sum 猜想均未见解决文献。

## 边界与约定

- 边界：n≥4非平凡；run定义（连续递增/递减段）约定。
- 独立验证建议：n≤12穷举S_n最大值与公式/构造对照。
