题面

Williams 的递归素数生成步骤是否总产出下一素数？

形式化表述

∀n: 该过程的最小缺失奇数 = 第 n+1 个素数？

人话版

一句话：用已知的前 n 个素数造一张乘积表，取最小缺失奇数，拿到的总是下一个素数吗？

假设已经知道前 n 个素数 p₁,…,p_n。规则大致是：对每个 r < p_{n−1} 写出相应的乘积，排成两行，然后在第二行里找最小的、还没出现过的奇数 l，宣称 l 就是第 n+1 个素数 p_{n+1}。问题问这个算法是否对所有 n 都给出正确答案。输入对规则的描述很简略，只有一句“按规则写出乘积、取最小缺失奇数”，细节要按原题核对；难点在于要排除某个 n 上取到合数的可能，而验证只能逐个 n 试。
