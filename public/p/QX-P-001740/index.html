End(R,+) 基数是否可介于 c 与 2^c（MO#342703 交叉帖同悬置）

人话版

一句话：实数加法群的自同构，数量会不会卡在 c 与 2^c 之间？

把 (ℝ,+) 只看成加法群（忘掉乘法与序），它的自同态就是满足 f(x+y)=f(x)+f(y) 的映射。在 ZFC 里这个自同态集合的基数是 c^c，而 c^c=2^c，所以它等于 2^c。若只保留选择公理下的一小部分——比如只算连续的自同态——则只有 c 个，因为连续解只能是 f(x)=kx。这两端分别给出 2^c 与 c。问题问：是否存在模型或被承认的框架，使这个基数严格落在 c 与 2^c 之间，即中间基数能不能在这里实现。做法是先把 ℝ 看成 ℚ 上的向量空间，再对基作置换，这需要选择公理。
