题面

Σ n!/n^n 的无理性

人话版

一句话：把 n! 除以 n 的 n 次方逐项相加，这个和是无理数吗？

级数 Σ_{n≥1} n!/n^n 的通项是 n 的阶乘除以 n 的 n 次方，由 Stirling 公式它约等于 √(2πn)·e^{−n}，所以收敛得极快。题卡问它的和是否为无理数。阶乘让分母很有规律，这个和看起来离有理数很近，这正是难点：常用「分母增长过快故不可能有理」的论证不够用，需要更精细的估计或新工具。
