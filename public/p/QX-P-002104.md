# 幂集函子迭代 Hom 集合有限性（题面修正）

## 题面

幂集函子迭代 Hom 集合有限性（题面修正）

## 人话版

**一句话**：幂集函子迭代几层之后，两个对象之间的映射还会有多少个？

幂集函子 P 把每个集合 X 送到它的幂集 P(X)、把每个映射 f:X→Y 送到「取像」映射 S↦f(S)。对它迭代 n 次得到 P^n。问题问：在集合范畴里，对给定的两个集合，Hom(P^n(X),P^n(Y)) 这个映射全体是否总为有限集，或何时有限。由于 P 把有限集送到更大的有限集、把无限集送到更大的无限集，Hom 集的基数会随迭代方式剧烈变化，需要仔细比较各层幂集的势。
