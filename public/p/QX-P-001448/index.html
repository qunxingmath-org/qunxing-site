Prove or disprove the parametric inequality sum (1-a_i)/(1-a_i^{lambda n}) >= (1-r)/(1-r^lambda)

题面

设 n∈N, λ>1, k=λn, c=(k−1)/(k−n), r=∏aᵢ^c（aᵢ≥0）。证明或否定：Σᵢ (1−aᵢ)/(1−aᵢ^{λn}) ≥ (1−r)/(1−r^λ)。

形式化表述

∀n,λ,aᵢ≥0（按上式参数）：Σᵢ(1−aᵢ)/(1−aᵢ^{λn}) ≥ (1−r)/(1−r^{λ})。

人话版

一句话：把几类难不等式揉成一个带参数的不等式，它到底成立吗？

给定 n 个非负数 a₁,…,a_n，以及 λ>1。记 k=λn，指数 c=(k−1)/(k−n)，再取“加权几何平均” r=a₁^c·a₂^c·…·a_n^c。要判断的不等式是：把每个 aᵢ 分别代入 (1−aᵢ)/(1−aᵢ^{λn}) 再求和，不小于把 r 代入同样形状的 (1−r)/(1−r^λ)。也就是说，逐个算出来的东西加起来不小于整体算的结果。原帖说这是若干个难不等式的统一推广，而通常的手段都不奏效。麻烦出在端点：aᵢ 可以取 0，也可以任意接近 1，此时分式趋近于极限值，要单独处理。

原文摘录

I have posted this question on Stackexchange but it has received no answer so far. It is a challenging generalization of several difficult inequalities, where none of the usual methods used in inequalities seems to work. I would like to know if someone has a deeper insight into what is happening here. Let $n\in\mathbb N$, $\lambda> 1$ and put $k:=\lambda n$ and $c:=\frac{\lambda-\frac 1n}{\lambda-1}=\frac{k-1}{k-n}$. For reals $a_1,...,a_n\ge 0,$ define $ r:=\prod_{i=1}^n a_i^c$.

提问: Wolfgang（2013-10-21），票数 4，无 accepted 答案（2026-11-20 API 核验）；标签: open-problems,inequalities,problem-solving

已知结果与进展

λ→1 极限情形化归为 Σ 1/(1+aᵢ+…+aᵢ^{n−1}) ≥ 1 型（OP 以微积分证明 ∏aᵢ=1 情形一切 n）；n=2,k=3 与其他特例已核；λ∈N 时有"纯倒数"等价形式。
