# batch_I I-060：猜想：若 a³+b³+c³=N 有整数解，则 x³+y³+z³+t³=N 有无穷多组整数解。OP 给出恒

## 题面

猜想：若 a³+b³+c³=N 有整数解，则 x³+y³+z³+t³=N 有无穷多组整数解。OP 给出恒等式 x³+y³+z³+t³=(a³+b³+c³)(p²+(a+b)cq²)³ 与 Pell 方程 p²+(a+b)cq²=1 的路线，问：若 (1) 只有全正解，如何保证存在含负变量的解使 Pell 方程可解？

### 形式化表述

a³+b³+c³=N 可解 ⇒ #{(x,y,z,t): x³+y³+z³+t³=N}=∞。

## 人话版

**一句话**：三个立方能表示 N，就一定有无限多组四个立方吗？

先看三立方问题：整数 a,b,c（允许为负）使 a³+b³+c³=N 的 N 很稀少，很多 N 至今没有解。四立方 x³+y³+z³+t³=N 多了一个变量，宽松得多。猜想是：只要三立方有解，四立方就必有无穷多组解。原帖给出一条路线：用恒等式把四立方和写成 (a³+b³+c³)·(p²+(a+b)cq²)³，再让括号部分等于 1，即解 Pell 方程 p²+(a+b)cq²=1，每解一次就得到一组四立方。难点在于初始的三立方解可能三个数全是正的，此时括号里是正系数，Pell 方程未必有非平凡解。

## 原文摘录

> It is well-known that, $$a^3+b^3+c^3 = N\tag1$$ for $N=1,\,2$ is solvable in the integers in infinitely many ways . However, it is an open question ( but is conjectured ) that if for general $N$ it has a solution, then it must have infinitely many. I'd like to propose a variant, Conjecture: If $a^3+b^3+c^3=N$, then $x^3+y^3+z^3+t^3 = N$ in infinitely many ways. 
>

## 已知结果与进展

OP 恒等式把四立方解归约为 Pell 方程（要求 (a+b)c<0）；Huisman 的 15254 个三立方和解显示可解 N 均有含负变量的解（经验观察）；Pell 方程理论给出无穷多 p,q 一旦初解存在。
