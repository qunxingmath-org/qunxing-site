# Kourovka 8.23：D₁₈ 为 A×B 截断⇒A 或 B 有该截断？

## 题面

D₁₈ 为 A×B 截断⇒A 或 B 有该截断？。

### 形式化表述

[D₁₈ 为 A×B 截断⇒A 或 B 有该截断？：以原文为准；8.23]

## 人话版

**一句话**：18 阶二面体群出现在 A×B 里，就一定已经出现在 A 或 B 里吗？

群 X 的截断指 X 的某个子群的商群，即形如 U/N 的群，其中 N 是 U 的正规子群。截断是比「子群」更宽松的概念：先取子群再商掉正规子群。D 是 18 阶二面体群，即正九边形的对称群，阶为 18。题目设 A×B 有截断同构于 D，问 A、B 中是否至少有一个也以 D 为截断。直积的截断一般不等于因子截断的直积：可以把 A 与 B 的部分拼起来，凑出一个在任一因子中都不出现的截断。这题只涉及一个 18 阶的具体群，若命题为否，反例本应是可明确写出的有限群对，因此思路可以很具体。
