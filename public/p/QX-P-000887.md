# 平面 n 点图的诱导通用图最小阶（OWR 2022/1）

## 题面

包含所有 n 点平面图作为诱导子图的图，最小阶是多少？

### 形式化表述

如上。

## 人话版

**一句话**：要装下所有 n 点平面图，这个「万能图」至少得多少个点？

平面图是能画在平面上而不让边相交的图。一个图叫 n 点平面图的通用图，如果任何 n 个顶点的平面图都出现在它里面。要求「诱导子图」意味着嵌入之后不能多出边，这比允许随意取子图严格得多。问题问：这样的通用图最少要有多少个顶点？因为 n 点平面图数量极多、形状各异，通用图的阶必须明显超过 n，但超多少正是需要确定的数量级。
