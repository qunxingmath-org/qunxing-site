题面

至今未发现任何Euclid数含平方素因子，也未证明全部平方自由。启发式：E_n平方自由概率≈∏(1-1/p^2)≈0.66量级——意味着可能有无穷多平方自由Euclid数，但平方因子反例是否存在未知。

形式化表述

∀n≥1, ∀p素: p^2 ∤ (p_n# + 1)？

人话版

一句话：把前 n 个素数乘起来再加 1，得到的数会不会总有平方因子？

Euclid 数 E_n 定义为前 n 个素数的乘积再加 1，例如 E_1 = 3、E_2 = 7、E_3 = 31。平方自由指没有任何素数的平方整除它。问题问：是否每个 E_n 都是平方自由的？卡片记录：至今没发现任何 E_n 含平方素因子，但也没有证明；按启发式估计，一个随机数平方自由的机会约为 ∏(1−1/p²)≈0.66，这只能说明『可能有』，推不出结论。要否定这道题，只需找到一个 n 使 p² | E_n；要肯定它则要对所有 n 论证。

（AI 起草，未经人工审校）

原文摘录

Euclid数 E_n = p_1·p_2·...·p_n + 1（前n个素数之积加1）是否都是squarefree？

—— Wikipedia: Euclid number

已知结果与进展

MSE#220162 (2012)：方法讨论与启发式0.66；Booker (arXiv:1611.01148) squarefree smooth数相关工作；无反例亦无证明。
（启发式修正注记 2026-11-21，SOL验证Agent：译述"平方自由概率≈∏(1−1/p²)≈0.66"失准——通例值应为 6/π²≈0.608；且对 E_n=p_n#+1 应按条件概率计算：素因子 q≤p_n 时 q∤E_n 自动成立（E_n≡1 mod q），仅 q>p_n 有 q²|E_n 风险，概率 ∏_{q>p_n}(1−1/q²)→1（n→∞）——正确启发式是"E_n 几乎应全为平方自由"，0.66 系未排除小素因子的通例误用。原译述行保留，此注记留痕。）

边界与约定

  • 最小参数: E_1..E_12 手工/机器全分解核验（已知平方自由）；n≤10^4 可 powmod 批量核验。
  • 退化情形: E_1=3（基线）；p≤p_n 自动排除（搜索域仅 q>p_n）；E_n 奇偶性（p_n# 偶 → E_n 奇 → 只查奇平方）。
  • 约定依赖: squarefree 定义；p_n# 记号；"∀p"按素数取遍（自动含 q≤p_n 的平凡排除分支）。
  • 结构性锚点: 固定 p 的模 p² 周期法——p²|p_n#+1 ⟺ p_n# ≡ −1 (mod p²)，n 的周期结构可批量排除（MSE 方法）；反例若存在给出显式 (n,p) 对，机器可验。
  • 建议独立验证方法（仅描述，不执行）: Sage/PARI 重算 E_n 最大平方因子至 n≤10^4；对每个小素数 p 用周期法批量排除 n 域；对声称反例做 (n,p) 双重验证（p²|E_n 且 p>p_n）。
