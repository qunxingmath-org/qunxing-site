# 三元根式不等式最优 k_p

## 题面

√(x+py) 型三元循环根式不等式 k_p（题面修正：平方根）

## 人话版

**一句话**：a/√(a+pb) 这类循环和，最大的系数 k_p 到底是多少？

给定 p>0，要对所有非负实数 a、b、c 求最小的 k_p，使 a/√(a+pb)+b/√(b+pc)+c/√(c+pa) ≤ k_p·√(a+b+c) 恒成立。也就是说 k_p 是左边与 √(a+b+c) 比值在所有 (a,b,c) 上的上确界。原文列出若干已知值：0≤p≤1/2 时 k_p=√(3/(p+1))，k₁=5/4，还给出了 p=3/2、2、4 的显式根式表达式，因此卡片标为部分解决。难点是当 p 较大时取等号的位置不再是 a=b=c，而要解一组高次方程。

## 原文摘录

> Given $p>0$. Find the smallest real number $k_p$ such that the following inequality holds for any non-negative reals $a,b,c$:
> $$\frac{a}{\sqrt{a+pb}}+\frac{b}{\sqrt{b+pc}}+\frac{c}{\sqrt{c+pa}} \le k_p \sqrt{a+b+c}.$$
> Some particular cases:
> $k_p = \sqrt{\frac{3}{p+1}}$ for $0\le p\le \frac{1}{2}$.
> $k_1=\frac{5}{4}$.
> $k_{3/2} = \frac{2\sqrt{6}-3\sqrt{2}}{\sqrt{-1+\sqrt{3}}}+\sqrt{-5+3\sqrt{3}}$.
> $k_2 = \frac{2\sqrt{3}-2}{\sqrt{2\sqrt{3}}}+\sqrt{-1+\frac{2}{\sqrt{3}}}$.
> $k_4 = \frac{17 -\sqrt{33}}{6\sqrt{-1+\sqrt{33}}}+\sqrt{\frac{-5+\sqrt{33}}{12}}$.
>
