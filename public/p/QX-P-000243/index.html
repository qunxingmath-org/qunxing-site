题面

任意凸多边形是否可剖分为 n 个面积与周长都相等的凸块？

形式化表述

∀凸多边形 P, ∀n∈N, ∃凸块 P_1,…,P_n: ∪P_i=P, area(P_i)=area(P)/n 且 perim(P_i)=perim(P)/n。

人话版

一句话：能不能把一个凸多边形切成 n 块，让每块的面积和周长都恰好相等？

把凸多边形 P 用不相交的凸块 P_1,…,P_n 铺满（只允许在边界上重叠），要求每块面积都是 area(P)/n，同时周长都是 perim(P)/n。只要求面积相等时，从任意一点放射状切分即可做到；再要求周长也相等就难了，因为落在原多边形边上的那一段长度也必须精确配平，各块的短边要彼此补偿。题卡标注为部分解决：某些特殊多边形或某些 n 已有构造，一般情形还没有定论。

  • n=2 容易；n=3、素数 n 为公认目标（OPG 页）。

边界与约定

  • 边界：剖分=闭包覆盖且内部不交；n=1平凡。
  • 独立验证建议：n=3数值构造（等面积+等周长离散化）验证可行性。
