# 类 Collatz 素数阶乘迭代

## 题面

primorial 递推 aₙ=(aₙ₋₁·n)/p# 是否回到 1（题面修正）

## 人话版

**一句话**：先乘 n 再除掉能除掉的最大素积，这个序列会一直回到 1 吗？

第 n 个素积（primorial）指前 n 个素数的乘积，这里把 2 算作第一个素数，所以 0 阶素积是 1。规则是：从 a₀=1 出发，第 n 步把上一步的数乘以 n，再除以「能整除结果的最大素积」，得到 a_n。原文演算：a₁=1；第 2 步得 2，2 能整除 2（素积），所以 a₂=1；之后变得越来越有意思。题目问的是这个序列是否总回到 1，也就是是否会卡在 1 以外的循环里或无限增长。它像 Collatz 问题一样规则极简，却没有明显的单调性或不变量可用。
