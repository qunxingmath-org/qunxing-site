题面

确定 R³ 中 n 条直线的 Voronoi 图的最坏组合复杂度（及构造算法）。

形式化表述

确定 max|D(L_n)| 的精确量级（n² ≤ f(n) ≤ 已知上界）。

人话版

一句话：n 条空间直线把 R³ 切成最近邻区域，最多能切出多少块？

对 R³ 中 n 条直线，一点到某条直线的距离用通常的欧氏距离衡量。离哪条直线最近就把空间中的点分给哪条，得到的区域划分就是这 n 条直线的 Voronoi 图；问题问它的组合复杂度（顶点、边、面、胞腔总数）在最坏情况下随 n 增长的确切量级。已知这类图可能远大于线性，具体指数仍未定，与之配套的还有如何高效构造它的算法问题。
