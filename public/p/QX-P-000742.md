# Erdős #547：树 Ramsey 数 R(T)≤2n−2（Burr 精确形式）

## 题面

每个 n 顶点树 T 满足 R(T,T) ≤ 2n−2（Burr 猜想精确形式，Erdős #547）。

### 形式化表述

树的二色 Ramsey 数上界 2n−2。

## 人话版

**一句话**：两色染色下，多大的完全图能保证出现指定的 n 点树？

对图 H，R(H,H) 是最小的整数 N，使得把 K_N 的边任意染成两色时，必有一种颜色里出现一个与 H 同构的副本。问题断言：若 T 是任意 n 个顶点的树，则 R(T,T)≤2n−2。这比一般估计更精确，而且界与树的具体形状无关，只依赖顶点数。要解决它，需对这个上界给出对所有树的统一证明，或找出打破它的树。
