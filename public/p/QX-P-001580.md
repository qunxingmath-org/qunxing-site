# 21.52 单群对合类着色完全图的自同构群刻画

## 题面

L 有限单群，D 为对合共轭类，完全图 Γ 顶点集 D，边按 |ab| 等价着色。是否着色图自同构群 = Aut(L)∩（由类稳定化子诱导）？

### 形式化表述

Aut(Γ) 的刻画。

## 人话版

**一句话**：只看对合之间乘积的阶，能还原出群自身的自同构吗？

设 L 是非交换有限单群，D 是 L 中由对合（2 阶元）组成的某一个共轭类。以 D 为顶点画完全图 Γ，并把边按两端点乘积的阶着色：两条边 (a,b) 与 (c,d) 同色当且仅当 |ab|=|cd|。着色图的自同构指 D 上的置换 τ，使每条边与它的像同色。题目问：Γ 的着色自同构群是否总落在 Aut(L) 之内？也就是这些纯粹由「对合乘法的阶」保留下来的置换，是否一定能由 L 的自同构（或某个类稳定化子）实现。

> Let L be a finite non-abelian simple group, and let D be a conjugacy class
> of involutions in L. Consider the complete graph Γ with vertex set D. Define an
> equivalence relation ∼(graph coloring) on the set of edges as follows: (a, b) ∼(c, d)
> if and only if |ab| = |cd|. An automorphism of the coloured graph Γ is a permu-
> tation τ ∈SD such that (a, b) ∼(aτ, bτ) for every edge (a, b). Is it true that the
> automorphism group of Γ is a subgroup of Aut(L)?
> I. B. Gorshkov
