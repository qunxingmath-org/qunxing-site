# Kourovka 20.47：极小+强近端作用必拓扑自由？

## 题面

极小+强近端作用必拓扑自由？。

### 形式化表述

## 人话版

**一句话**：忠实、极小又强近端的自由群作用，一定拓扑自由吗？

设 G=F_n 是秩 n 的自由群，X 是紧空间，G 连续作用在 X 上。忠实指只有单位元作用为恒等；极小指 X 没有非空的真正闭不变子集；强近端指 X 上任意概率测度的轨道闭包的凸包中总含有点质量。拓扑自由指每一点的稳定子都平凡的那些点构成稠密集，等价于：每个非单位元的不动点集内部为空。题目问：这三条一起能否推出拓扑自由——即极小性是否已经排除了「有一块开集被某个非单位元整体固定」的可能。

（AI 起草，未经人工审校）
