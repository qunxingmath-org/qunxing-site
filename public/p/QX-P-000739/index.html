题面

凸 n 边形的某顶点到其余顶点至少有 ⌊n/2⌋ 个不同距离（Erdős #982）。

形式化表述

凸位置 n 点集 ⇒ max_v d_dist(v) ≥ ⌊n/2⌋。

人话版

一句话：凸 n 边形中，总有一个顶点量出至少 ⌊n/2⌋ 种不同距离吧？

取平面上处于凸位置（所有点都是凸包顶点）的 n 个点，例如一个凸 n 边形的顶点。从一个顶点出发可以量出它到其余 n−1 个点的距离，其中可能有些距离相等，去重后得到不同距离的个数。问题断言：至少存在一个顶点，其不同距离数不少于 ⌊n/2⌋。原始输入标明该问题已部分解决。要解决它，需对一切 n 与一切凸位置点集给出证明。

（AI 起草，未经人工审校）
