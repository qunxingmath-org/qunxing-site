# 正 n 边形对角线剖分最大胞面积

## 题面

正 n 边形对角线剖分最大胞面积

## 人话版

**一句话**：只用对角线把正 n 边形切开，最大那块面积最小能压到多少？

取一个正 n 边形，用一组互不相交的对角线把它切成若干块多边形，这种切法叫对角线剖分（只切到三角形就是三角剖分）。每块都有确定的面积，记下其中最大的一块。题目问：在全部对角线剖分里挑一种，使这块最大面积尽量小，并求出那个最小值；另一种读法是让最大块尽量大，卡片没有写明是哪一种。固定 n 时剖分只有有限多种，可以逐个枚举算出答案，所以单个 n 的数值是可算的；难的是对所有 n 给出统一公式，并证明任何切法都无法更好。
