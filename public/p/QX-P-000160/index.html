题面

能否用 n 种颜色染正整数，使对每个 a，a,2a,...,na 两两不同色？

形式化表述

∀n, ∃c: Z^+→[n]: ∀a, ∀1≤i<j≤n, c(ia)≠c(ja)。

人话版

一句话：只用 n 种颜色，却要让 a,2a,…,na 每一步都换色，做得到吗？

问题要给全体正整数染上 n 种颜色，并要求：不论取哪个正整数 a，等比数列 a、2a、3a、…、na 这 n 个数两两都不许同色。文件形式的写法是：对任意 a 和任意 1≤i<j≤n，都要 c(ia)≠c(ja)。这条要求沿着每个 a 的倍数链施加约束，而所有链彼此重叠，无法独立处理；数量上每种颜色平均要用在无穷多个数上，所以只能靠全局的周期或对偶构造。输入记录说这题目前只被部分解决，因此不能假定答案已知为是或否。

已知结果与进展

1) n+1 素数情形：Dorais + Kuperberg/Protsak 推广（Chebotarev）；2) n=3：首个具体染色；3) Fedor Petrov：等价于相关图无 (n+1)-团（难命题）；4) domotorp 反例：图非完美（induced C5）；5) Caicedo/Chartier 硕士论文部分限制；6) 计算验证 n<30 及更大周期染色。

边界与约定

  • 边界：n=1平凡；n=2即2染色奇偶；n+1素数已证。
  • 独立验证建议：n=3..6候选染色可程序验证条件∀a∀i<j c(ia)≠c(ja)（周期染色有限检验）。
