# 行和 r 列和 c 的 0-1 矩阵精确计数公式（AMM E2794）

## 题面

给出 (0,1)-矩阵（行和均 r、列和均 c）计数的精确公式。

### 形式化表述

N(m,n,r,c) := #{A∈{0,1}^{m×n}: 每行和 r, 每列和 c}（rm=cn）；求闭式/有效精确算法。

## 人话版

**一句话**：每行和都是 r、每列和都是 c 的 0-1 矩阵，到底有多少个？

0-1 矩阵指每个元素只取 0 或 1；“每行和 r”就是每行恰有 r 个 1，“每列和 c”就是每列恰有 c 个 1，条件 rm=cn 保证 1 的总个数对得上。问题要的是精确公式（或真正能执行的精确算法），不是估计。这类矩阵等价于给定行列度序列的二分图计数，一般参数下没有简单的乘积公式，通常要用对称函数或容斥来写。
