题面

Trappist-1（无限象棋变体）mate-in-n 可判定性

人话版

一句话：在无限棋盘的这个变体里，能不能用算法判定一方能否 n 步将死对方？

无限象棋指棋盘没有边界、棋子可以无限远地走。mate-in-n 问题问：给定局面，先手是否存在至多 n 步内必胜（将死）的下法，且对所有应手都成立。它是有限回合的量化问题，因此对每个 n 都是有限的搜索，但在无限棋盘上可能的走法有无穷多，搜索树不像有限棋盘那样能穷尽。Trappist-1 是其中一个变体，卡片没有给出它的具体规则（棋子种类、走法与棋盘形状）。题目问的是：这个变体的 mate-in-n 是否可判定，即是否存在一个对所有局面和所有 n 都正确终止的算法。
