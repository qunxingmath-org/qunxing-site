# 环面网格交叉数 cr(C_m□C_n)=m(n−2)

## 题面

环面网格交叉数 cr(C_m□C_n)=m(n−2)

## 人话版

**一句话**：两个圈做笛卡尔积画在平面上，最少要交叉几次？

C_n 是 n 个点围成的圈，即 n 边形。C_m□C_n 是两圈的笛卡尔积：把 m 个 C_n 一圈圈摊开再同向连边，得到画在环面上的 m×n 网格，m 行 n 列。把它画到平面上（边可以是任意曲线）时，至少要有多少个交叉点，就是它的交叉数 cr；交叉只算两条边内部的交点，且不许三条边同交一点。卡上的命题是 cr(C_m□C_n)=m(n−2)。要证否只需画出交叉更少的图；要证实则须证明任何画法都至少交叉这么多次。卡上把状态标为部分解决，但没有列出究竟是哪些参数组合已有定论。
