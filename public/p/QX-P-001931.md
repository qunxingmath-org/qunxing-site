# k⁴+1 型 3-伪素数

## 题面

k⁴+1 型 3-费马伪素数

## 题面草稿（AI 起草，待核）

设 $k$ 为正整数，$N:=k^{4}+1$，且设 $N$ 为合数。问：$N$ 能否是以 $3$ 为底的费马伪素数，即同余式
$$3^{N-1}\equiv 1 \pmod{N}$$
是否可能成立？等价地，对形如 $k^{4}+1$ 的数，以 $3$ 为底的费马检验是否实际上已足以判定素性？（原文报告：检验到 $k=10^{8}$ 未发现例子。）

## 人话版

**一句话**：k⁴+1 这种形状的合数，能骗过以 3 为底的费马检验吗？

若 N 是合数却满足 3^{N−1}≡1 (mod N)，就称 N 是以 3 为底的费马伪素数——它会让「用费马小定理判素」的检验出错。题目限定 N=k⁴+1（k 为正整数，且 N 本身是合数），问这样的 N 能否成为 3-费马伪素数；等价地问：对 k⁴+1 这种形状，以 3 为底的费马检验是不是已经足够判素。原文报告检验到 k=10⁸ 都没有反例。难点在于排除所有 k 需要处理 k⁴+1 的因子结构，而它并非总是容易分解。
