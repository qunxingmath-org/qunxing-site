# 21.89 n>39 时 p(n) 整除 n! 永不成立？

## 题面

（MacHale）n>39 时，Sn 的共轭类数 k(Sn)=p(n)（分拆数）是否永不整除 |Sn|=n!?（数表验证+解析论证，A层：可计算验证型。）

### 形式化表述

∀n>39: p(n) ∤ n!。

## 人话版

**一句话**：40 以后，分拆数 p(n) 会不会再也不能整除 n! 了？

p(n) 是 n 的整数分拆数，也就是把 n 写成若干个正整数之和的方法数；它同时等于对称群 Sₙ 的共轭类个数。问题（MacHale 提出）问：当 n > 39 时，p(n) 是否永远不整除 n! = 1·2⋯n？等价说法是：n > 39 时，Sₙ 的共轭类个数永远不是群阶的因子。要否定它，只需找到一个 n > 39 使 p(n) 整除 n!；要证明它，需要对所有更大的 n 控制 p(n) 的素因子与 n! 中可用的指数，通常要借助 p(n) 的增长估计。

## 已知结果与进展

p(n) 渐近已知；小 n 可全验；一般论证无文献（检索无命中）。

## 边界与约定

- 最小参数: n=40 起（命题域起点）——p(40) 是否整除 40! 的机器核验是第一锚点；n≤39 的整除例清单（历史背景）可帮助识别结构。
- 退化情形: p(n) 的奇偶（Landowski/Cayley 型 parity 结果——p(n) 奇时整除与否的另一路径）；素因子重数比较 v_q(p(n)) vs v_q(n!)（核心论证形态——p(n) 的素因子须在 n! 中充分出现才整除）。
- 约定依赖: 整除标准定义；p(n) 分拆数；n>39 严格。
- 结构性锚点: p(n) 渐近 ~exp(π√(2n/3))/(4n√3)——p(n) 与 n! 的素因子谱（n! 含所有 ≤n 素因子，p(n) 的素因子可 >n——大于 n 的素因子不整除 n! 即得否定，这是候选论证路线）。
- 建议独立验证方法（仅描述，不执行）: PARI 独立验证 n≤10^5 全部 p(n)∤n!（p(n) DP 计算+大整数整除）；对声称证明检查其对 p(n) 素因子 >n 情形的覆盖率。
