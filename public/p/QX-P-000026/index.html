题面

稀疏标尺问题: F(N)=使{0..N}⊆A−A的最小|A|; 求极限F(N)/√N的值。

形式化表述

lim_{N→∞} F(N)/N^{1/2} = ? (极限存在, Erdős–Gál 1948; 值∈[1.56,√3≈1.732]; Pegg 2020计算支持Wichmann构造√3为真值。)

人话版

一句话：用最少的刻度量出 0 到 N 的每个长度，刻度数除以 √N 会趋于多少？

稀疏标尺问题：取一小组整数刻度 A，要求 0,1,…,N 每个数都能写成两个刻度之差（即 {0,…,N} 落在 A−A 里），最少需要多少刻度记作 F(N)。Erdős 与 Gál 1948 年证明 F(N)/√N 的极限存在，但没定出它的值。卡片记录：该极限夹在 1.56 与 √3≈1.732 之间，Pegg 2020 年的计算支持 Wichmann 构造给出的 √3 就是真值。问题就是确定这个极限数：需要新的构造压低上界，或新的论证抬高下界。

（AI 起草，未经人工审校）

已知结果与进展

  • [PARTIAL] Erdős–Gál (1948): 极限存在。
  • [PARTIAL] Wichmann构造: 上界√3; 下界1.56。
  • [PARTIAL] Pegg (2020): 大规模计算支持√3。

边界与约定

  • 最小参数: F(N) 精确序列（OEIS A046693）——小 N 全枚举/SAT 可达 N≤200；F(N)/√N 序列对 Wichmann 渐近线 √3 的单调逼近行为是数值检查点。
  • 退化情形: 0∈A、N∈A 必要（见上）——构造搜索可 WLOG 固定这两点；A−A 覆盖按无序差（|a−a'|∈[0,N]）而非有向差；N=0,1 平凡（F=1/2）。
  • 约定依赖: "size"=A 的元素个数；差集允许负差（覆盖的是绝对位置 0..N）；极限值未指定精度目标（常数问题）。
  • 结构性锚点: Wichmann 构造的周期结构（√3 渐近）与下界 1.56 的计数/组合论证之间的缺口——声称解决须封口一端：给出 F(N)≥(√3−o(1))√N 下界或构造 <√3 上界构造。
  • 建议独立验证方法（仅描述，不执行）: ILP/SAT 独立求 F(N) 至 N≤200（与 Pegg 2020 实现不同源）；对 Wichmann 构造独立复算其覆盖性与渐近常数；对声称下界改进审查其计数参数。

相关进展与声称解决
