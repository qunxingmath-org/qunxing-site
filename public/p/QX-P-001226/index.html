题面

永恒支配（eternal domination）参数链中的具体间隙问题：三个参数是否可取两个相等而第三个严格更大。

形式化表述

∃ G: γ(G)=γ_∞(G) 且 γ_∞(G)<θ(G)。

人话版

一句话：能不能找一张图，让两个控制参数相等、第三个严格更大？

在图里，支配集是一批顶点，使得每个顶点要么自己在这批点里、要么与其中一个相邻，相当于每个位置都有看守照看得到；支配数 γ(G) 是这种集合的最小大小。永恒支配是把看守摆在顶点上，攻击者每次攻击一个顶点，看守要沿边移动过去应战，并且要求无论攻击多少次都能应对；所需最少看守数记作 γ_∞(G)。θ 是这条参数链上的另一个控制参数（原卡片写作全支配数？，本身带问号，需核对）。问题问：是否存在图使 γ 与 γ_∞ 相等、而 θ 严格更大。

（AI 起草，未经人工审校）

原文摘录

是否存在图G使 γ(G)=γ_∞(G)<θ(G)（支配数=永恒支配数<全支配数?θ为特定控制参数）。

—— Wikipedia: Eternal dominating set
