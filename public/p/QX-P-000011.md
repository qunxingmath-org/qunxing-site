# Erdos P36: minimum overlap problem constant c

## 题面

最小重叠问题: [1,2N]等分A,B, 必存在位移x使差a−b=x的表示数≥cN。求最优常数c。

### 形式化表述

c* = inf over equal partitions of max_x #{(a,b)∈A×B: a−b=x}; 求 c*。已知 0.379005<c*<0.380876。
（核对修正注记 2026-11-21，SOL验证Agent：原形式化漏掉 N→∞ 层——原文要求"对所有充分大 N"一致成立，故精确定义为 c* = liminf_{N→∞} [ min over 等分 A⊔B={1,…,2N}, |A|=|B|=N of ( max_{x∈Z} #{(a,b)∈A×B: a−b=x} ) / N ]。固定 N 的 inf 只是有限值 c*(N)；本条已知窗口 0.379005<c*<0.380876 针对渐近常数。已补 liminf 层并留痕。）

## 人话版

**一句话**：把 {1,…,2N} 平分成两半随意错位，最大的重合能压到多小？

把 1 到 2N 这 2N 个数分成两个各 N 个的集合 A 和 B。对每个整数位移 x，数一数有多少对 (a,b) 满足 a−b=x，取这些数里最大的一个。这个最大值最多能被压到多小，除以 N 后当 N 趋于无穷，就得到常数 c。问题是要确定 c 的确切值。目前只知道它夹在 0.379005 和 0.380876 之间，上下界的缝隙还很明显。

（AI 起草，未经人工审校）

## 边界与约定

- 最小参数: N=1（A={1},B={2} 等 2 种等分，max_x 计数=1, c*(1)=1）；N=2..100 可精确 ILP/SAT 求 c*(N) 全序列——渐近常数与 c*(N) 序列的关系本身是检查点。
- 退化情形: x=0（A∩B=∅ 不相交 ⇒ 0 个表示）；负 x 与正 x 对称性（A,B 互换+反射可将 x→−x，构造验证时可减半搜索）；2N 必为偶（N≥1 整数）。
- 约定依赖: 表示数按有序对 (a,b)∈A×B 计；"sufficiently large"的阈值未显式——声称的常数必须指明其下界对所有 N≥N₀ 成立并给出 N₀。
- 结构性锚点: 区间型构造（否定 c=1/2）与 AI 构造（AlphaEvolve 2025、TTT-Discover 2026）均给出显式等分模式——任何新纪录必须同时给出: 下界证明（对所有等分）或上界构造（可机器复算 max_x 计数）。
- 建议独立验证方法（仅描述，不执行）: 对 N≤200 用 ILP 精确计算 c*(N) 下界序列（独立于 White 的 Fourier/组合论证）；对 2025/2026 AI 构造逐项复算 max_x 表示数核验 0.380876 上界；OEIS A393584 序列交叉比对。
