# Log-Rank 猜想

## 题面

通信复杂度中 log-rank 与确定性通信复杂度的多项式关系。

### 形式化表述

D(f) ≤ poly(log rank(f))。

## 人话版

**一句话**：只看到通信矩阵的秩，就能估出它需要多少通信量吗？

两方通信模型中，Alice 与 Bob 各持输入的一部分，要合力算一个函数 f；把 f 写成一个 0-1 矩阵 M（行是 Alice 的输入、列是 Bob 的输入）。这个矩阵在实数上的秩 rank(M) 是一个简单的线性代数量，而确定性通信复杂度 D(f) 是双方在最坏情况下交换的最少比特数。已知 D(f) ≥ log₂rank(M)，log-rank 猜想断言反向也有多项式关系：D(f) ≤ (log rank(M))^c 对某个常数 c 成立。
