# 整数复杂度：Mahler–Popken f(n) 的 Selfridge 2f(x)+11 与 Isbell–Myerson 2f(x)+13 差距

## 题面

用最少 1 和加法乘法表示 n 的代价 f(n)：是否存在 x 使 f((3x+1)^2+6) = 2f(x)+13（Selfridge 只排除了 13 以上的情形，证明 ≤ 2f(x)+11）。

### 形式化表述

∃x∈N: f((3x+1)^2+6) ≥ 2f(x)+12？（更一般：确定缺陷 δ(n)=f(n)−3log₃n 在此类合成数上的精确最大值。）

## 人话版

**一句话**：用最少的 1 表示 (3x+1)²+6，能不能比 2f(x)+11 更费劲？

整数复杂度 f(n) 是只用数字 1、加号、乘号和括号写出 n 所需的最少 1 的个数，例如 f(1)=1、f(2)=2（1+1）、f(3)=3（1+1+1）、f(4)=4（(1+1)×(1+1)）。Mahler 与 Popken 提出研究它的增长，缺陷 δ(n)=f(n)−3log₃n 衡量实际表示比理论下界差多少。Isbell 与 Myerson 猜测存在形如 (3x+1)²+6 的数使 f(n) 大到 2f(x)+13；Selfridge 只证得上界 2f(x)+11，两者之间还留着缺口。

## 原文摘录

> Mahler–Popken 问题（AMM [1986, pp.186–189]；Guy 1987 综述 p.965）：f(n)=最少 1 的个数（用 +、× 与括号表示 n）。Isbell–Myerson 猜测存在 n=(3x+1)^2+6 型数使 f(n) 大到 2f(x)+13；Selfridge 证明上界 f(n) ≤ 2f(x)+11——差距未闭合。
>
> —— AMM [1986, pp.186–189]；Guy 1987 p.965

## 已知结果与进展

- Selfridge 上界 2f(x)+11；整数复杂度领域 2012+ 高度活跃（Altman–Zelinsky 2012 "low-defect"、Altman INTEGERS 2018 综述、Zelinsky 系列）。
- 已知 f(n) ≥ 3log₃n；f(2p) 型猜想被否定（Steinerberger 2014）。
