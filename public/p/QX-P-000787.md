# Erdős P19：n 个边不交 K_n 的并图色数=n（$500悬赏）

## 题面

若一个图是 n 个边不交 K_n 副本的并，则其色数恰为 n。

### 形式化表述

G = ⊔ᵢ₌₁ⁿ K⁽ⁱ⁾（K⁽ⁱ⁾≅K_n 且边两两不交）⇒ χ(G) = n。悬赏 $500。

## 人话版

**一句话**：n 个边不交 K_n 叠在一起，色数恰好是 n 吗？

取 n 个 K_n 的副本，把它们的顶点合并到一起（不同副本的顶点允许重合），但要求任意两条边都不重复，也就是这些完全图彼此边不交。这样的图记为 G。题目断言：色数 χ(G) 恰好等于 n。下界是自动的，因为每个 K_n 副本自己就需要 n 种颜色，而 G 的边包含它们；真正要证的是上界，即存在一种只用 n 种颜色的染法，同时满足所有副本。难点在于副本之间共享顶点，一个副本上的染色选择会把约束传导到别处。这是 Erdős 问题 P19，附 500 美元悬赏。
