题面

n 边形全部三角剖分族 T_n（|T_n|=C_{n-2}）中，两两有公共对角线的子族 S 是否必有 |S| ≤ |T_{n-1}|=C_{n-3}？

形式化表述

max{|S|: S⊂T_n 两两共对角线} =? C_{n-3}。

人话版

一句话：两两共用一条对角线的三角剖分，最多能有几个？

正 n 边形（顶点已固定）的三角剖分，是用 n−3 条互不相交的对角线把它切成 n−2 个三角形的分法，总数为 Catalan 数 C_{n−2}。若一族三角剖分里任意两个都至少共用一条对角线，就称这族是相交族。问题问：相交族最多能有多少个？猜想的答案恰好是 C_{n−3}，也就是 n−1 边形的三角剖分数。候选的构造是“所有包含某条固定对角线的三角剖分”，它的个数正正好是 C_{n−3}，所以只需证明没有更大的相交族。这是典型的极值计数问题，答案若真为 C_{n−3}，就必须对所有 n 一致地给出上界。

已知结果与进展

1) Robert Frost 部分观察（非证明）；2) Stump 等 arXiv:1710.02518：嵌入纯 flag 单纯复形相交族更大猜想族，dim≤3 已证；3) Zaimi 更一般多面体版本被 Bruno Le Floch 反例否证（环面/金字塔反例），Santos 提出修正中间猜想；4) 主问题 n 一般开放。

边界与约定

  • 边界：n=3无对角线（T_n单点）；n=4星形唯一；等号情形n≥5待查。
  • 独立验证建议：n≤8全枚举三角剖分图的最大相交子族验证|S|=C_{n-3}。
