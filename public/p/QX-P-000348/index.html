Lehmer's totient problem: is there a composite n with phi(n) dividing n-1?

题面

不存在合数 n 使得 φ(n) 整除 n−1。

形式化表述

∀n∈N [φ(n) | (n−1) → n 为素数]。

人话版

一句话：有没有合数 n 让 φ(n) 整除 n−1？至今一个都没找到。

φ 是欧拉函数，φ(n) 表示 1 到 n 中与 n 互素的整数个数。对素数 p 有 φ(p)=p−1，所以每个素数都满足 φ(n) 整除 n−1。Lehmer 在 1932 年问：满足这个整除条件的 n 会不会只有素数，也就是说不存在这样的合数？人们做了大量计算与同余分析，一个反例也没找到，但也无法排除；已知若有这样的 n，它必须同时满足许多苛刻的条件。只要回答存在或不存在。

（AI 起草，未经人工审校）

原文摘录

D. H. Lehmer (1932): There is no composite number n such that φ(n) divides n−1. (AMM Unsolved Problems column [1973, p.192]; Guy, Monthly Unsolved Problems 1969–1987, AMM 94(10) 1987, 961–970)

—— Guy, "Monthly Unsolved Problems, 1969–1987", Amer. Math. Monthly 94(10) (1987) 961–970

已知结果与进展

  • 任一反例必为奇、无平方因子、Carmichael 数；素因子个数下界经 Cohen–Hagis(1980)≥14 → 2024 年新结果 ≥16（附 Lean 形式化与程序，GitHub eLhmr, Deep Bhattacharjee）。
  • Pinch 计算排除至大界；与 Giuga 猜想相关（Banks 2009）。

边界与约定

  • 边界：n=1平凡（素数档）；合数限定。
  • 独立验证建议：Pinch式搜索上限扩展+Carmichael数生成器定向检验。

相关进展与声称解决

  • [PARTIAL] 素因子个数下界持续改进（14→16，2024）；偶有"解析证明"预印本（arXiv 1608.08086 等）未被接受。
