# Schoenberg 密度函数的可微性（EP#50；原批次 A-008）

## 题面

f(c) 为 {n: φ(n)<cn} 的自然密度（Schoenberg 证明存在）。是否不存在这样的 x：f 在 x 处可导且导数为正？

### 形式化表述

∀x∈[0,1]，若 f'(x) 存在则 f'(x) ≤ 0（等价：f 无"正导数可微点"）。

## 人话版

**一句话**：让 φ(n)<cn 的密度函数 f(c)，能在某点带着正斜率可导吗？

φ 是欧拉函数：φ(n) 是 1 到 n 中与 n 互素的正整数个数，通常 φ(n) 比 n 小不少。对每个 c∈[0,1]，考虑所有满足 φ(n)<cn 的正整数 n 构成的集合，它的自然密度（前 N 个整数中占比的极限）存在，记作 f(c)。f 单调不减，c 从 0 涨到 1 时 f 从 0 涨到 1。问题问：f 会不会在某个 x 处可导并且导数大于 0？猜想是不会——f 只允许以「不上升」的方式可导。难点在于 f 是由 φ 的分布拼出来的极限函数，结构非常不规则。

（AI 起草，未经人工审校）

## 已知结果与进展

- Schoenberg（1928）：密度处处存在。
- Ford (1999)：φ 值集密度为 0（相邻工具性结果）。

## 边界与约定

- 边界：c=0,1端点密度退化；f单调不减故导数≥0——问句即排除>0。
- 独立验证建议：f数值逼近（φ(n)分布）检验可疑可微点的差商符号。
