题面

存在群 G 含有限指标子群族 (Gn)，使每个 Gn 有同态 fn:Gn→Z 其核为型 Fn 但非 Fn+1？

形式化表述

∃G, Gn≤G f.i., fn:Gn→Z, ker fn of type Fn not Fn+1 ∀n ?

人话版

一句话：能不能造一个群，让同调有限性的台阶被一级一级地削掉？

type F_n 是同调有限性条件的一个层级：群有长度有限的自由消解，且前 n 步的模都有限生成；n 越大要求越强，对所有 n 都成立则称 F∞ 型。题目问：是否存在群 G，含有一族有限指标子群 (G_n)_{n∈ℕ}，使每个 G_n 都有满同态 f_n:G_n→Z（整数加法群），而核 ker f_n 恰好是 F_n 型但不是 F_{n+1} 型？也就是用有限指标的切片，把同调有限性的层级一级一级地压低一级。

（AI 起草，未经人工审校）

提出人：E. Schesler
Does there exist a group G that contains a family (Gn)n∈N of finite-index
subgroups such that for every n there is a homomorphism fn : Gn →Z whose kernel
is of type Fn, but not of type Fn+1?
E. Schesler
