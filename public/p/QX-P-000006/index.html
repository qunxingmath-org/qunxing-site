A coefficient criterion for power series bounded on the real line

题面

对处处收敛的幂级数 f(x)=Σ a_n x^n，给出系数序列 (a_n) 使得 f 在整条实轴上有界的充要判据。已知：若 f 有界则 a_0 是唯一非零系数，或存在无穷多个非零系数且符号无穷多次变化；有界幂级数全体构成线性子空间且为代数；包含一切 g(x²)（g 为整函数且在 [0,∞) 有界）。问：该子空间是否恰好只有这些函数？

形式化表述

令 B = { (a_n)∈R^N : Σ a_n x^n 对所有 x∈R 收敛且 sup_{x∈R} |Σ a_n x^n| < ∞ }。
(1) 刻画 B 的元素特征（充要判据）。
(2) B 是否 = { 系数与 g(x²) 一致的级数 : g 整函数、有界于 [0,∞) } ∪ { (a_0,0,0,…) }？
（已知 B 是实线性子空间、对乘法封闭（是 R-代数），且包含所有上述 g(x²) 型。）

人话版

一句话：整条实轴上都有界的幂级数，它的系数必须长成什么样？

有的幂级数处处收敛，因而在整条实轴上定义了一个函数。问：怎样从系数本身判断这个函数是否被某个常数压住？已知若函数有界，则要么只有常数项非零，要么有无穷多个非零系数且符号无穷多次变号；有界的那批级数还恰好构成一个对乘法封闭的代数。进一步的子问题是：它们是否只有 g(x²) 这种偶函数形状（g 是整函数且在正半轴有界）？这属于要给出完整刻画的问题。

原文摘录

Consider a power series f(x)=Σ a_n x^n that is convergent for all x∈R, thus defining a function f: R→R. Give a necessary and sufficient criterion for the sequence (a_n) so that f is bounded for all x∈R.
——Andreas Rüdinger（Open Problem Garden, 2009-05-09）
补充子问题（原页）：The question whether the subspace of bounded power series contains only functions of the form g(x²)（g entire，在 [0,∞) 有界）seems to be open.

—— Open Problem Garden 页 "Criterion for boundedness of power series"（2009-05-09 由作者本人发布，Subject: Analysis）

已知结果与进展

  • 必要条件（原页）：a_0 唯一非零，或非零系数无穷多次变号。
  • 改变除 a_0 外的有限多个 a_n（非零改动）必离开 B（原页注记为 "Changing a finite set of a_n's (except a_0) does leave the subspace of bounded power series"；原因: 非零多项式无界——OPG 评论区亦确认）。 （核对修正注记 2026-11-21，SOL验证Agent：池内原记"改变有限多个 a_n（除 a_0）不离开 B"将原页含义反转——原页为 "does leave"（离开）。2026-11-21 重取 OPG 原页核实后已更正；另 OPG 原页公式渲染缺失，子问题 (2) 中 g(x²) 类的精确公式以页内文字为准、表述待核。）
  • 结构性结果：B 为线性子空间且为代数；含全部 g(x²) 型。

边界与约定

  • 最小参数: 常函数 ∈ B（任意 a_0）；cos x ∈ B（=g(x²)，g(t)=Σ(−1)^k t^k/(2k)! 整且在 [0,∞) 有界）；sin x ∈ B（=x·h(x²)，h(t)=sin(√t)/√t 型整且在 [0,∞) 有界）——注意 sin x 不是 g(x²) 型（奇函数），是子问题 (2) 字面读法的即时机反例。
  • 退化情形: 有限非零系数 ⇒ 多项式 ⇒ 有界仅当常函数（非零多项式无界）；a_0 单独改动不离开 B；改任何 n≥1 的单系数（非零量）必离开 B。
  • 必要条件边界（必要≠充分，声称判据须过此关）: e^{-x} 系数 (−1)^n/n! 无穷次变号且无穷多非零（必要条件满足）但 f=e^{-x} 在 (−∞,0] 无界 ∉ B——任何声称的充要判据必须把 e^{-x} 排除在外；e^{x}、e^{x²}（偶但无界）也须排除。
  • 约定依赖: 幂级数在 R 上处处收敛（=整函数，实系数）；"有界"= sup_{x∈R} |f(x)| < ∞（双侧）；系数域为 R（复系数变体不在原文范围）。
  • 结构性检查点: B 是线性子空间且为代数（对乘法封闭）——任何声称的判据必须与该代数结构相容（如判据应在乘法下稳定）；偶部/奇部分解: f∈B ⟹ f_e=(f(x)+f(-x))/2 与 f_o=(f(x)−f(−x))/2 均 ∈B，故 B = {g(x²) 型} ⊕ {x·h(x²) 型}（g,h 整且 [0,∞) 有界）——该分解为平凡真，任何"仅含 g(x²) 型"的字面声称都会被奇部否证，须与 OPG 页缺失公式对质。
  • 建议独立验证方法（仅描述，不执行）: 对声称判据做正反例机器测试（B 正例: cos, sin, e^{−x²}, cos(π/2−x)=sin x；非 B 反例: e^{x}, e^{−x}, e^{x²}, x e^{x²}）；数值上对候选判据生成随机整级数（系数快速衰减+符号随机）检验判据输出与数值有界性一致；文献面查 "bounded entire function coefficient criterion"（与 OPG 途径不同源）。
