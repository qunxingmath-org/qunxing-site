# Kourovka 21.146：F_{n-1} 型群是否总能嵌入 F_n 型群

## 题面

称群 $G$ 为 **type $F_n$**，如果它有一个分类空间 $K(G,1)$，其 $n$ 维骨架只有有限多个胞腔；称它为 **type $F_\infty$**（或 type $F$），如果它对每个 $n\geq1$ 都是 type $F_n$。等价地，type $F_\infty$ 群有有限 CW 复形作为分类空间。

最低两层是熟悉的条件：

- type $F_1$ 等价于有限生成；
- type $F_2$ 等价于有限呈示。

注意 type $F_n$ 比同调有限性条件 type $FP_n$ 更强，不能把二者混同。

**问题：对每个整数 $n\geq3$，是否每个 type $F_{n-1}$ 群都能作为子群嵌入某个 type $F_n$ 群？**

原题还提出更强的版本：

**是否每个 type $F_{n-1}$ 群甚至都能嵌入某个 type $F_\infty$ 群？**

形式上，第一问是判定
$$
\forall n\geq3\ \forall G\
\Bigl(G\text{ 为 type }F_{n-1}
\Rightarrow
\exists H\ \bigl(H\text{ 为 type }F_n\ \land\ G\hookrightarrow H\bigr)
\Bigr).
$$

## 原文摘录

> Type $F$ means type $F_n$ for all $n$.
>
> For $n\geq 3$, does every group of type $F_{n-1}$ embed as a subgroup of a group of type $F_n$? Or even in a group of type $F$?
>
> —— M. C. B. Zaremsky，Kourovka Notebook 21.146，2026，第200–201页，https://arxiv.org/abs/1401.0300v50

## 动机：能否通过嵌入提高有限性层级

有限生成与有限呈示之间有一个经典事实：每个有限生成群都能嵌入有限呈示群。因此 $n=2$ 不构成困难。真正的台阶从 $F_2$ 到 $F_3$ 开始：给定一个有限呈示群 $G$，能否把它放入某个具有有限三维骨架的 $K(H,1)$ 的群 $H$？

直接对 $K(G,1)$ 附着三维胞腔可以消去 $H_3$，却可能产生非零的 $\pi_3$，因而未必得到 $K(H,1)$。要继续附着四维、五维胞腔，又可能破坏三维骨架有限性。这正是“升一层”比“同层改造”困难的拓扑根源。

## 已知结果与进展

### 已经解决的最低层与同层嵌入

- **$n=2$ 是经典结果。** 每个有限生成群都可嵌入有限呈示群，所以 $F_1\to F_2$ 不是本题的开放部分。
- **Baumslag–Dyer–Miller 1983。** 每个有限呈示群可嵌入一个有限呈示的无环群。这给出 $F_2\to F_2$ 的强化，但宿主仍只是 type $F_2$。[Baumslag–Dyer–Miller](https://doi.org/10.1016/0040-9383(83)90044-7)
- **Bridson 1998，Theorem A。** 若一个有限生成群类在沿有限生成自由群的等距 amalgamation 下封闭，则其中每个群都可拟等距嵌入同类群，并使宿主没有真有限指数子群。原文明确把 type $F_n$ 群类列为适用类。因此这是 **$F_n\to F_n$** 的嵌入定理。[Bridson 1998](https://msp.org/gtm/1998/01/p004.xhtml)
- **Palmer–Wu 2025，Corollary 0.2。** 每个 type $F_n$ 群都可拟等距嵌入一个无环、没有真有限指数子群的 type $F_n$ 群。构造使用 labelled Thompson 群，并证明这些群无环。该结果回答了论文自己的同层 Question 0.1，而不是 Kourovka 的升层问题。[Palmer–Wu 2025](https://arxiv.org/abs/2510.16879)

### 有限性层级确实严格

- **Stallings–Bieri 型构造。** 对每个 $n$，存在 type $F_n$ 而非 type $F_{n+1}$ 的群，说明这些条件不是空的名义层级。
- **Palmer–Wu 2025，Corollary 0.9。** 对每个 $n\geq1$，存在无环群是 type $F_n$ 而非 type $F_{n+1}$；甚至可取为单群。这显示即使无环、单群也不能自动升到下一层。
- 这些严格性结果**不排除**一个低层群嵌入高层群；它们只说明不能期待任意高层构造自动保留所需有限性。

### 尚未解决的核心

目前没有检索到以下任一结果：

1. 对 $n\geq3$，任意 $F_{n-1}$ 群嵌入 $F_n$ 群的一般构造；
2. 一个 $n\geq3$ 和 $F_{n-1}$ 群不能嵌入任何 $F_n$ 群的反例；
3. 每个 $F_{n-1}$ 群都嵌入统一 $F_\infty$ 宿主的证明。

## 边界与约定

- **$F_n$ 不是 Thompson 群 $F_n$。** 本题的 $F_n$ 始终指有限性类型；Higman–Thompson 群通常也记为 $F_n$，但那是另一个对象。
- **$F_n\neq FP_n$。** $F_n$ 要求分类空间具有有限 $n$ 维骨架；$FP_n$ 只要求有限生成的投射消解。对有限呈示群和有限 $n$ 二者等价，但不能在一般陈述中替换。
- **嵌入必须是群同态的单射。** Cayley 图的拟等距嵌入本身不够；Bridson 和 Palmer–Wu 的定理之所以相关，正因为它们给出真正的群嵌入。
- **同层结果不能跨层使用。** 对 type $F_n$ 群成立的 $F_n\to F_n$ 定理，应用于 $F_{n-1}$ 群时只产生 $F_{n-1}$ 宿主。
- **$n=2$ 不构成部分答案。** 原题从 $n\geq3$ 开始，正是因为 $F_1\to F_2$ 已知。
- **无环性不是升层条件。** 无环 $F_n$ 而非 $F_{n+1}$ 群的存在甚至说明，无环性不能替有限性类型自动升级。
- **统一 $F_\infty$ 宿主更强。** 若对每个 $n$ 分别找到 $F_n$ 宿主，未必能把这些宿主放进一个 $F_\infty$ 群。

## 相关进展与声称解决
