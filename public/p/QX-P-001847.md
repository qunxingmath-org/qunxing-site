# {σ(n)/φ(n)} 是否恰为 {r∈Q: r≥1}

## 题面

{σ(n)/φ(n) : n≥1} 是否恰为 {r∈Q : r≥1}

## 人话版

**一句话**：σ(n)/φ(n) 跑遍所有不小于 1 的有理数吗？

σ(n) 是 n 的全部正因数之和，φ(n) 是不超过 n 且与 n 互素的整数个数。两者都是乘性函数，所以 σ(n)/φ(n)=∏(σ(p^a)/φ(p^a)) 按素因子逐项相乘。又因 σ(n)≥φ(n)，比值总不小于 1，而且是有理数。题目问：反过来，是不是每个有理数 r≥1 都能由某个 n 实现？要回答「否」，得指出一个具体的有理数并证明任何 n 都取不到它。
