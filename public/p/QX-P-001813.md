# ⌊ζ(−n)⌋ 仅 n=23 素？

## 题面

⌊ζ(−n)⌋ 是否仅 n=23 为素数

## 人话版

**一句话**：zeta 在负整数上的取值取整后，只有一个 n 能得到素数吗？

Riemann zeta 函数在负整数处有封闭公式 ζ(−n)=−B_{n+1}/(n+1)，其中 B 是 Bernoulli 数。n 为奇数时 ζ(−n)=0；n 为偶数时 ζ(−n) 的符号随 n 交替，所以取整后能得到正整数的 n 属于某一同余类。题卡问：这些取整值中是否只有 n=23 时是素数。验证每个 n 只需算一个有理数并做素性检验，因此新的反例可以被有限计算发现，但要证明「只有这一个」需要控制 Bernoulli 数分子的因子结构，目前没有这样的工具。
