# Hadamard最大行列式问题d(n)

## 题面

Hadamard (1893)最大行列式问题：偶4k阶归结Hadamard猜想；奇数n的精确值大多未知（n=9,11等部分已知）；Ehlich/Wojtas界与Gram矩阵方法。

### 形式化表述

∀ n: 确定 max |det(±1矩阵)|。

## 人话版

**一句话**：元素只有 ±1 的 n 阶方阵，行列式绝对值最大能到多少？

d(n) 是所有元素取 ±1 的 n×n 方阵中，行列式绝对值的最大值。行列式有上界 n^{n/2}（Hadamard 界），达到它当且仅当对应矩阵是 Hadamard 矩阵，而这要求 n=1、2 或 n 是 4 的倍数。所以当 n≡1,2,3 (mod 4) 时上界取不到，精确值要另想办法，通常靠 Ehlich 型或 Wojtas 型界配合 Gram 矩阵的分析。每一个固定的 n 都只有有限多种矩阵，因此原则上可以用有限计算定出 d(n)；难的是对大 n 给出统一结论与渐近行为。
