# Erdős #779：素数阶乘+素数为素数（Deaconescu）

## 题面

对 n>1，设 P 为前 n 个素数之积，则存在素数 pₙ<p<P 使 P+p 为素数（Deaconescu/Erdős #779）。

### 形式化表述

primorial 区间内 P+p 素性。

## 人话版

**一句话**：把前 n 个素数乘起来，总能挑个素数让和仍是素数吗？

记 P 为前 n 个素数之积（n>1），p_n 是第 n 个素数。问题断言：存在素数 p 满足 p_n<p<P，且 P+p 也是素数。也就是在从第 n 个素数到这个巨大的乘积之间，总能找到一个素数 p，使 P+p 不被打上小素因子。这属于素数分布的加性形式问题。原始输入标明该问题已部分解决。要解决它，需对每个 n 给出证明或找到反例。
