# Caccetta–Häggkvist 猜想（r≥5 开放）

## 题面

Caccetta–Häggkvist 猜想（r≥5 开放；TCSExam 基准收录智能体 0 分）

## 人话版

**一句话**：每点至少 r 条出边，就必有长度 ≤⌈n/r⌉ 的有向圈吗？

有向图的出度是从该点出发的边数。Caccetta–Häggkvist 猜想：n 个顶点、最小出度至少 r 的有向图必含一条长度不超过 ⌈n/r⌉ 的有向圈，长度按边数算。直观意思是出边越多，圈就必须越短，这在 r=1、2 时几乎显然，越往上越难。卡上注明 r≥5 仍开放，并提到某智能体基准收录了它而智能体得 0 分。
