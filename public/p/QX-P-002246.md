# n+1 与 nφ(n)+1 均平方 ⇔ 孪生素数积？

## 题面

n+1 与 nφ(n)+1 均平方 ⇔ n 为孪生素数积？

## 人话版

**一句话**：两个式子同时变成平方数,是不是只可能发生在孪生素数之积上？

φ(n) 是欧拉函数,数出 1 到 n 中与 n 互素的整数个数。孪生素数指相差 2 的一对素数 p 与 p+2;若 n = p(p+2),可以验证 n+1 = (p+1)² 与 nφ(n)+1 都是平方数(因为 φ(n) = (p−1)(p+1))。猜想反过来也成立:只要这两个式子同时是平方数,n 就一定是一对孪生素数之积。验证小的 n 可以直接算,证明则需要把平方条件翻译成对 n 的因式结构的限制。
