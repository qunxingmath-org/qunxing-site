题面

Euclid 数 E_n=p₁p₂…p_n+1（等价 p#+1）中素数是否有无穷多个？

形式化表述

|{n: E_n 为素数}| = ∞？

人话版

一句话：前 n 个素数乘起来再加 1，得到的数里素数有无穷多个吗？

把前 n 个素数 2,3,5,7,… 全部乘起来再加 1，得到的数叫第 n 个 Euclid 数，记作 E_n=p_1p_2…p_n+1，也写成 p_n#+1，其中 p_n# 表示前 n 个素数的乘积。E_n 被任何不超过 p_n 的素数除都余 1，所以它的素因子必定都是更大的新素数——Euclid 证明素数无穷多用的就是这个想法。前几个 E_n 确实是素数：3、7、31、211、2311；第六个 30031=59×509 就是合数。题目问：使 E_n 为素数的 n 是否有无穷多个。

（AI 起草，未经人工审校）

原文摘录

A number defined as the product of first $n$ prime numbers $+1$ is called $n$th Euclid number. Are there any survey on the progress for answering the following question: are there an infinite number of prime Euclid numbers? The references on the papers in which people have tried partially answer the question are also accepted.

提问: Oleksandr Bondarenko（2010-11-11），票数 5，无 accepted 答案（2026-11-20 API 核验）；标签: nt.number-theory,prime-numbers,open-problems

—— MathOverflow

已知结果与进展

Caldwell–Gallot（Math. Comp. 2002）：计算+启发式，期望 ~e^γ log N 个（Caldwell arXiv:2103.04483"Amazing Prime Heuristic"）；Ribenboim（Little Book of Big Primes p.3）：连合数 Euclid 数是否无穷多也未证；Wikipedia/PrimePages 维护纪录。

边界与约定

  • 边界：Euclid数定义（前n素数积+1）；'素数成员'计数。
  • 独立验证建议：大n素性检验（PRP）扩展已知纪录（PrimePages维护线）。
