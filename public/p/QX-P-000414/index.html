A large subset of n integers whose restricted sumset avoids the set itself

题面

n 个整数组成的 A 中是否存在 |S|=(log n)^100 的子集使受限和集 S∔S 与 A 不交？

形式化表述

∃S⊂A: |S|=(log n)^100 且 S∔S 与 A 不交。

人话版

一句话：n 个整数里，能挑出 (log n)^100 个使两两之和都落在 A 外吗？

A 是由 n 个整数组成的集合。对子集 S⊂A，受限和集 S∔S 指所有 s+s' 构成的集合，其中 s、s' 取 S 中互不相同的两个元素。题目问：是否总能找到 S⊂A，|S|=(log n)^100，使 S∔S 与 A 完全没有公共元素，也就是任意两个取自 S 的不同元素相加，结果都不落在 A 里。注意 (log n)^100 相对 n 极小，这个要求是很弱的；问题在于无论 A 长什么样（比如本身就是等差结构）都必须能做到，所以要给出统一的存在性论证或者反例。

（AI 起草，未经人工审校）

原文摘录

A: n integers. Is there S⊂A, |S|=(log n)^100, with (S∔S)∩A=∅?

—— Ben Green, '100 open problems'（arXiv 讲义，2024；清单 2025-12 更新版仍列 open）

已知结果与进展

  • Green 清单问题2；与 sumset 反相关结构相关，无公认解。

边界与约定

  • 边界：|S|恰为(log n)^100 vs ≥该值两读法——原问'with |S|=(log n)^100'按精确值读。
  • 独立验证建议：小A枚举最大可行S验证下界方向。
