# 素特征下约化李代数的定义缺失

## 题面

素特征下约化李代数的定义缺失

## 人话版

**一句话**：特征为零时好好的定义，搬到素特征还剩哪一条？

李代数由满足反对称性与 Jacobi 恒等式的括号运算定义。特征为 0 时，约化代数群对应的李代数是约化的，半单李代数也可约化成可对角化的结构；许多刻画在特征 0 下互相等价。把基域换成正特征 p 后，这些等价性大量失效：可对角化、半单、约化必须分开讨论，Cartan 子代数也不再都交换。问题问：素特征下「约化李代数」应当怎么定义——候选定义之间是否一致、哪一个保留了特征 0 时的好性质。卡片只给了标题。
