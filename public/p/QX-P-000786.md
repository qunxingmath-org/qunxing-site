# Erdős P1082：一般位置 n 点集至少 n/2 个不同距离

## 题面

每个无三点共线的 n 点平面点集至少确定 ⌊n/2⌋ 个不同距离，且存在一点从它出发可见至少 ⌊n/2⌋ 个不同距离。

### 形式化表述

∀ 一般位置点集 A（|A|=n）: |{距离}| ≥ ⌊n/2⌋ 且 ∃a∈A: |{d(a,b): b∈A}| ≥ ⌊n/2⌋。

## 人话版

**一句话**：一般位置的 n 个点，至少能确定多少个不同的距离？

一般位置指点集中没有三点共线。题目断言两件事：第一，一个 n 点的一般位置点集所确定的距离（所有两点间距中互不相同的取值）至少有 ⌊n/2⌋ 个；第二，更强的一条，存在某个点 a，使从 a 到其余各点的距离本身就至少有 ⌊n/2⌋ 个不同取值。第二条更强，因为它把计数集中到单个点上，而不是让各处的距离互相补足。这类「不同距离个数下界」的问题常用凸包、最远点或代数手段处理，难点是一般位置条件几乎不提供结构。
