# Landau n²+1 无穷素数（第四问题）

## 题面

Landau n²+1 无穷素数（Landau 第四问题；2026 官方页确认全部未解）

## 人话版

**一句话**：n²+1 这样的数，会无穷多次成为素数吗？

把 n 取 1, 2, 3, …，数列 2, 5, 10, 17, 26, 37, 50, … 中确实不断出现素数（2、5、17、37…）。Landau 把它列为四个基本问题之一，问这样的素数是否有无穷多个。难点在于 n²+1 的取值是一个二次多项式，现有的筛法只能给出「这样的素数不会太少」的部分结论，做不到无穷性；同样悬着的还有 n²+1 型素数之外的孪生素数等问题。输入记录该问题目前仍全部开放。
