题面

q-阶乘 [n]_q!+1 的不可约性

题面草稿（AI 起草，待核）

对正整数 $n$，令 $[n]_q:=1+q+q^{2}+\cdots+q^{n-1}$，并定义 $q$-阶乘
$$[n]_q! := 1\,(1+q)\,(1+q+q^{2})\cdots\left(1+q+\cdots+q^{n-1}\right).$$
问：对每个正整数 $n$，多项式 $[n]_q!+1$ 是否都在 $\mathbb{Z}$ 上不可约？（原文报告：$n\le 20$ 时均成立。）

人话版

一句话：[n]_q!+1 这几个多项式，在整数上会不会一直是不可约的？

先把 [n]_q 定义为 1+q+q²+⋯+q^{n−1}（等比和），再把 q-阶乘定义为 [n]_q!=1·(1+q)·(1+q+q²)⋯(1+q+⋯+q^{n−1})，即把 [1]_q 到 [n]_q 依次乘起来。题目问：[n]_q!+1 作为整系数多项式，是否对每个正整数 n 都在 Z 上不可约（不能分解成两个次数至少为 1 的整系数多项式的乘积）。原文报告 n 到 20 都成立。难点在于常数项、根的分布和不可约性判据（如 Eisenstein）都难以同时用上。

（AI 起草，未经人工审校）

原文摘录

Is it true that $[n]_q! + 1$ is an irreducible polynomial over $\mathbb{Z}$ for all positive integers $n$ ?
I checked that this is true for $n$ up to $20$ .
Here $[n]_q! := 1 (1 + q) (1 + q + q^2) \cdots (1 + q + \cdots + q^{n-1})$ is the q-factorial.

—— Math StackExchange 问题 #3123746，作者 Penchez，CC BY-SA 4.0，https://math.stackexchange.com/questions/3123746/irreducibility-of-q-factorial-plus-1
