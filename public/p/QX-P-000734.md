# Counterexamples to Dujella's conjecture on integral points on the elliptic curve attached to a Diophantine triple

## 题面

【主线已解决，此为延伸问题】刻画使 y^2=(ax+1)(bx+1)(cx+1) 出现额外整点（x∉{0,d_-,d_+,-1}）的丢番图三元组结构与整点分布：{5,115,c} 族的整点完全分类、其他异常族的搜索与分类。

### 形式化表述

给定丢番图三元组 {a,b,c}，研究 E: y^2=(ax+1)(bx+1)(cx+1) 的整点集。原文证明：存在无穷多 {5,115,c} 含 x≠-1 且三因子皆非平方的整点 → 强猜想与弱问题4.8均否定。

## 人话版

**一句话**：丢番图三元组给出的椭圆曲线上，还会冒出哪些意料之外的整点？

丢番图三元组 {a,b,c} 指三个正整数，两两乘积加 1 都是完全平方数。对每个这样的三元组，可以写出椭圆曲线 y²=(ax+1)(bx+1)(cx+1)，并研究它的整点横坐标 x。原始输入说明：原文构造出无穷多个三元组 {5,115,c}，使曲线上出现 x 不等于 −1 且三个因子都不是平方的整点，从而否定了原先的强猜想与较弱的问法。剩下的延伸问题是刻画这类额外整点的结构，并对 {5,115,c} 族及其它异常族做完整分类。

## 原文摘录

> Dujella conjectured the only integral x-coordinates on y^2=(ax+1)(bx+1)(cx+1) are 0, d_-, d_+ (and -1 if 1 in {a,b,c}). The weaker Problem 4.8 asked: must every integral point with x not -1 make ax+1, bx+1, cx+1 all perfect squares? "We construct infinitely many triples {5,115,c} admitting an integral point with x not -1 for which all three factors are nonsquares."
> （出处: Jurašić, Jurašić, arXiv:2608.22635, 2026-08-23 (v2)）
