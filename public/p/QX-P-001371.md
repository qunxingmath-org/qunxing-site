# σ(n)=2n−2 的数的分类（AMM E2571）

## 题面

分类 σ(n) = 2n−2 的正整数（" deficient-perfect, d=2" 框架下的特定情形）。

### 形式化表述

{n: σ(n)=2n−2} = ?（完全列举或结构定理。）

## 人话版

**一句话**：自己所有因子加起来正好比两倍自己少 2，这样的 n 有哪些？

σ(n) 是 n 的所有正因子之和，包括 1 和 n 本身。例如 σ(10)=1+2+5+10=18，正好等于 2·10−2，所以 10 是解。问题要求把所有满足 σ(n)=2n−2 的正整数 n 找全，可以列清单，也可以给出结构定理。难点：σ 的取值随素因子结构跳得很厉害，要同时控制素因子个数与指数，光靠枚举保证不了没有遗漏。
