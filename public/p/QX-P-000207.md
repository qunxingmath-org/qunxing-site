# Erdos P78: constructive proof of R(k) > C^k

## 题面

给出 R(k)>C^k 的构造性证明（显式构造不含大团或大独立集的图）。

### 形式化表述

∃ explicit construction of n-vertex graphs with no clique/ind. set of size ≥ c·log n (c>0). 等价于显式 R(k)>C^k。

## 人话版

**一句话**：不靠抛硬币，能不能真的把 R(k) 的指数下界造出来？

R(k) 是最小的 N：任意给 K_N 的边染两色都必出单色 K_k。Erdős 用随机方法证明了 R(k) 至少有 c^k 量级：随机染色的图里，既没有大团也没有大独立集。问题 P78 要的是把这个存在性变成显式构造——给出一个可描述、可验证（不依赖随机抽样）的构造，直接产出 n 个顶点的图，其中团和独立集的规模都只有 c·log n 量级（c>0），这恰好等价于显式地证明 R(k)>C^k。难点在于大多数去随机化手段只能给出弱得多的常数。

（AI 起草，未经人工审校）

## 已知结果与进展

- [PARTIAL] Cohen (2015): 显式构造, 团/独立集规模≤2^{(log log n)^C}。
- [PARTIAL] Li (2023): 显式构造改进至 (log n)^C。
- [BACKGROUND] Erdős概率证明: R(k)≫k·2^{k/2} (非构造)。

## 边界与约定

- 边界：C>1存在性由概率法知；'构造性'层级（poly-time/准多项式）需注明。
- 独立验证建议：候选显式构造按定义验证团/独立集上界（谱计算+枚举小规模）。
