# Is the column Hilbert space C an OUMD operator space?

## 题面

Pisier在向量值非交换Lp空间背景下引入算子空间OUMD性质（operator norm UMD常数对维度适中/均匀）。开放问题：column Hilbert空间C是否具有OUMD性质？

### 形式化表述

判定 C 是否满足 OUMD（即存在与维度无关的常数使column Hilbert valued martingale difference transforms有界）。原文经复插值把问题关联到非交换Lp空间的OUMD_q性质。

## 人话版

**一句话**：把向量换成算子的那一侧，UMD 性质还留得住吗？

UMD 是 Banach 空间的一个性质：取值在该空间的鞅差级数，其符号变换有统一有界的范数估计。把它搬到算子空间，就得到 OUMD——要求这些估计的常数不随矩阵维数增长。column Hilbert 空间是把一串向量按列排起来得到的算子空间，它是最基本的非交换例子之一。问题是：这个空间到底满不满足 OUMD？文章把这个问题与向量值非交换 Lp 空间的 OUMD_q 性质联系起来，但结论仍开放。只需回答是或否。
