题面

圆上混沌游戏径向密度双峰

题面草稿（AI 起草，待核）

混沌游戏（chaos game）与本题设定：设 $S^{1}\subset\mathbb{R}^{2}$ 为单位圆。给定初始点 $x_{0}\in\mathbb{R}^{2}$，第 $n$ 步从 $S^{1}$ 上按弧长均匀分布独立地取一点 $P_{n}$，并令
$$x_{n+1}=\frac{x_{n}+P_{n}}{2},$$
即新位置取「当前点与所取圆上点的中点」。这就是预设点取遍单位圆时的混沌游戏（对照：预设点取等边三角形顶点时，极限集是 Sierpiński 三角形）。

记该点列的平稳分布为 $\mu$，并令 $\rho(r)$ 为其关于半径 $r=|x|$ 的径向密度。

问题：

  1. 把径向密度的直方图乘以 $1/r$（原文说是为了补偿二维中半径 $r$ 处周长的增长），得到的分布出现两个峰，位置约在 $r\approx 0.35$ 与 $r\approx 0.60$。能否推导出这两处峰的确切位置（即给出以 $r$ 为未知量的方程）？
  2. 能否进一步给出径向密度 $\rho$（或 $\rho(r)/r$）的解析表达式？

（歧义：原文在「and maybe…」处被截断，第 2 问的完整形式无法读到；原文没有指明初始点 $x_{0}$、迭代步数，也没有说明直方图所用的分箱方式，以及「径向密度乘以 $1/r$」与「$\rho(r)/r$」是否为同一个量。）

人话版

一句话：圆上随机取点走「半步」，径向密度为何在 0.35 与 0.60 附近冒双峰？

混沌游戏是一种随机游走：每一步在当前点与某个预设点之间取中点。预设点取等边三角形顶点时，极限图形就是 Sierpiński 三角形。提问者把预设点换成从单位圆上均匀取的点，画出的图形很有意思：径向密度出现两个峰。把径向密度的直方图乘以 1/r（补偿二维中半径 r 处周长的增长）后，两个峰分别落在 0.35 与 0.60 附近。问题是要解析地算出这两个峰的位置，进而求出径向密度的表达式。原文在此处被截断。

（AI 起草，未经人工审校）

原文摘录

The chaos game is a random walk that steps halfway between your current position and a set of predefined points. If the points are on an equilateral triangle, the resulting set is Sierpinski's triangle. I wanted to see what would happen if the points were chosen uniformly from a circle and the result is pretty interesting:
It looks like there are two peaks in the radial density. If you make a histogram of the radial density and multiply by $1/r$ (to account for the expected spreading in 2D) you get two peaks around 0.35 and 0.60.
Is it possible to derive the location of these peaks, and maybe…
