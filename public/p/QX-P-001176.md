# t-完美图是否强 t-完美（及染色数上界）

## 题面

每个 t-完美图是否强 t-完美？t-完美图的染色数是否有界？

### 形式化表述

∀G: (t-perfect) ⇒ (strongly t-perfect)？以及：是否存在常数 C 使每个 t-perfect 图满足 χ(G) ≤ C？（2026-11-21 SOL验证修正：原句 χ(G) ≤ f(?) 为占位符，按 EGRES 原问口径改写为有界性问题）

## 人话版

**一句话**：t-完美的图一定强 t-完美吗？它的染色数会不会无界？

t-完美图是稳定集多面体（以「每个顶点取值 0 或 1、相邻顶点不能同时取 1」为整点）能由三类不等式完整刻画——顶点非负、每条边两端之和≤1、每个奇圈上顶点之和≤(|C|−1)/2——的那类图。强 t-完美是在此之上再加更强的约束条件。题目两问：一是每个 t-完美图是否都自动强 t-完美；二是 t-完美图的染色数 χ(G) 是否有统一上界（即是否存在常数 C 使所有 t-完美图满足 χ(G)≤C）。
