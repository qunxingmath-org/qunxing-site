提出者
Gowers–Long（Green Problem 88；Loh 引发）

题面

S⊂[N]^3，任两不同元素 s−s′ 的三个分量中恰有两个严格正（或两个严格负）——称"可比"。问 |S| ≤ N^{2−δ}（某 δ>0）？

形式化表述

等价图论形式：[N]^3 上图 G，x~y 当 (x1−y1)(x2−y2)<0 且 x3 与…（Green 原注：x 与 y 相连当不"可比"，例如 x2<y2 且 x3>y3）；求最大独立集是否 ≤N^{2−δ}。

人话版

一句话：三个坐标里总有两个同向，这样的集合能大到 N² 量级吗？

在 [N]³ 里取子集 S，要求任意两个不同元素 s、s′ 都「可比」：差向量 s−s′ 的三个坐标中，有两个（严格）同向——要么有两个正坐标，要么有两个负坐标。题目问：是否一定存在 δ>0 使 |S| ≤ N^{2−δ}？若成立，就把这类集合的大小从可能的 N³ 量级压到比 N² 略高一点的水平。输入另外给了一种图论改写，把「可比」换成某种不连边的条件，但那段改写本身表述含糊，两种说法是否完全等价需要核对。这是 Green 问题 88，源于 Gowers 与 Long 的问题。

（AI 起草，未经人工审校）

原文摘录

Consider a set S ⊂ [N]^3 with the property that any two distinct elements s,s' of S are comparable, which means that s−s' has either two (strictly) positive indices or two (strictly) negative ones. Is |S| ≤ N^{2−δ} for some δ>0?

—— https://people.maths.ox.ac.uk/greenbj/papers/open-problems.pdf（本地提取核对原文）；HF GREEN-054 (id=142)
