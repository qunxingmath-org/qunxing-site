# Tao 优化常数 14：BB(n) 不可判定的最小 n 上下界（Aaronson Conjecture 11）

## 题面

使 BB(n) 值不可判定的最小 n 的上下界能否改进？（当前下界与上界间隔巨大）

### 形式化表述

改进 n_min 的上下界。

## 人话版

**一句话**：从第几个 n 开始，忙碌海狸数就再也算不出来了？

BB(n) 是忙碌海狸函数：在所有 n 状态、2 符号且最终停机的图灵机中，停机前在纸带上写下的最多 1 的个数。它增长得比任何可计算函数都快，所以必然存在某个 n，使 BB(n) 的值无法由任何算法求出——即命题「BB(n)=m」在给定公理系统里不可判定。题目问：使 BB(n) 不可判定的最小 n 在哪里？目前已知的下界与上界之间差得很远，改进这个间隔就是问题所在。这是 Aaronson 猜想 11，也列在 Tao 的优化常数清单里。

（AI 起草，未经人工审校）
