题面

n 元偏序 P 中元素 x 的"胜场"统计（随机线性扩张中 x 排在其可比对手前的次数）与秩方差 σ²(x)：是否有 win(x)=Ω(σ²(x)/n) 对一切 P,x？

如上。

人话版

一句话：偏序集里某个元素的胜场数，会不会被它的秩方差压得过小？

偏序集 P 里只有部分元素能比较大小。把 P 排成一个与序关系相容的全序（小的在前），叫做一个线性扩张，通常有很多个。固定元素 x，在随机取一个均匀分布线性扩张时，compare(x) 是能与 x 比较的元素个数；win(x) 是这些可比较元素中排在 x 后面的那部分在随机意义下的期望个数。σ²(x) 是 x 在这个随机线性扩张中所处位置的方差，描述它的排名有多飘。猜想断言 win(x)≥c·σ²(x)/n，即胜场数不会比秩方差小太多。
