题面

s_n（前 n 素数和）素数项分布猜想（题面修正）

人话版

一句话：把前 n 个素数加起来，得到的数有多常是素数？

记 p_n 为第 n 个素数，s_n=p_1+p_2+…+p_n 是前 n 个素数的和。问题关心新数列 s_n 中有多少项本身又是素数：是无穷多个，还是只有有限多个；计数函数能否给出渐近或上下界。由素数定理，s_n 约等于 n²·ln n／2，所以这等于在一个增长很快的稀疏数列中数素数，通常要比在等长区间里数素数难得多。卡片标题注明这是「题面修正」版，只保留了部分和这一设定，原文其余条件未保留。
