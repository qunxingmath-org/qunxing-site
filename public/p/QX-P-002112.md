# （|{ab+c}| 最小值（sum-product 型））

## 题面

|A|=|B|=|C|=n 为三个有限整数集，求 min |{ab+c : a∈A, b∈B, c∈C}| 的精确渐近（MSE#2328450，Kenny Lau 2017 代发，源 SE 聊天室他人提问）。

## 人话版

**一句话**：三个 n 元整数集，{ab+c} 最少能缩到多小？

给定三个各有 n 个元素的整数集 A、B、C，作集合 S={ab+c : a∈A, b∈B, c∈C}。问题求当 A、B、C 取遍所有 n 元整数集时，|S| 的最小值及其精确渐近。原文给出两条基本观察：|S| 显然不超过 n³；取 A=B={2^i : 0≤i<n} 时乘积 ab 只有 2n−1 个不同值，再加上 C 后至多 2n² 个值，所以最小值是 O(n²)。下界一侧，固定一个 a 就给出至少 n 个值。真正要问的是：这个 O(n²) 能否再压低，精确的阶是多少。

## 原文摘录

> For a triple of sets of integers $A,B,C$ with $|A|=|B|=|C|=n$, we can compute the set $S_{A,B,C} = \{ab+c \mid a \in A, b \in B, c \in C\}$. I am interested in the minimum sized $S_{A,B,C}$ when taken over all possible such triples of sets.
> It is clear that it can be no bigger than $n^3$ and in fact one can show that it the minimum size is $\mathcal O(n^2)$. This is because $A=B=\{2^i | 0 \le i < n\}$ gives us $2n$ distinct values of $ab$ and we therefore get at most $2n^2$ distinct values once we include the set $C$.
