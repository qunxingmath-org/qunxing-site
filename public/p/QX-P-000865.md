# Leighton–Yao 问题：稳定 0,1<2 排序的线性规模比较器电路

## 题面

三元串的稳定"0,1<2 排序"函数（把 2 全部移到右端，保持 0 与 1 的相对次序）能否用 O(n) 规模比较器电路计算？

### 形式化表述

如上（比较器电路模型）。

## 人话版

**一句话**：把 2 都挪到末尾，真的需要超线性多个比较器吗？

输入串只含 0、1、2 三个字符。函数 f 的递归定义是：遇到 0 或 1 就把它留在最前面（相对次序不变），遇到 2 就把它挪到最右边；所以 f 就是把所有 2 稳定地移到末尾，同时 0 和 1 保持原来的先后。比较器电路的每条线上放一个符号，一个比较器可以看两条线并交换，使小的往左、大的往右（顺序 0<1<2）。排序网络用 O(n log n) 个比较器就能做到；Leighton–Yao 问的是能否只用 O(n) 个。
