# Wilf 数值半群猜想（e|L|≥c）

## 题面

每个数值半群满足 e·|L| ≥ c（e=嵌入维数，L=低于 conductor c 的半群元素数）（Wilf 1978 提问）。

### 形式化表述

e|L| ≥ c 对一切数值半群。

## 人话版

**一句话**：半群的『缺口比例』，会不会被嵌入维数从下方卡住？

数值半群是自然数的一个加法封闭子集 S，包含 0 且只有有限多个自然数不在其中。不在 S 里的正整数里最大的那个加 1，叫 conductor c；比 c 小的 S 中元素共有 |L| 个。嵌入维数 e 是 S 的最少生成元个数（它不超过 S 的最小正元素）。Wilf 1978 年提出的猜想是：对所有数值半群都有 e·|L| ≥ c。写成比例形式，等于说缺口比例 (c − |L|)/c 不超过 1 − 1/e，也就是嵌入维数越大，半群必须越饱满。否定它只需给出一个具体半群算出与猜想不符的数值。
