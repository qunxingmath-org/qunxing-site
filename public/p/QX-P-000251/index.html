题面

随机取 {0,1} 系数（常数项非零）的 n 次多项式，当 n→∞ 时不可约概率是否趋于 1（及其精确值）？

形式化表述

lim_{n→∞} P(Σ_{i=0}^{n} ε_i x^i 不可约 | ε_i∈{0,1}, ε_0=1) = 1 ?（或求精确极限值）

人话版

一句话：系数只取 0 和 1 的随机多项式，几乎一定不可约吗？

把每个系数独立地取成 0 或 1，并规定常数项非零（否则 x 直接是因子），得到一个 n 次整系数多项式。问题问：当次数 n 趋于无穷时，它不可约的概率是否趋于 1；如果极限是个小于 1 的常数，那个常数是多少。判断不可约常用的手段是模一个小素数 p 检验——模 p 不可约就推出整系数不可约，但反过来不成立，大量多项式在每一个小素数下都约化，所以“几乎都不可约”需要比逐个模检验更细的计数。

（AI 起草，未经人工审校）

原文摘录

Problem 93 (Green 2024; cf. arXiv:1810.13360): Is a random polynomial with coefficients in {0,1} and nonzero constant term almost surely irreducible? (精确渐近/变体待核对)

—— 提出: Ben Green (2024 清单 #93)；arXiv:1810.13360

形式化: formal-conjectures GreensOpenProblems/93.lean

已知结果与进展

Odlyzko–Poonen 1993（Enseignement Math）证明随机 0-1 多项式不可约概率 → ~0.6243（非 1）？——记忆有冲突：OP 证明的是'首项与常数项非零的 0-1 多项式不可约概率趋于 ~0.6243'? 实际 OP 结果: 不可约概率趋 B≈0.62433。Green 版本可能问条件（系数含负/特定分布）变体。FC 陈述为准，入池后需逐字核对。

边界与约定

  • 边界：常数项非零（固定为1）；n次首一；均匀独立系数。
  • 独立验证建议：n≤200精确计数（Sage）p_n序列看趋势与1的差距。
