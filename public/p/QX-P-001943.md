# 三次图自同构群阶最大值

## 题面

3-连通三次图自同构群阶最大值

## 人话版

**一句话**：3-连通三次图的自同构群，阶最大能到多少？

三次图（cubic graph）指每个顶点都恰好有 3 条边的图；3-连通指去掉任意两个顶点图仍然连通。这种图的自同构群是作用在顶点集上的置换群，其阶至多是 n!，但三次图的结构限制把上界压得很低。题目要问：对给定顶点数 n 的 3-连通三次图，自同构群的阶最大能是多少，以及这个最大值如何随 n 增长。已知有许多高度对称的三次图（如 Petersen 图、圈状多面体图）逼近这类极值，精确的函数关系仍需确定。
