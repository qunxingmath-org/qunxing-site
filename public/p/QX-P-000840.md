# Kahn 永久式猜想：[A A] 有 n 阶子阵 permanent 非零

## 题面

A 可逆 n×n：块阵 [A A]（2n 列）中是否必存在 n 列选出的 n×n 子阵 B 使 permanent(B)≠0？

### 形式化表述

∀域 K、∀A∈GL_n(K)：∃S⊂{1..2n}, |S|=n（对 2n 列列选）使 perm([A A][:,S])≠0。等价：prank([A A])=n。

## 人话版

**一句话**：可逆矩阵 A 复制一份列，真能挑出 n 列使 permanent 不为零？

设 A 是元素在某域 K 上的可逆 n×n 矩阵。把 A 和它的一个副本并排拼成 n×2n 的矩阵 [A A]，也就是把同一组列写两遍。题目问：能否从中挑出 n 列（每列按位置区分，来自左半或右半），使得到的 n×n 子阵 B 的 permanent 不为零？permanent 的展开式与行列式只差一个置换符号，所以它没有「线性相关就为零」的抵消机制：即使 A 可逆，permanent 也可能恰好归零。这个问题等价于问 [A A] 的「permanent 秩」是否为 n，它与 Alon–Tarsi 猜想那条关于奇偶置换计数的思路关系密切。
