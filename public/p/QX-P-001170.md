# Firoozbakht 猜想：p_{n+1} < p_n^{1+1/n}

## 题面

素数列满足 (p_{n+1})^{n} < (p_n)^{n+1}（即 p_n 递增速度的精确上界）。

### 形式化表述

∀n≥1: p_{n+1}^n < p_n^{n+1}。

## 人话版

**一句话**：第 n 个素数的 n 次根，会随 n 一直变小吗？

设 p_n 是第 n 个素数。猜想断言 p_{n+1} < p_n^{1+1/n}，两边取 n 次幂就是 p_{n+1}^n < p_n^{n+1}，等价于数列 p_n^{1/n} 严格递减。这条不等式给素数的增长速度规定了一个很紧的上界：第 n+1 个素数不能比第 n 个超出「1+1/n 次幂」这个比例。在大范围内验算都成立，但由于素数间隔的分布尚未被完全掌握，一般证明仍缺；找到一对 n 使不等式反向即可否定它。
