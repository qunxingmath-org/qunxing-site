# Kourovka 15.96：分裂自同构（φⁿ=1 且 xx^φ...x^{φ^{n-1}}=1）

## 题面

分裂自同构（φⁿ=1 且 xx^φ...x^{φ^{n-1}}=1）。(a) d-生成幂零 p-群承受 n 阶分裂自同构，衍长由 d,n 有界吗？[b) 小问见原文]

### 形式化表述

[derived length bounds under splitting automorphisms，原文为准]

## 人话版

**一句话**：分裂自同构存在时，幂零 p-群的导长能只由生成元个数和 p、n 控制吗？

自同构 φ 若满足 φ^n=1 且对每个 x 都有 x·x^φ·x^{φ²}⋯x^{φ^{n−1}}=1，就称为 n 阶分裂自同构（这里 x^φ 表示 φ 作用在 x 上）。问题 (a)：d-生成、幂零的 p-群若承受 pn 阶的分裂自同构，其导长（导出列长度）能否被 d、p、n 的函数界住。原文注明 n=1 时已证。小问 (b) 问 pn=4 的同样问题。回答需给出统一界，或造出导长无界的反例族。

## 原文摘录

> 提出人：E. I. Khukhro
> An automorphism φ of a group G is called a splitting automorphism of order
> n if φn = 1 and xxφxφ2 · · · xφn−1 = 1 for any x ∈G.
> a) Is it true that the derived length of a d-generated nilpotent p-group admitting
> a splitting automorphism of order pn is bounded by a function of d, p, and n? This
> is true for n = 1, see Archive, 7.53.
> b) The same question for pn = 4.
> E. I. Khukhro
>
> —— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21（E. I. Khukhro & V. D. Mazurov 编），问题 15.96（第15辑 2002 年）
