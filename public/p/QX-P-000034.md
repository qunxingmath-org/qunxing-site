# Catch-Up 对策猜想：总分为偶时最优对策下全平局

## 题面

Catch-Up 是两人轮流取数、以总分贴近对手此前总分的取数对策；当总分 N(N+1)/2 为偶数时，双方最优对策下结果恒为平局。

### 形式化表述

∀N with N(N+1)/2 ≡ 0 (mod 2): value of Catch-Up game on {1..N} = tie（双方得分相等）。

## 人话版

**一句话**：从 1 到 N 轮流取数比总分，总和为偶数时双方最优下一定平局吗？

Catch-Up 是两人轮流从 1,2,…,N 里取还没被取过的数、各自累加自己总分的取数游戏，玩法是每步尽量让自己的总分贴住对手的分数。所有数字之和是 N(N+1)/2。猜想是：当这个总和为偶数时，在双方都走最优策略的情况下，最终两人的总分恰好相等，即平局。总和为偶数只是胜负不可能是『一方总分严格更高』的一个前提，真正的断言是这局博弈的值正好落在平局上，而不是某一方靠策略多拿一分。卡片只记了猜想本身，没有抄录完整走法规则，判定时须以原始规则为准。

（AI 起草，未经人工审校）

## 已知结果与进展

Odd/N 为奇时先手/后手优势已有部分分析（2015 论文）；偶分情形手算 N=3,4 成立；FC Lean 化。

## 边界与约定

- 最小参数: N=3,4（总分 6,10 偶——最小可平局实例，手算/暴力均可达）；N=7,8,11,12,…（N≡0,3 mod 4 序列）逐级验证。
- 退化情形: 奇总分 N（前提域外——此时平局不可能，原论文已分析先/后手优势）；双方得分相等的定义（各自取数总和相等）。
- 约定依赖: Catch-Up 规则细节（轮流取数、每步取后个人总分须贴近对方此前总分? 具体规则以 Nealen 2015 原文为准——声称证明须引用同一规则变体）；最优对策=双方均最优（极小极大值）。
- 结构性锚点: 有限完全信息零和对策——暴力 minimax 搜索 N≤25 状态空间 {1..N} 子集（2^N 级，带剪枝可更大）；平局构造/策略盗用（strategy stealing）是两条候选证明路线。
- 建议独立验证方法（仅描述，不执行）: minimax+记忆化搜索精确求 N≤25 各偶分实例的对策值（与 FC 形式化途径不同源）；对声称证明按 N 分层核验其不变量。
