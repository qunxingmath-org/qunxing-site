题面

（表述已由查新Agent依据原文补全）间隔博弈 CIG_C（玩家轮流向集合加入点使其保持 C-凸，无法行动者输/目标型视定义）在 geodesic、monophonic、ℓ_k 凸性下的计算复杂性是什么？对照组 hull 博弈已全部 PSPACE-完全。

形式化表述

CIG_g / CIG_m / CIG_ℓk 的判定问题复杂度 ∈ {P, NP-难, PSPACE-完全}? 已知零星：Araújo 等 2025 CLOSED interval game 在 cobipartite PSPACE-完全、opt interval game 直径4 PSPACE-完全（CLOSED/闭包变体，非本题原版）。

人话版

一句话：玩家轮流加点、保持凸性，这个游戏到底有多难？

在图上可以定义各种“凸性”：一个点集是凸的，指它包含任意两点之间的所有最短路上的点（geodesic 凸性）、所有诱导路径上的点（monophonic 凸性），或长度不超过 k 的路径上的点（ℓ_k 凸性）。区间博弈 CIG_C 是这样玩的：两名玩家轮流往点集里加顶点，每次加完必须保持 C-凸，先无法行动的一方输（或按目标型规则判胜负）。与之相对的 hull 博弈（一开始摆点、轮流扩展凸包）已经在上述几种凸性下都被证明是 PSPACE-完全的。问题问：区间博弈在 geodesic、monophonic、ℓ_k 这三种凸性下分别属于 P、NP-难还是 PSPACE-完全，这一整片都还空着。

（AI 起草，未经人工审校）

原文摘录

The complexity of the interval game CIG_C remains open for every convexity C considered here (geodesic, monophonic and ℓ_k), in contrast with the hull game, which we now know to be PSPACE-complete in all these cases.
——Costa, Almeida, Sampaio, "Hull Games of Induced Path Convexities in Graphs", arXiv:2609.30302v5 (2026-09)

—— arXiv:2609.30302v5 "Hull Games of Induced Path Convexities in Graphs", 2026-09-21

已知结果与进展

  • hull 博弈（CHG_m、CHG_ℓk，k≥2，直径≤3）PSPACE-完全（本文主结果）。
  • P_n/C_n 上 Sprague–Grundy 多项式算法+闭式判据（奇 k 精确）。
  • k=2 时与 Conway's Couples-are-Forever 序列 99.97% 相合（2亿项计算）；周期性本身长期开放（Caines 等 n=50M → 本文 200M）。
