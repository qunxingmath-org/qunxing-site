无限完全图的精确着色 P(n)（原批次 A-059）

Exact colourings of the infinite complete graph: when does P(n) hold?

题面

命题 P(n)（每个精确 n-着色的无限完全图含精确 m-着色的可数无限完全子图）成立当且仅当 n≤2、n=m 或 n=m+1？（Stacey–Weidl 已证大 n 时失败，与"仅当"方向一致。）

形式化表述

（依题页）P(n) ↔ n∈{1,2,m,m+1}？（"仅当"方向部分已知，"当"方向剩余情形开放。）

人话版

一句话：恰好用 n 种颜色的无穷完全图，一定含着恰好用 m 种颜色的子图吗？

把顶点无穷多的完全图（任意两点都相邻）的顶点染色。「精确 n-着色」指恰好用了 n 种颜色且每种颜色都真的出现。「恰好 m-着色的可数无穷完全子图」指抽出一个可数无穷的顶点集（其中任意两点仍相邻），限制上去之后恰好用到 m 种颜色。命题 P(n) 断言这对所有精确 n-着色的无限完全图都成立。猜想是：P(n) 成立当且仅当 n≤2、n=m 或 n=m+1。题面记录 Stacey 与 Weidl 已证明 n 很大时命题失败，这与猜想的「仅当」方向一致；「当」方向还有情形没解决。

原文摘录

(OPG, Erickson 1994) 无限完全图的精确 n-着色必含恰 m-着色的可数无限完全子图；P(n) 成立 iff n≤2、n=m 或 n=m+1？

已知结果与进展

  • Stacey–Weidl (1999)：大 n 否定（采集记录）。
  • arXiv sweep 零直接命中（题目小众）。

边界与约定

  • 边界：可数无限子图；'精确m-着色'含义（恰好使用m色）。
  • 独立验证建议：n=m+1情形显式构造可形式化复核；剩余情形集合论枚举。
