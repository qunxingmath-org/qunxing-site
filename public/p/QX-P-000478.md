# Scholz–Brauer 与加法链猜想族（TAOCP v2 4.6.3 ex.42, M50）

## 题面

加法链长度：ℓ(2^n−1)≤n−1+ℓ(n)？等号恒成立？ℓ(n)=ℓ⁰(n)？

### 形式化表述

三问如上。

## 人话版

**一句话**：算 2^n−1 次幂，真的只比算 n 多花 n−1 步吗？

加法链是从 1 出发、每步取已有两数之和、最终得到 n 的最短序列；其长度 ℓ(n) 等于「只用乘法算 n 次幂」所需的最少乘法次数。ℓ⁰(n) 是受限版本：每步只能用当前最大数加上某个已有数（星链）。三个问题分别是 ℓ(2^n−1) ≤ n−1+ℓ(n) 是否恒成立、等号是否恒成立、ℓ(n)=ℓ⁰(n) 是否恒成立。对固定的小 n，链长可以穷举算出，所以任一断言若假都能用具体 n 反证。
