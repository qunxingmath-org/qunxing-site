# OWR 2024/3：超立方体图是否存在绝对常数 c 的"无 c 个两两相交边"画法

## 题面

是否存在绝对常数 c，使每个超立方体 Q_d 都有平面拓扑画法，其中不存在 c 条两两相交的边？

## 人话版

**一句话**：超立方体的画法里，能不能做到没有一堆边两两互穿？

拓扑画法允许图的边在平面上任意弯曲，只要顶点位置不同、边不经过顶点。一组边叫两两相交，如果其中任意两条都在内部相交。准平面图就是存在一种画法使得不存在三条两两相交的边。超立方体 Q_d 是很规则的图，顶点越多边越密。问题问：是否存在与 d 无关的绝对常数 c，使每个 Q_d 都有一种画法，其中凑不出 c 条两两相交的边？这等价于问 Q_d 是否以一致的方式「接近准平面」。
