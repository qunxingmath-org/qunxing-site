# Kourovka 21.80：存在有限生成左序群恰有一个非平凡共轭类吗

## 题面

存在有限生成左序群恰有一个非平凡共轭类吗？（肯定答案将导出 21.78 肯定；Osin 已构造无挠 fg 两共轭类群）

### 形式化表述

∃fg left-orderable G with exactly one nontrivial conjugacy class ?

## 人话版

**一句话**：有没有有限生成、可左序、却只有一个非平凡共轭类的群？

左序群指群上存在全序 <，使左乘保持序（g<h 推出 ag<ah）。共轭类是形如 {gxg⁻¹ : g∈G} 的集合；恰有一个非平凡共轭类，意思是除单位元所在的类之外，其余所有元素彼此共轭，这类群也常被称为恰有两个共轭类的群。问题（Lodha、Navas）问：是否存在有限生成、左可序、且恰有一个非平凡共轭类的群？已知 Osin 造出过无挠、有限生成、恰有一个非平凡共轭类的群，但没有左序这一条件。
