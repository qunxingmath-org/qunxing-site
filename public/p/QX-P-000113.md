# 中心对称 Viterbo 猜想（c_EHZ(X)^n ≤ n!·vol(X)）

## 题面

每个中心对称凸体 X⊂ℝ^{2n} 满足 c_EHZ(X)^n ≤ n!·vol(X)（Viterbo 体积-容量猜想的对称版）。

### 形式化表述

∀ 中心对称凸体 X⊂ℝ^{2n}: c_EHZ(X)^n ≤ n! vol(X)；已知球取等。非对称版已被反例否定（2024）。

## 人话版

**一句话**：辛几何里的 EHZ 容量，能被普通体积压住吗？

在 2n 维空间上，辛容量是一种给凸体指派“辛大小”的数，它对辛变换不变，并且总要被体积按某个尺度控制。EHZ 容量是其中一种具体的容量，定义为某种作用量谱的最小值。这张卡的中心对称版本断言：对每个中心对称凸体 X⊂ℝ^{2n}，都有 c_EHZ(X)^n ≤ n!·vol(X)，而球恰好让等号成立，所以这个上界是精确的。输入的记录还提到，非对称的完整版本已有反例（2024），因此剩下的正是这道对称情形；要解决它，需要对任意中心对称凸体给出容量与体积关系的统一估计。
