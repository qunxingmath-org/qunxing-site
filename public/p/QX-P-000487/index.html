Ungar 方向集猜想（奇数点情形 n 个方向）

Ungar's direction conjecture: do n noncollinear points determine at least n directions when n is odd?

题面

n 个不共线平面点确定的方向数：偶数 n 已由 Ungar 定理解决（≥n）；奇数 n 时是否 ≥n（已知 ≥n−1）。

形式化表述

∀奇 n: n 点非共线 ⇒ 方向数 ≥n。

人话版

一句话：n 是奇数时，不共线的 n 个点还一定确定 n 个方向吗？

平面上 n 个不共线的点，两两连线会给出一些方向；两条连线平行就算同一个方向，所以问的是不同方向的总数。Ungar 在 1982 年证明：n=2N 为偶数时，方向数至少是 2N，也就是至少 n 个。奇数 n 的情形是否也至少 n 个，至今没有答案；目前只知道至少 n−1 个，与目标差一个。要证伪只需画出一组给出 n−1 个方向的不共线 n 点。

（AI 起草，未经人工审校）

原文摘录

Ungar (1982): 2N noncollinear points determine ≥2N directions. OPEN (odd case): do n noncollinear points determine at least n directions when n is odd? (known ≥n−1)

—— Ungar JCTA 1982; Pilatte ELJC 27(1) 2020; atlas: opa.mathematics.discrete-geometry.ungar-conjecture (tier_1)

已知结果与进展

  • [PARTIAL] 偶数情形已证（Ungar 1982）；奇数情形 n−1 已知；Pilatte (EJC 2020) 分类 n+1 方向构型（近极值结构）。

边界与约定

  • 边界：方向=连接线斜率类数；n奇数。
  • 独立验证建议：n+1方向构型枚举（Pilatte分类扩展）检验n方向是否可达。
