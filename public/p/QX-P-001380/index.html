题面

证明该二阶线性递推两解之比的展开系数恰好（或按指定方式）匹配 tan x 的 Maclaurin 系数。

形式化表述

-f_n(x)/g_n(x) 的展开 = tan x 的连分式收敛子/系数关系（Pincherle 极限解理论）。

人话版

一句话：一个带 m(m+1)x 的递推，两解之比怎么会正好对上 tan x 的系数？

递推 u_{m+1} = −u_m − m(m+1)x·u_{m−1} 里 x 是参数，把解看成 x 的形式幂级数；取两个解 f_n、g_n（下标 n 表示截断到第 n 步），作比值 −f_n/g_n，要求证明这个比值的 Maclaurin 系数与 tan x 的系数之间满足既定关系。直觉来自 Pincherle 的极限解理论：递推的最小解与连分式相联系，而 tan x 也有连分式展开。
