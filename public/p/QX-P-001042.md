# Kourovka 17.57：CT(Z) 由类换位子 τ_{r1(m1),r2(m2)} 生成

## 题面

CT(Z) 由类换位子 τ_{r1(m1),r2(m2)} 生成。[按原文题面：由特定 r(m) 类换位子生成的子群的结构/性质]

### 形式化表述

[CT(Z) subgroups by class transpositions，原文为准]

## 人话版

**一句话**：由类换位生成的这个单群，外自同构群真的只有两个元素吗？

对整数 0≤r<m，r(m) 表示同余类 {r+km}。若 r_1(m_1) 与 r_2(m_2) 不交，类换位 τ 就是把 r_1+k m_1 与 r_2+k m_2 逐对互换、其余不动的对合。由所有类换位生成的群记 CT(Z)，原文注明它是单群。Out(CT(Z))=Aut/Inn 是外自同构群。原文中的 σ 指置换 n↦n 与 n↦−n−1 这类映射。问题问 Out(CT(Z)) 是否恰为二元群 C_2。

（AI 起草，未经人工审校）

## 原文摘录

> 提出人：S. Kohl
> Let r(m) = {r+km | k ∈Z} for integers 0 ⩽r < m. For r1(m1)∩r2(m2) = ∅
> define the class transposition τr1(m1),r2(m2) as the involution which interchanges
> r1 + km1 and r2 + km2 for each integer k and fixes everything else.
> The group
> CT(Z) generated by all class transpositions is simple (Math. Z., 264, no. 4 (2010),
> 927–938). Is Out(CT(Z)) = ⟨σ 7→σn7→−n−1⟩∼= C2?
> S. Kohl
>
> —— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21（E. I. Khukhro & V. D. Mazurov 编），问题 17.57（第17辑 2010 年）
