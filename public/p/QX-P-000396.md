# batch_I I-054：曲线 C/Q 带 Pic¹ 有理点 P。对每个有理点 Q，Q−P 给出 H¹(Q,J[n]) 类。问

## 题面

曲线 C/Q 带 Pic¹ 有理点 P。对每个有理点 Q，Q−P 给出 H¹(Q,J[n]) 类。问：若 C 无有理点，是否必存在 n 使每个 H¹(Q,J[n]) 类在某局部（p 或 ∞）遇阻碍（该类不来自任何 Q_p 点）？

### 形式化表述

C(Q)=∅ ⇒ ∃n ∀ξ∈H¹(Q,J[n]): ∃v∈{p,∞}: ξ|_{H¹(Q_v,J[n])} 不来自 C(Q_v)。

## 人话版

**一句话**：曲线没有有理点时，能否用 J[n] 上同调里逐个类的局部阻碍把它挡住？

C 是 Q 上的一条曲线，J 是它的 Jacobian（由 C 上零次除子类构成的阿贝尔簇）。固定一个次数为 1 的有理除子 P。每个有理点 Q 给出 J 里的点 Q−P，经乘以 n 的 Galois 上同调长正合列，就得到 H¹(Q,J[n]) 中的一个类。原始思路是给 C 的有理点找局部阻碍：在某个素数 p 或实位处根本没有 Q_p 点。题目换个角度：不去找点，而是给 H¹(Q,J[n]) 里每个类找局部阻碍，即该类限制到某个 Q_v 后不来自 C(Q_v)。问的是：若 C(Q) 为空，是否必存在某个 n，使每个类都在某处遇到阻碍。

## 原文摘录

> Let $C$ be a curve over $\mathbb Q$ with a point $P$ on $Pic^1$. For each $\mathbb Q$-rational point $Q$, $Q-P$ is a point on the Jacobian $J$. We can use the map $H^0(\mathbb Q, J) \to H^1(\mathbb Q,J[n])$ to obtain a class in $H^1(\mathbb Q,J[n])$ associated to each rational point. Rather than trying to find a local obstruction to existence of rational points on $C$, we could try to find a local obstruction to existence of rational points in each $H^1(\mathbb Q, J[n])$ class.

## 已知结果与进展

回答 a307242（票7）：该阻碍=Stoll 有限阿贝尔下降阻碍（Thm 6.4），与 Brauer–Manin 一致（Cor 7.3）；Stoll 猜想（Conj 9.1）：C(K̄)=C(𝔸_K)_•^{f-ab}，即 f-ab 为 Hasse 原理与弱逼近的唯一阻碍；g=0 成立；g=1 ⟺ Ш(K,Pic⁰)_{div}=0（Tate–Shafarevich 弱形式）；g≥2：连 C(𝔸)_•^{f-ab} 有限性未知；Stoll Thm 8.6：存在到 A 的态射且 A(K) 有限+Ш_{div}=0 时成立。
