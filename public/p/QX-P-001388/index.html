Two alternating recurrences with (m,n) = (1,4) and (1,8) share only the value 1

题面

证明 (m,n)=(1,4) 与 (1,8) 时，两条交替递推序列的交集恰为 {1}。

形式化表述

对 (m,n)∈{(1,4),(1,8)}: S^{(m,n)}∩S^{(n,m)} = {1}。

人话版

一句话：两个只差 m、n 对调的交替递推序列，真的只在 1 处相遇吗？

序列这样定义：S₁=1，S₂=m，之后每一步按 k 的奇偶交替使用 S_k=m·S_{k−1}+S_{k−2} 与 S_k=n·S_{k−1}+S_{k−2}。把 (m,n) 与 (n,m) 当成两套参数各生成一列，就得到两条“交替方向相反”的序列。题目要证：当 (m,n)=(1,4) 和 (m,n)=(1,8) 时，这两条序列的公共项只有 1。难点：交替系数使序列不是单一线性递推，需要用两两之间的比、连分式或线性型下界来控制可能的相遇。

（AI 起草，未经人工审校）

原文摘录

Martin Schechter，FQ H-305 (1979)，Rabinowitz 索引 p.418：S₁=1, S₂=m, S_k 按 k 奇偶交替取 mS_{k−1}+S_{k−2} 或 nS_{k−1}+S_{k−2}；(m,n)=(1,4) 与 (1,8) 时两序列（两个交替方向）仅共享元素 1。

—— Rabinowitz 索引 p.418
