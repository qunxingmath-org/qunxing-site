题面

若 n−1 被 φ(n) 整除，则 n 是素数。

形式化表述

∀n>1: (φ(n) | n−1) ⇒ n ∈ Prime。

人话版

一句话：φ(n) 能整除 n−1 的合数，真的一个都没有吗？

欧拉函数 φ(n) 数的是 1 到 n 中与 n 互素的整数个数。对素数 p 有 φ(p)=p−1，于是 φ(p) 当然整除 p−1；猜想反过来也成立：只要 φ(n) 整除 n−1，n 就必须是素数。等价的说法是：不存在合数 n 使 n−1 是 φ(n) 的整数倍。已知若这样的 n 存在，它必须满足若干很强的限制条件，搜索范围因此被压得很窄，但至今既没有找到，也没有证明不存在。
