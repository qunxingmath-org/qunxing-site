# Kourovka 18.98：哪些有限单群不能由 2、3 阶元素生成

## 题面

哪些有限单群不能由 2、3 阶元素生成。

### 形式化表述

[哪些有限单群不能由 2、3 阶元素生成：以原文为准；18.98]

## 人话版

**一句话**：哪些有限单群，配不出一个 2 阶元和一个 3 阶元来生成？

称一个群是 (2,3)-生成的，是指它有两个生成元 x、y，其中 x 的阶为 2、y 的阶为 3。已知绝大多数有限单群都如此。题目问：完整的例外清单是什么？特别地问：在经典李型单群中，除 PSU(3,5²) 这一例外之外，是否只有在特征为 2 或 3 时才会出现例外？题注还说明，整个问题目前主要在偶数维正交群的若干情形上仍未定。

（AI 起草，未经人工审校）
