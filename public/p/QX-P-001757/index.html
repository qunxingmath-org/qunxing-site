题面

Coxeter 元的中心化子结构

人话版

一句话：群元素里最标准的 Coxeter 元，它的中心化子长什么样？

Coxeter 群由若干反射生成，把每个生成元在一次乘积里各用一次，得到的元素称为相对于所选生成元顺序的 Coxeter 元。中心化子指群里所有与 c 可交换的元素，它衡量 c 有多中心。题卡问的是这个中心化子的结构：它有多大、由哪些生成元撑起来、随 c 的取值怎样变化。卡上把状态标为 solved，说明这一结构已有定论，剩下的工作是把结论准确写清并验证。
