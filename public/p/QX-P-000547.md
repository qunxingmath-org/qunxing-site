# 17.6 n-Engel 生成元的幂零类函数界 f(n,d)/g(n,d)

## 题面

a) 是否存在 f:N×N→N 使由 d 个左 n-Engel 元生成的幂零群类≤f(n,d)？b) 右 n-Engel 情形 g(n,d)？

### 形式化表述

见题面 a/b。

## 人话版

**一句话**：n-Engel 元生成的幂零群，幂零类能被 n 和 d 卡住吗？

用交换子记号，迭代 [x,y,y,…,y]（y 出现 n 次）若恒等于 1，就称 x 是左 n-Engel 元；把 x 与 y 的位置对调得到右 n-Engel 元。幂零类衡量一个幂零群「离交换有多远」：类为 1 就交换，类越大链越长。问题分两半：(a) 是否存在二元函数 f，使任何由 d 个左 n-Engel 元生成的幂零群，幂零类不超过 f(n,d)；(b) 把左换成右，是否也存在相应的 g(n,d)。
