题面

二部多重图中 n 个大小为 n+1的两两不交匹配族必有 n 条彩虹匹配（每色选一边两两不共端点）。

形式化表述

n matchings of size n+1 ⇒ rainbow matching of size n。

人话版

一句话：n 个各有 n+1 条边的匹配，一定能凑出 n 条互不共端点的彩虹边吗？

在一个二部多重图里给出 n 个匹配，每个匹配含 n+1 条边，匹配内部任意两条边不共用端点。把第 i 个匹配的边染成第 i 种颜色，彩虹匹配就是每种颜色最多取一条、且取出的边两两不共用端点的边集。Aharoni–Berger 猜想：这样的 n 个匹配一定能凑出一个大小恰为 n、也就是每种颜色恰好用一次的彩虹匹配。每个匹配比 n 多出一条，这个“多一”就是全部余量；难点在于不同匹配之间可以任意交织，无法逐个贪心挑选。

（AI 起草，未经人工审校）
