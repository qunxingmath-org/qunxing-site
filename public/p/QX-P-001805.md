# Cohen 猜想66：SG 循环数 HL-2 类比

## 题面

Cohen 猜想66：SG 循环数的 HL-2 类比（C_σ(m+n)≤C_σ(m)+C_σ(n)）

## 人话版

**一句话**：把次可加性搬到 Sophie Germain 式的循环数上，不等式还成立吗？

循环数指满足 gcd(n,φ(n))=1 的整数 n，φ 是 Euler 函数。把「Sophie Germain 素数」的模式搬过来，就是要求 n 与 2n+1 都是循环数，这类数在题卡里记作 Sophie Germain 循环数。设 C_σ(x) 统计不超过 x 的这类数的个数，题卡问的正是 Hardy–Littlewood 第二猜想式的次可加性：C_σ(m+n)≤C_σ(m)+C_σ(n)。卡上状态标为 unknown，且 C_σ 的精确定义材料未给出，需回原文核对后再下结论。
