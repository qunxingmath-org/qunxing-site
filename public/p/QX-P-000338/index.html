Erdos P165: asymptotic formula for R(3,k)

Determining the constant c in the asymptotic formula R(3,k) = (c + o(1)) k^2 / log k

题面

求R(3,k)的渐近公式。已知两侧各差常数: (c+o(1))k²/log k ≤ R(3,k) ≤ (1+o(1))k²/log k。

形式化表述

R(3,k)=(c+o(1))k²/log k? c=? 纪录: 下界c≥1/2 (Hefty–Horn–King–Pfender 2025); 此前c≥1/3 (Campos–Jenssen–Michelen–Sahasrabudhe 2025); 两文均猜c=1/2。

人话版

一句话：R(3,k) 前面那个常数，究竟是 1/2 还是别的数？

R(3,k) 是最小的 N：任何 N 个顶点的图，要么含三角形，要么含 k 个两两相邻的顶点。已知它满足 (c+o(1))k²/log k 的形状，上下界只差常数 c：上界一侧 c=1，下界一侧的 c 已从 1/3 提高到 1/2。问题是要确定这个常数究竟是多少；给出这两侧估计的作者都猜 c=1/2，即 R(3,k)=(1/2+o(1))k²/log k。

（AI 起草，未经人工审校）

已知结果与进展

  • [PARTIAL] HHKP (2025): 下界c≥1/2。

  • [BACKGROUND] 上界(1+o(1))k²/log k (Shearer 1983); 下界原始Kim 1995。

边界与约定

  • 边界：k→∞主阶。
  • 独立验证建议：R(3,k)中小k精确值延伸计算对照趋势。
