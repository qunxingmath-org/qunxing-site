Erdos P60: >ex(n;C4) edges force many C4 copies

Above the extremal number for C4, must the number of C4 copies grow like sqrt(n)?

题面

n个顶点、边数>ex(n;C4)的图必含 ≫√n 个C4副本？

形式化表述

∀ G, |V|=n, e(G)>ex(n;C4) ⟹ #C4(G) ≫ n^{1/2}。Erdős–Simonovits猜想; 他们甚至无法证明至少2个C4。

人话版

一句话：边数刚超过 C4 的极值数，C4 副本就会成 √n 量级地冒出来吗？

ex(n;C4) 是 n 个顶点的图中不出现四元环时能有的最多边数。问题问：只要边数比这个数多一点，图里四元环的个数是否就一定至少是 √n 的量级？也就是说，越过极值线后四元环不是零星出现，而是成规模地出现。Erdős 与 Simonovits 提出这个猜想，但他们连「至少有两个四元环」都证不出来，可见门槛在极值线附近的行为。

（AI 起草，未经人工审校）

已知结果与进展

  • [PARTIAL] He–Ma–Yang (2021): n=q²+q+1 (q偶) 时成立。
  • [BACKGROUND] Erdős–Simonovits: 连'≥2个C4'都无法证明(初始状态)。

边界与约定

  • 最小参数: 小 n 全枚举（n≤10 的 ex(n;C₄) 与超饱和图的最小 C₄ 数可精确计算）；n=q²+q+1（q 偶）极性图族（HMY 特例域）——q=2,4,6… 的显式实例可机器复核。
  • 退化情形: 超饱和最小过量 e(G)=ex(n;C₄)+1（前提的最低要求）；ex(n;C₄) 仅对特殊 n 有精确公式（如极性图情形）——声称证明若依赖 ex 的精确值，须对一般 n 处理其未知性；孤立点/非连通图允许。
  • 约定依赖: 副本计数无标度约定；"≫"常数的绝对性；n 无整除性限制（主命题对所有 n）。
  • 结构性锚点: 下界构造——ex(n;C₄)+1 条边的极性图加一条边产生的 C₄ 数是否 ≥c√n 是核心数值实验点；Sidorenko/Zarankiewicz 方向的相邻结果不替代本题（已按相邻处理）。
  • 建议独立验证方法（仅描述，不执行）: 用 SAT/ILP 在小 n（≤30）搜索使 #C₄ 最小的超饱和图，数值验证下界系数量级（与 HMY 的极性图分析法不同源）；对声称的一般证明检查其对 ex(n;C₄) 上界的依赖是否自洽。
