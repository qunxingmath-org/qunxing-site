# Erdős：密度零但含全部几何级数的集合（PME 389）

## 题面

(a) 构造零密度整数集：包含每条几何级数的几乎所有项，却在每条等差数列中缺无穷多项；(b) 实数版本。

### 形式化表述

(a) ∃A⊂N, d(A)=0: ∀a,r: {ar^n}⊂^a.e. A 且 ∀a,m: A∩(a mod m) 缺无穷多；(b) 实数版本。

## 人话版

**一句话**：能不能造一个“几乎没几个数”的集合，却抓住每条等比数列的几乎所有项？

密度是指前 N 个整数里有几个落在集合 A 中，再除以 N 取极限；密度为 0 就意味着 A 极稀疏，在整数中占的比例趋于 0。题目分两问：(a) 构造正整数序列 1≤a₁<a₂<…，密度为 0，会从每条等差数列里漏掉无穷多项，却包含每条等比数列除有限项以外的全部项；(b) 对实数集合作类似构造，漏掉每条等差级数的无穷多项、包含每条等比级数的几乎所有项。难点：(a) 里两个要求方向相反——要抓等比数列的尾巴，又要在每类等差数列里留下无穷多个空洞。
