# What is the optimal condition on c for c-cyclical monotonicity to imply optimality of N-marginal plans?

## 题面

N≥2边际最优传输：c-循环单调性是最优性的必要条件；问：使c-循环单调性成为最优性充分条件的代价函数c的最佳（最弱）条件是什么？原文构造了循环单调但非最优的N边际计划与Smirnov型N-流分解。

### 形式化表述

刻画 {c: ∀μ cyclically monotone ⟹ μ optimal} 的精确充要条件。

## 人话版

**一句话**：循环单调到什么程度，就足以保证这个多边际方案最优？

N 边际最优传输要同时搬运 N 组测度，代价函数 c 是 N 个变量的函数；c-循环单调性指方案支集上任意有限多个点都满足代价和的不等式，它总是最优性的必要条件。经典二边际情形下（c 连续且满足一定结构）已知它也是充分的，多边际时却会失效：原文构造了循环单调但非最优的 N 边际计划，并给出 Smirnov 型的 N-流分解。问题是要刻画怎样的代价函数 c 才让'循环单调 ⟹ 最优'成立，并说明这个条件最弱能到什么程度。

## 边界与约定

- 最小参数/退化: N=2经典情形（c-循环单调⟺最优，标准OT定理——基线支，问题主体为N≥3）；N=3最小开放情形。
- 分支/等号: 代价函数c的条件类（连续性/三角不等式型/Monge型）；"最佳（最弱）条件"的偏序口径（条件集合上的极大性）。
- 独立验证建议（与查新途径不同源）: 有限边际小实例（|X_i|≤4）穷举代价矩阵类，数值区分c-循环单调∧非最优的参数域，对照原文反例构造。
