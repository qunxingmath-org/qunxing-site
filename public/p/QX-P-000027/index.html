Erdos P85: f(n+1) >= f(n) for min degree forcing C4

Erdos P85: is f(n+1) at least f(n) for the minimum degree that forces a C4?

题面

强迫C4的最小度函数f(n): 是否对充分大n单调不减 f(n+1)≥f(n)?

形式化表述

f(n):=min{δ: δ-最小度⟹含C4}; 已知f(n)=(1+o(1))√n (via ex(n;C4)); 问: 最终单调性(及更弱'下跳≤常数c'变体)。

人话版

一句话：点数多一个，逼出四元环所需的最小度会反而变小吗？

f(n) 是最小的整数 δ，使得每个 n 个顶点、最小度至少 δ 的图都必然含一个四元环 C4。这个函数由 ex(n;C4)（不含四元环的 n 顶点图最多能有多少条边）决定，已知 f(n) = (1+o(1))√n。问题问的是更细的形状：n 增大时 f(n) 会不会往下掉？猜想是存在 N₀，使所有 n ≥ N₀ 都有 f(n+1) ≥ f(n)，即最终单调不减；一个更弱的变体是允许偶尔下降，但降幅被一个常数 c 界住。

（AI 起草，未经人工审校）

已知结果与进展

  • [PARTIAL] f(n)=(1+o(1))√n (由ex(n;C4)渐近)。
  • [BACKGROUND] 弱变体: 下跳是否≤常数c? 亦开放。

边界与约定

  • 最小参数: f(n) 精确值序列（OEIS A006672）——n≤30 可分支定界/nauty 穷举 C₄-free 图的最大最小度；增量序列 f(n+1)−f(n) 的符号模式是直接检查点（是否存在负增量、首例位置）。
  • 退化情形: n<4（无 C₄ 可能，f 未定义——域外）；n=4（f(4): K₄ 减边？C₄-free 4 点图最大最小度=1（路径/星形），f(4)=2）；δ 离散化使"下跳"含义明确（负增量大小）。
  • 约定依赖: 最小度 δ(G)=min_v deg(v)；C₄ 为子图（非诱导）；"for all large n"=∃N₀∀n≥N₀——声称证明须给出显式 N₀ 或说明存在性。
  • 结构性锚点: 极性图（ex(n;C₄) 极值）的最小度结构随 n 的跳变是单调性破坏的候选机制——扰动分析路线；渐近 (1+o(1))√n 与单调性的相容性（渐近单调不排除有限次下跳）。
  • 建议独立验证方法（仅描述，不执行）: 用 nauty/geng+分支定界独立计算 f(n)（n≤30，与 OEIS 已知值交叉）并检查增量符号；对声称证明在小 n 机器模拟其构造/障碍论证；弱变体（下跳 ≤c）先于强单调性验证（分层攻克）。
