# Erdős P580：半数顶点度≥n/2 蕴含含所有 ≤n/2 阶树（Loebl 猜想顶点数版）

## 题面

设 G 是 n 顶点图且至少 n/2 个顶点的度 ≥ n/2，则 G 包含每个至多 n/2 个顶点的树作为子图（Loebl 猜想的顶点数版，Erdős P580）。已被归约为有限计算。

### 形式化表述

∀ n 顶点图 G: |{v: d(v)≥n/2}| ≥ n/2 ⇒ ∀ 树 T（|V(T)|≤n/2）: T ⊆ G。

## 人话版

**一句话**：半数顶点的度都过 n/2，图里就装得下所有小树了吗？

设 G 是 n 个顶点的图，条件是至少 n/2 个顶点的度数不小于 n/2。结论是：任何顶点数不超过 n/2 的树 T，都能作为子图出现在 G 里（边可以有富余，不要求诱导）。这是 Loebl 猜想的顶点数版本。它的分量在于条件只控制『度数大的那些点有多少』，而不控制图的具体形状，却要保证容纳所有小树——树的数量极多、形状各异。卡片另记这条题『已被归约为有限计算』，但该归约覆盖哪些情形、依据是什么，卡片没有展开，所以这里的检验方式只标为不确定。

## 边界与约定

- 最小参数: n=1,2,3,4 手工枚举（n=3: 度条件或不可满足/或结论平凡）；奇偶 n 分支——奇数 n 时"≥n/2"应为 ⌈n/2⌉ 个顶点度 ≥⌈n/2⌉、树规模 ≤⌊n/2⌋，两取整约定需在声称的反例中显式声明。
- 退化情形: 树为单点（规模 1）平凡嵌入；星形 K_{1,⌊n/2⌋} 要求最大度 ≥⌊n/2⌋−1，度条件自动供给；路径 P_{⌊n/2⌋} 为典型难例。
- 结构性锚点: Zhao 2011（LKS 大 n 证明）已覆盖充分大 n——任何新声称只需处理 n≤N₀；N₀ 非有效（regularity 途径），"有限计算"是原则性口径。
- 建议独立验证方法（仅描述，不执行）: 对固定小 n（≤12）用 SAT/约束搜索枚举满足度条件的图并检验全部树嵌入；与 CB 反例目标（度条件图+允许规模树无嵌入）同构。
