# （来源 C-010）是否存在无穷多正整数 n 使 tan(n) > n？

## 题面

是否存在无穷多正整数 n 使 tan(n) > n？

补充：回答（Thomas Andrews 2014-12-29, 3票）：化为「π/2 的连分数展开中具有奇分母的奇收敛且后续系数足够大」的存在性问题；344 是首个候选但不够（tan 344 ≈ 227.5）。评论（user203812 2014-12-29）指出 Bellamy et al. 论文 math.udel.edu/~lazebnik/papers/tan_n.pdf（与 OEIS A088306 关联）。OEIS 注记确认带符号版本开放。

### 形式化表述

证明或否定：{n ∈ N : tan n > n} 无穷。OEIS A088306 注记：|tan n| > n 的无穷性已由 Bellamy-Lagarias-Lazebnik 证明，但带符号正方向（tan n > n）无穷性似乎未知（It seems not to be known whether there are infinitely many n with tan n > n）。Thomas Andrews（MSE 2014）将该问题化为 π/2 的连分数收敛分子问题（需 344 之后更远的奇分母渐近）。

## 人话版

**一句话**：tan(n) 能比 n 本身还大无穷多次吗？

这里的 n 是整数，单位是弧度。tan(n) 的绝对值要大，n 就必须非常接近 π/2 的奇数倍；这种逼近由 π 的连分数收敛给出。输入指出：使 |tan n| > n 的 n 有无穷多个已有证明，但把绝对值去掉、只要求 tan(n) > n 的正方向，其无穷性似乎还没有定论。也就是说，问题在于正负两侧是否都无穷次地超过 n，还是有一侧只是有限次。
