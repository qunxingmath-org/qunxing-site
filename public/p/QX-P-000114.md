# Aharoni–Berger 秩分划猜想（EGRES）

## 题面

设 M₁,…,M_k 为同一有限地面集 S 上的拟阵，秩函数 r₁,…,r_k。若对每个有序分划 S=X₁⊔⋯⊔X_k 都有 Σᵢ rᵢ(Xᵢ) ≥ (k−1)ℓ，则诸拟阵存在大小为 ℓ 的公共独立集。

### 形式化表述

∀ 有序分划 (X₁..X_k): Σ rᵢ(Xᵢ) ≥ (k−1)ℓ ⇒ ∃ I: |I|=ℓ, I 独立于每个 Mᵢ。

## 人话版

**一句话**：若每种分划下秩的总和都够大，几个拟阵就必有公共独立集吗？

在同一批元素 S 上放 k 个拟阵 M₁,…,M_k，各有秩函数 r_i；一个子集若在每个拟阵里都独立，就叫公共独立集。把 S 任意切成分给各拟阵的 k 块 X₁,…,X_k，再把各块在自己拟阵里的秩加起来，得到一个数 Σ r_i(X_i)。猜想是：只要对每一种这样的有序分划，这个和都至少是 (k−1)ℓ，就必定存在一个大小为 ℓ 的公共独立集。k 个拟阵要同时满足，而 ℓ 只被 (k−1) 倍的余量保证，条件已经相当紧；难处在于分划有无穷多种，需要把它们全部转化为对某组独立集的约束。

（AI 起草，未经人工审校）

## 原文摘录

> Let M₁,…,Mₖ be matroids with rank functions r₁,…,rₖ on the same finite ground set S, and let ℓ be a positive integer. If Σᵢ rᵢ(Xᵢ)≥(k−1)ℓ for every ordered partition S=X₁⊔⋯⊔Xₖ, then the matroids have a common independent set of cardinality ℓ.
>
