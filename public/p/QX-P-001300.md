# Is PR₂ᵢ ⊂ PR₂ᵢ₊₁ for all i≥1 (Cerna's elementary recursive operator hierarchy)?

## 题面

Cerna定义超越PR的初等递归算子层级PR₂ⁱ，猜想所有偶数层真含于下一奇数层。

### 形式化表述

对每个i≥1构造属于PR₂ᵢ₊₁∖PR₂ᵢ的算子。

## 人话版

**一句话**：每升一层，初等递归算子层级就真的严格变大吗？

原始递归（PR）函数由基本函数出发，经复合与原始递归生成。若把'算子'理解为把函数映成函数的映射，就能在 PR 之上继续搭层级；Cerna 的 PR₂ⁱ 正是这样一族超越 PR 的初等递归算子层级。猜想是：对每个 i≥1，偶数层 PR₂ᵢ 真包含于下一层 PR₂ᵢ₊₁。要证严格性，必须为每个 i 造出一个落在上层却不落在下层的算子，仅有包含关系不够。
