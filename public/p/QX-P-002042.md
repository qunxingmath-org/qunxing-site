## 人话版

**一句话**：一条曲线能否只用最少数目的多项式方程「集合论地」切出来？

STCI 是 set-theoretic complete intersection（集合论完全交）的缩写：余维为 c 的子簇 X 若能用 c 个多项式的公共零点集恰好表示出来，就是集合论完全交。注意只要求点集相等，不要求 X 的理想由这 c 个多项式生成。Hartshorne 猜想断言：仿射空间 Aⁿ（n≥3）中每个连通的光滑子簇都是集合论完全交。卡上注明这是「题面修正」版，并把与习题 I.2.17(d) 相关的非连通性结论列为题面必须交代的边界情形。
