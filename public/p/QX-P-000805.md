# OEIS A056777：φ(n+12)=φ(n)+12 且 σ(n+12)=σ(n)+12 的合数 n=p(p+8)（素数四连组）

## 题面

每个满足 φ(n+12)=φ(n)+12 且 σ(n+12)=σ(n)+12 的合数 n 必形如 n=p(p+8)，其中 p,p+2,p+6,p+8 均为素数（素数四连组）。

### 形式化表述

n 合数 ∧ φ/σ 平移等式 ⇒ ∃p: n=p(p+8), p,p+2,p+6,p+8∈ℙ。

## 人话版

**一句话**：同时满足两个平移等式的合数，只能是 p(p+8) 这种形状吗？

φ(n) 是 Euler 函数，数 1 到 n 中与 n 互素的整数个数；σ(n) 是所有正因数之和。题目同时要求 φ(n+12)=φ(n)+12 与 σ(n+12)=σ(n)+12，并要求 n 是合数。猜想断言：这样的 n 必定形如 p(p+8)，其中 p、p+2、p+6、p+8 四个数全是素数——这种结构叫素数四连组。也就是说，两个看似宽松的函数平移等式，会把 n 锁死在一个非常狭窄的形状里；把这种形状刻画完全，就是分类问题的目标。
