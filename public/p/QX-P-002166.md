# EGZ 定理相关加性组合新命题（S1⟺S2+二维 analogue）

## 题面

EGZ 定理相关加性组合新命题（S1⟺S2 等价+二维 analogue）

## 人话版

**一句话**：子集和覆盖整个区间，真的等价于任意整数组都能分块？

设 k₁≤k₂≤…≤k_n 是正整数。命题一：0 到 k₁+…+k_n 之间的每个整数，都能写成这些 k_i 中某几个之和（每个最多用一次）。命题二：任意 k₁+…+k_n 个整数，都能划分成 n 组，使第 i 组恰含 k_i 个数且这 k_i 个数之和被 k_i 整除。原文声称这两条等价，并由此提出二维的类似命题。命题二是 Erdős–Ginzburg–Ziv 定理（任取 2n−1 个整数必有 n 个之和被 n 整除）的推广形态，把「n 个数」换成一组可变的 k_i。
