# （来源 C-017）光束进入整点坐标多边形房间（一面墙开口），最大反射次数/边数比是多少？（坐标∈[0,50]）

## 题面

光束进入整点坐标多边形房间（一面墙开口），最大反射次数/边数比是多少？（坐标∈[0,50]）

补充：MSE 0 回答 0 评论（2013-12 至今）。

### 形式化表述

给定平面整点多边形房间（一面墙开口），由整点对定义的入射光束，求 maximize 反射次数/边数 比，坐标范围 [0,50]。求最优构造或一般上界。

## 人话版

**一句话**：整点坐标画出的镜面房间里，一束光最多能弹多少次？

房间是平面上一个顶点都在整点上的多边形，一面墙上开个口，一束由整点确定方向的光从开口射入，在墙之间不断反射。问的是「反射次数与边数之比」的最大值，且所有顶点坐标都限制在 0 到 50 之间的整点。分析反射的常用手段是展开法：把每次反射后的房间沿墙翻折出去，折线就变成直线，反射次数于是转化为直线穿过了多少个镜像房间。由于坐标范围有界，可枚举的多边形与入射方向都是有限的。
