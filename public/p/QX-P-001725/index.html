题面

单位圆为三角形的平面度量存在？

题面草稿（AI 起草，待核）

问：是否存在 $\mathbb{R}^2$ 上的度量 $d$，使得 (i) $d$ 诱导的拓扑与 $\mathbb{R}^2$ 上的通常拓扑一致；(ii) 在 $d$ 之下，圆（或至少单位圆）是三角形？其中「$d$ 之下的单位圆」指集合 $\{y\in\mathbb{R}^2: d(x,y)=1\}$（对某个 $x$ 而言）。作为对照：欧氏度量下（单位）圆是圆，曼哈顿 $\ell^1$ 度量下是正方形，而沿某个固定三角形的边方向取最短路径所定义的度量给出六边形。（歧义：原文把「circles, or at least unit circles」并列成两种强弱不同的提法，未说明圆心位置是否受限，也未说明「三角形」是否要求其边为通常的直线段。）

人话版

一句话：换一种量距离的方式，平面上的「圆」能变成三角形吗？

在平面上定义一个距离 d 之后，「圆」就是到某定点的距离等于常数的点集，半径取 1 时叫单位圆。换个距离，单位圆的形状就变了：欧氏距离给圆；曼哈顿距离（只许沿横竖走）给正方形；若规定只能沿某个固定三角形的三个方向走、取最短路径，单位圆可以是六边形。可见这些例子给出的是凸的、中心对称的图形。问题问：能否造一个距离，使单位圆（或者所有圆）是三角形，同时它还诱导出平面通常的拓扑，即开集概念不变？

原文摘录

If we use the Euclidean metric on $\mathbb R^2$ , (unit) circles are circles; if we use the Manhattan distance or $\ell^1$ distance, (unit) circles are squares. We can also get polygons with an even number of sides: for instance, circles are hexagons if we define the distance between two points to be the shortest path between them that moves only along the directions of the sides of some fixed triangle.
Is there a metric on $\mathbb R^2$ (that gives the usual topology) for which circles, or at least unit circles, are triangles?
