# 20.126 加法群有限生成的 brace：(G,◦) 可非可解/含自由子群？

## 题面

是否存在 brace (G;+,◦)，(G,+) 有限生成，且 a) (G,◦) 非可解？ b) (G,◦) 含非交换自由群？

### 形式化表述

(G,+) fg ⇒ (G,◦) 非可解可能？

## 人话版

**一句话**：加法群有限生成的 brace，乘法那边能不可解甚至含自由子群吗？

brace (G;+,∘) 是同一个集合上带两种运算的结构：(G,+) 是阿贝尔群，(G,∘) 是群，且满足分配律 a∘(b+c)+a=(a∘b)+(a∘c)。brace 是研究 Yang–Baxter 方程集合解（即 skew brace 与相关结构）的主要工具。题目问：是否存在这样的 brace，其加法群 (G,+) 有限生成，而乘法群 (G,∘) 分别 a) 不可解？b) 含有非交换自由子群？通常加法侧有限生成会强烈约束乘法侧，问这种约束能到多强。

> A brace (G; +, ◦) is non-empty set G with two binary operations +, ◦such
> that (G, +) is an additively written abelian group, (G, ◦) is a multiplicatively written
> group, and a ◦(b + c) + a = (a ◦b) + (a ◦c) for all a, b, c ∈G. Does there exist a brace
> with finitely generated group (G, +) such that
> a) the group (G, ◦) is non-solvable?
> b) the group (G, ◦) contains a non-abelian free group?
