# 超曲面 K-稳定性（3≤d≤n+1）

## 题面

超曲面 K-稳定性（3≤d≤n+1）

## 人话版

**一句话**：次数介于 3 和维数加一之间的超曲面,哪些是 K-稳定的？

n 维射影空间里的次数 d 超曲面,其规范类是 O(d−n−1),所以当 d ≤ n 时反规范类丰沛,是 Fano 簇;d = n+1 时规范类平凡,严格说已不属于 Fano 情形。K-稳定性是判断这类簇上能否存在 Kähler–Einstein 度量的代数条件,由测试构型上的 Donaldson–Futaki 不变量非负来刻画。问题问:在标题给出的 3 ≤ d ≤ n+1 这一段里,超曲面的 K-稳定性该如何按 d 与 n 的具体关系判定。
