# Kourovka 15.48：任意生成集下 <2log₂|G| 次乘法枚举全群？

## 题面

任意生成集下 <2log₂|G| 次乘法枚举全群？。

### 形式化表述

[任意生成集下 <2log₂|G| 次乘法枚举全群？：以原文为准；15.48]

## 人话版

**一句话**：从任意生成元出发，2log₂|G| 次乘法真能把整个群都造出来吗？

设 G 是任意非平凡有限群，X 是它的任意一组生成元。从这个生成元集出发反复做乘法，问：群里的每个元素是否都能用少于 2·log₂|G| 次乘法得到？计数规则很关键：每一步都可以用前面已经算出来的元素相乘，所以可以复用中间结果，这就像计算整数时用的『加法链』，比逐次累乘高效得多。若成立，就给出了任意有限群的一个统一的短生成公式；要否定它，只需在一个具体群里找出一个需要更多乘法才能到达的元素。

（AI 起草，未经人工审校）

## 原文摘录

> 〔15.48 〕提出人：C. R. Leedham-Green
> Let G be any non-trivial finite group, and let X be any generating set for G. Is it true that every element of G can be obtained from X using fewer than 2 log2 |G| multiplications? (When counting the number of mutiplications on a path from the generators to a given element, at each step one can use the elements obtained at previous steps.) C. R. Leedham-Green
>
> —— Kourovka Notebook, Unsolved Problems in Group Theory, No. 21（E. I. Khukhro & V. D. Mazurov 编），问题 15.48（第15辑 2002 年）

## 边界与约定

- 最小参数: 2 阶群（log₂|G|=1，需 <2 次乘法覆盖 e 外唯一元素——0 次即可）基线；小群全枚举可机器验证。
- 退化情形: 生成集含冗余元（|X| 大）不改变问题（取子集即可）；阿贝尔情形 SLP=字长，2log₂|G| 与经典直径界对接——声称反例需给出（群,生成集,元素）三元组并证其 SLP 下界（难）。
- 约定依赖: "乘法次数"=SLP 长度（每步产生一个新元素）；与"乘法链上中间元素可无限复用"一致（题面括注已声明）。
- 建议独立验证方法（仅描述，不执行）: 小群库全枚举（|G|≤64）对最坏生成集求 SLP 直径上确界，检验 <2log₂|G| 余量；与 Babai–Szemerédi halving 技巧的理论 2log 系数（是否可达）作文献比对。
