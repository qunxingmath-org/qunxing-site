题面

（表述已由查新Agent依据原文补全编号问题）所有有限连通 Cayley 图的族是否弱/渐近哈密尔顿？超立方序列 (Q_n) 是否渐近哈密尔顿？是否存在普适常数 R 使每个 Q_n 都有 R-稠密诱导圈？

形式化表述

序列 (G_n) 渐近哈密尔顿 := 存在圈 C_n⊆G_n 使 V(G_n)\C_n 的每点到 C_n 距离一致有界；R-稠密诱导圈 := 诱导圈 C 使每点到 C 距离 ≤R。问题1.6 是 snake-in-the-box 变体。

人话版

一句话：在无限提升的图族里，能不能找到「几乎扫过全部点」的长圈？

一个图序列 (Gₙ) 称为渐近哈密尔顿的，若每个 Gₙ 里存在一个圈 Cₙ，使得 Gₙ 中每个顶点到 Cₙ 的距离都被同一个常数界住——圈不必经过所有点，但漏掉的部分必须离圈很近。R-稠密诱导圈则要求这个圈本身是诱导圈，且图中每个顶点到该圈的距离都不超过 R。题面列出的四问分别是：所有有限连通 Cayley 图构成的族是否弱哈密尔顿、是否渐近哈密尔顿、超立方体序列 (Qₙ) 是否渐近哈密尔顿、是否存在通用常数 R 使每个 Qₙ 都有 R-稠密诱导圈。

原文摘录

Problem 1.2. Is C (the family of all finite connected Cayley graphs) weakly hamiltonian?
Problem 1.3. Is C asymptotically hamiltonian?
Problem 1.5. Is (Q_n) asymptotically hamiltonian?
Problem 1.6. Is there a universal constant R such that Q_n has an R-dense induced cycle for every n>1?
——Georgakopoulos, "Asymptotic connectivity, hamiltonicity and toughness", arXiv:2610.09992 (2026-10)

已知结果与进展

  • 论文建立渐近连通度/韧性/哈密尔顿性的基本理论（如渐近哈密尔顿 ⇒ 渐近连通度≥2）。
  • 渐近哈密尔顿性在 Cartesian 积下封闭（论文 Section 7）。
  • Q_n 本身哈密尔顿经典；但 R-稠密诱导圈（诱导性+稠密性同时）未知。
  • 作者注：问题1.3 可能比经典 Cayley 哈密尔顿猜想（Conjecture 1.1）更可攻（对生成集不敏感）。

边界与约定

  • 边界：粗几何定义（一致有界距离）；Cayley图族。
