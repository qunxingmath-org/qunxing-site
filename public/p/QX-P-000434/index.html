Atiyah–Sutcliffe Conjecture 1: linear independence of configuration polynomials

题面

n 个不同点的构型多项式线性无关（Atiyah–Sutcliffe 猜想 1）。

形式化表述

det(Atiyah) ≠ 0 对所有 n 点构型。

人话版

一句话：平面里 n 个不同点给出的构型多项式，一定线性无关吗？

对 R³ 中 n 个互不相同的点，每一点对应一个「构型多项式」：以该点为变量，其余点固定形成的多项式，其构造来自 Atiyah 与 Sutcliffe 研究点构型时提出的行列式。猜想 1 断言：这 n 个构型多项式在复数域上线性无关；等价的说法是，由它们组成的 Atiyah 行列式不为零。也就是说，不论 n 个点怎样摆放（只要求互不相同），这些多项式都不会线性相关。题目要求对所有 n 与所有构型证明这一点。

（AI 起草，未经人工审校）

原文摘录

For n distinct points in ℝ³, the n configuration polynomials are linearly independent over ℂ (Atiyah–Sutcliffe 2003, Conjecture 1; equivalently the Atiyah determinant nonzero).

—— Atiyah–Sutcliffe 2003 论文; formal-conjectures（GitHub issue #4756）

已知结果与进展

  • n=3 Atiyah（Hopf 纤维化）；n=4 Eastwood–Norbury（证 C2 更强）；反射轴/共线/旋转对称特例已证；2026 arXiv:2610.33090 研究退化构型。

边界与约定

  • 边界：构型多项式定义；n点互异。
  • 独立验证建议：数值计算随机构型Atiyah行列式条件数（近奇异即线索）。

相关进展与声称解决

  • [PARTIAL] n≤4；特例类已证；一般情形无声称解决。
