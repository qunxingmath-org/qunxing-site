Erdos P94: convex polygon, sum f(u_i)^2 << n^3

Erdos P94: for a convex n-gon, must the sum of squared distance multiplicities be O(n^3)?

题面

凸n边形各距离出现次数f(u_i): 证明 Σf(u_i)² ≪ n³。

形式化表述

∀ convex n-point set X: Σ_d mult(d)² = O(n³). (平凡Σmult(d)=n(n-1)/2.)

人话版

一句话：凸 n 边形的距离重复得很厉害时，平方和能有多大？

取平面上一个凸 n 边形的顶点集 X。对每个正实数 d，记 mult(d) 为 X 中恰好相距 d 的点对个数（题面把它记作 f(u_i)）。问题问 Σ_d mult(d)² 的上界。所有点对共有 C(n,2) 个，所以 Σ_d mult(d) 就等于 n(n−1)/2；平方和衡量的是距离分布有多不均匀——把点对挤到少数几个距离上会让它变大，而如果每个距离都只出现一次，平方和就只有 C(n,2) 本身。要证的是凸性足以把 Σ_d mult(d)² 压在 O(n³)：也就是说，平均下来每个距离的多重数只能到 O(n) 量级。要反驳只需造一个凸点集，让少数几个距离上聚集起远多于 n 个点对。
