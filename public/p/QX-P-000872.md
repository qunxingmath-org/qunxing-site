# Kirby 1.74：连通和下 ropelength 的控制（Rop(K1#K2) 型不等式）

## 题面

绳长（ropelength）在连通和下是否满足带减项的上界：(a) 减 4π−4；(b) 减某绝对常数 c。

## 人话版

**一句话**：把两个纽结接起来，绳长能不能比两者相加更短一些？

绳长 ropelength 是一个几何量：把纽结想成一根粗细固定的绳子，绳长就是绳子的长度除以它的直径。纽结型越复杂，绳长越大。两个纽结 K1、K2 的连通和 K1#K2 是剪开两者各一端再对接而成。明显的上界是 Rop(K1#K2) ≤ Rop(K1)+Rop(K2)，问题问能否减去一个固定量：(a) 减 4π−4，或较弱的 (b) 减某个绝对常数 c>0。难点在于对接处两块曲率会互相「挤」出一点余量。

（AI 起草，未经人工审校）

## 原文摘录

> (a) For any knot or link types K1,K2: Rop(K1#K2) ≤ Rop(K1)+Rop(K2)-(4π-4). (b) Rop(K1#K2) ≤ Rop(K1)+Rop(K2)-c for some absolute c>0.
