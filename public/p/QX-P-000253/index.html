The Bollobas-Eldridge-Catlin packing conjecture

题面

两个 n 点图 G1,G2 若最大度满足 (Δ1+1)(Δ2+1)≤n+1，则存在双射嵌入使两图边集不交（可打包）。

形式化表述

∀n 点图 G1,G2: (Δ1+1)(Δ2+1)≤n+1 ⇒ ∃π∈S_n 使 E1∩π(E2)=∅。

人话版

一句话：只要 (Δ₁+1)(Δ₂+1)≤n+1，两张图就能挤在同一批点上而不撞边吗？

两个图 G₁、G₂ 都画在同样的 n 个顶点上。若存在一个顶点重排 π，使把 G₂ 的边按 π 搬过去之后不与 G₁ 的边重合，就说这两个图可以打包（等价于两幅图的边集不交地共存）。Δ 指最大度，即一个顶点最多连多少条边。Bollobás–Eldridge–Catlin 猜想：只要 (Δ₁+1)(Δ₂+1) ≤ n+1，打包一定存在。这个条件来自把 K_n 的边拆成两个正则图时的计数必要式，猜想断言它对任意两个图也已经够用。

（AI 起草，未经人工审校）

原文摘录

Bollobás–Eldridge–Catlin conjecture (1978): if (Δ(G1)+1)(Δ(G2)+1) ≤ n+1 then G1 and G2 pack on n vertices.

—— 提出: B. Bollobás, S. Eldridge, C. Catlin (1978)

形式化: formal-conjectures Paper/BollobasEldridgeCatlinConjecture.lean

已知结果与进展

Sauer–Spencer 加和形式已证；乘积形式在 Δ2≤2 等特殊情形已证（Kaul–Kostochka–?）；一般开放。

边界与约定

  • 边界：打包=双射顶点映射边集不交；n点两图。
  • 独立验证建议：小n临界实例（(Δ1+1)(Δ2+1)=n+2反例候选）枚举检验。

相关进展与声称解决

  • - [PARTIAL] Sauer–Spencer 1982（加和形式）；Δ2≤2 情形已证。
