# 1-因子分解猜想（充分大 n 已证 CKLOT）

## 题面

1-因子分解猜想（充分大 n 已证 CKLOT Memoirs；一般 n 开放）

## 人话版

**一句话**：度数接近顶点数时，正则图的边一定能拆成完美匹配吗？

完美匹配指一组两两不共用顶点、且覆盖全部顶点的边。1-因子分解是把全部边分成若干个完美匹配；若图有 d 个这样的匹配，它必定是 d-正则的。猜想的方向相反：2n 个顶点的 d-正则图，只要 d 足够大、足够接近完全图的度数 2n−1，就一定能做 1-因子分解。难点在中段度数，各种奇偶阻碍都可能出现。这张卡标为部分解决：只对充分大的 n 证出，一般 n 仍开放。
