# 1-generic ⇒ index guessable 可逆性

## 题面

1-generic ⇒ index guessable 可逆性

## 人话版

**一句话**：1-generic 在 index guessable 意义下能被反转吗？

1-generic 实数指这样一类实数：对每个可计算枚举的字符串集合，它要么被其中某个字符串延长，要么被其中某个无延长的串所避开，也就是「凡是能构造性地满足的条件，它都满足或明确避开」。index guessable 是一种更弱的可构造性要求，指存在算法能在有限步内正确猜出某个下标参数。题目问的是把这两者结合后的一种可逆性：给定 1-generic 的实数，在 index guessable 的意义下能否把某个操作反过来，使所得结果仍保持相应性质。卡片只留标题。
