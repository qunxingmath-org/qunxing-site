隐私政策

适用于网站 www.qunxingmath.org 和群星桌面端。更新于 2026 年 11 月 25 日。

要点

  • 网站不用 Cookie，不运行脚本，不加载其他网站的统计代码、字体或图片。服务器的访问日志保存 14 天。
  • 桌面端默认不上传任何东西。运行记录、证明和花费都留在你的电脑上。
  • 上传要你自己点，分两步，每一步单独同意，都可以跳过。现在还不能上传：收件服务开放之前，桌面端的上传按钮不会发出任何东西。
  • 上传的数据存放在美国。对中国境内的用户来说，这是向境外提供个人信息，上传前会单独征求你的同意。

1. 谁处理你的信息

群星项目，由 GitHub 组织 qunxingmath-org 的维护者负责。

联系邮箱：team@qunxingmath.org。安全问题请按 SECURITY.md 私下报告。

4. 上传：两步，各自同意

收件服务开放以后才适用。开放前我们会按实际情况更新本页。

第一步：提交证明，点亮星星

  • 公开的材料：自然语言证明、Lean 工程和本机检查的参数、题面和题意复核的记录、用了哪些模型和工具。Lean 代码按 Apache-2.0、文字按 CC BY-SA 4.0 公开。公开后只能撤回，不能删除。
  • 账号：用 GitHub 授权关联一个群星账号。群星服务器用 GitHub 给的令牌查一次你的数字用户编号，然后丢掉令牌，只保存这个编号。编号只用来担责和撤回，不公开，也不和你的科研数据关联。
  • 不公开：用量和费用、对话原文、提示词、你电脑上的文件和路径、机器信息。

第二步：上传科研数据

  • 上传什么：每个环节的 token 数、用时、按 API 价格折算的花费；用了哪些模型和工具版本、预算上限、搜索次数、干预的类型和次数；题目编号、停在哪一步、自报的“对不对”“新不新”；安装 ID（本机随机生成，可以在设置里重置）、运行时间（精确到分钟）、通道（订阅或 API）。
  • 用来做什么：只用于科研统计，研究 AI 解数学题要花多少算力、效果怎样。不用于广告，也不出售。
  • 服务器上：安装 ID 只存它的加密散列（HMAC），不存原文。科研数据和证明分开存放。
  • 公开：匿名化以后以 CC0 1.0 公开；延迟两周发布，时间只精确到周，条数太少的组合并后再公开。
  • 可选的两项，各自单独勾选：失败路径摘要（匿名，不超过 1000 字，以 CC0 公开）；昵称（先经人工审核，列入贡献者名单）。

两步都不上传对话原文、提示词、你电脑上的文件和路径、机器信息、账号密码和 API 密钥。上传的内容一有变化，就重新征求你的同意。

6. 保存多久

网站访问日志14 天。
上传的科研数据保存到研究结束或满 3 年，以先到者为准。
账号关联保存到你注销账号。为了办理撤回，我们只保留必要的撤回记录。
删除以后收件库里的记录立即删除，灾备里的副本 30 天内消失，之后发布的数据不再包含它。
已经公开的内容公开的证明可以撤回，页面上会标“已撤回”。已经发布的数据版本、已发表的统计和别人保存的副本，我们收不回来。

7. 你的权利

  • 关闭上传：设置里随时关闭自动上传。
  • 删除：在桌面端按记录申请删除。重装电脑前，可以在设置里导出删除凭据；凭据丢了，写信给我们，按指引提供当时的安装 ID。
  • 查询、复制、更正、撤回同意、注销账号：写信到 team@qunxingmath.org，说明是哪类数据、想怎么处理。我们会用最少的必要信息核对是不是你本人。
  • 你也可以直接联系上面的服务商，用它们隐私政策里写的渠道。需要的话，我们帮你找到对应的记录。
  • 邮件里只写必要的信息；不要把删除凭据的原文写进邮件，在桌面端里提交。

8. 年龄

上传和提交证明要年满 16 周岁。浏览网站和在本机使用桌面端没有这个限制。

9. 安全

  • 网站和收件服务只用 HTTPS。收件服务不记访问日志。
  • 灾备和研究快照先加密再存；解密用的密钥离线保管。
  • 发生或怀疑发生泄露时，我们先关掉对应的入口，撤销和更换密钥，再按法律要求通知你和主管部门。

10. 本政策的修改

修改后更新本页和上面的日期。改动的历史在 GitHub 上公开：qunxing-site。上传的内容或接收方有变化时，桌面端会重新征求你的同意。
